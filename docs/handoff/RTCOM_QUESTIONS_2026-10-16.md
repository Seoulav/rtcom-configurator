# 알티컴 확인 요청 질문 목록 (2026-10-16)

알티컴에 아직 답을 받지 못한 질문만 모은 문서입니다(15번과 17~19번은 2026-10-16에 답을 받아 뺐습니다). 번호는 `docs/RTCOM_MANUFACTURER_DATA_REQUEST.md` §5 표의 번호와 같습니다(1~15번과 17~19번은 답을 받아 반영 완료). 답을 받으면 §5 표 "답" 칸에 날짜와 함께 적고, 사이트에 반영한 뒤 `docs/handoff/OPEN_ITEMS.md`의 해당 항목을 지웁니다.

## 보내는 방법

아래 "메일 문안"과 "질문"을 그대로 복사해 보내면 됩니다. 답은 번호별로 받으면 정리하기 쉽습니다. 특정 현장 이름이나 현장 명령 값은 이 저장소에 적지 않습니다.

## 메일 문안

알티컴 담당자님께

RTCOM 제품정보 사이트(XDM·SPX·VDM·QMS·HDS 제어 예시 포함)를 정리하면서 매뉴얼만으로 확인되지 않는 내용이 생겨 아래와 같이 문의드립니다. 특히 AMX 같은 통합 제어에서는 RS-232보다 LAN(TCP/IP) 제어를 많이 쓰고 있어, 1순위 묶음(LAN 제어)을 가장 먼저 확인 부탁드립니다. 포트·전송 방식·동시 접속은 회신 주셔서 반영했습니다(감사합니다). 번호별로 짧게 답해 주셔도 충분합니다. 매뉴얼이나 별도 자료가 있으면 쪽 번호만 알려 주셔도 됩니다.
