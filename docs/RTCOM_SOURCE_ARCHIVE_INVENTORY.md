## 자료 적용 원칙

- 최신본과 이전자료가 함께 있는 경우 최신본을 우선하고, 버전과 날짜를 기록한다.
- 카탈로그에 같은 제품이 있어도 연결 허용 관계와 전원 조건은 별도 공식 자료가 없으면 확정하지 않는다.
- 제조사 표기 충돌은 임의로 정정하지 않고 `표기 검토 필요`로 표시한다.
- 외부 공개 전에는 로고·제품 사진·도면·매뉴얼의 웹 사용 허가 범위를 확인한다.
