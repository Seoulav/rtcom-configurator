# RTCOM Configurator 디자인 초안

작성일: 2026-09-18  
상태: 클릭 가능한 화면 설계 초안. 실제 제품 구성·검증 엔진은 구현 전이다.

## 참고 및 적용

참고: [Analog Way Configurator](https://www.analogway.com/configurator), 2026-09-18 확인.

공개 페이지 콘텐츠와 스타일 정의에서 상단 6단계 진행 표시, 데스크톱 좌우 구성, 왼쪽 선택 목록, 오른쪽 장비 표현, 빈 슬롯 클릭을 통한 입출력 카드 선택, 구성 확정·PDF 출력 흐름을 확인했다. 연결된 브라우저가 없어 실제 렌더링된 참고 사이트의 스크린샷과 스크롤 동작은 확인하지 못했다.

RTCOM에서는 아래 요소를 사용한다.

- 얇은 구분선, 절제된 카드 테두리, 넓은 여백, 단계별 명확한 제목.
- 제품군/모델 선택 시 표시되는 선택 상태와 하단 다음 단계 버튼.
- 섀시 단계의 좌측 모델 선택, 우측 제품군 이미지 및 선택 요약.
- 카드 단계의 중앙 슬롯 도식과 우측 카드 선택 패널.
- 입력·출력 카드 이후 별도의 전송기 연결 단계.

RTCOM용 문구·색상·컴포넌트를 새로 작성했다. 참고 사이트의 로고·사진·문구·소스코드를 가져오지 않았다. 제품군 사진은 사용자가 제공한 RTCOM PDF p.4, 14, 17에서 추출한 이미지이며 내부 초안 검토에만 사용한다. 공개 사용 허가 여부는 기존 Data Gaps G14를 따른다.

## 단계 순서

1. **제품군:** XDM / SPX / VDM. 초기 진입 화면이며 섀시 선택보다 먼저 배치.
2. **섀시:** 선택한 제품군의 메인프레임 목록과 이미지. 사용자 요구량 입력은 이후 보조 영역으로 제공하고 제품군보다 앞에 두지 않는다.
3. **입출력 카드:** 슬롯 선택 → 카드 선택 → 포트 합계 반영.
4. **전송기:** 입력 TX / 출력 RX, 카드별 장비 선택, 연결 수량, 거리.
5. **구성 검토:** 메인프레임·카드·전송기 수량을 한 목록으로 확인.
6. **내보내기:** PDF / CSV / JSON 형식별 미리보기. 연락처 입력은 요구하지 않음.

이 순서는 기존 개발 계획서의 제품군·요구사항 첫 단계 구조를 구체화한다. Analog Way 전용 VPU/IPU/MVR 선택 단계는 RTCOM의 I/O 및 전송기 구성 단계로 바꾼다.

## 초안의 상호작용

- 세 제품군 모두 선택 가능하며 섀시 목록과 카드 목록이 변경된다.
- 제품군 또는 섀시를 변경하면 이후 선택을 초기화한다. 실제 앱에서는 영향 항목 확인 후 적용하는 흐름을 추가한다.
- 섀시를 선택해야 입출력 단계로 진입할 수 있다.
- 입력·출력 슬롯을 눌러 해당 방향 카드 선택과 제거를 체험한다.
- XDM CAT/광 직접 연결, SPX COS12/RX 관계를 이용해 전송기 선택 방식을 보여준다.
- VDM의 개별 카드-전송기 호환 관계는 확인 전이므로 후보 목록과 확인 필요 상태만 표시한다.
- 전환형 CTR100은 연결 방향에 따라 TX/RX 역할을 표시한다.
- 전송기 연결 수량은 해당 카드의 포트 수 이내에서 정하고 BOM은 같은 모델을 합산한다.
- 단계별 되돌아가기와 완료한 단계 재진입이 가능하다.
- 출력 화면은 예시이며 실제 PDF/CSV/JSON 다운로드는 제공하지 않는다.

## 실제 사양과 화면 예시의 구분

모델 목록과 개별 카드 포트 수는 이전 근거 문서를 따른다. 섀시 이미지는 개별 선택 모델 사진이 아니라 제품군 전체 사진임을 표시한다.

카드 편집기의 입력 2칸·출력 2칸은 UI 조작용 개념 도식이다. 특정 섀시의 물리 슬롯 수, 위치, 허용 카드 목록을 의미하지 않는다. 프레임별 실제 배치는 공식 도면과 허용표 확보 후 대체한다.

초안에서는 신호 프로파일, 케이블 종류, 거리 한도, 급전 예산, 실제 설치 가능성을 검사하지 않는다. 구성 검토와 내보내기 화면에 실제 검증 전임을 표시하며 '유효 구성' 또는 '검증 완료'라고 표현하지 않는다.

## 시각 방향

- 기본 강조색: 절제된 오렌지. 선택 단계·포커스·선택 카드에 사용.
- 표면: 밝은 중성색, 장비 이미지 영역은 원본 사진의 흰 배경 유지.
- 다크 모드에서는 별도 제품 색상 쌍으로 대비 유지.
- 다음 단계는 짙은 중성색 버튼, 이전 단계는 낮은 강조 수준.
- 호스트 디자인 조절 기능이 있으면 오렌지/블루 및 기본/간결 여백 비교 가능.
- 모바일에서는 제품군 카드와 좌우 작업 영역을 세로로 재배치.

## 실제 구현에서 추가할 내용

1. 공식 후면 도면 기반 슬롯 위치와 제품별 카드 제한.
2. 전송기 포트별 개별 배정, 케이블 규격·급전 선택, HDMI TX/RX 쌍 연장.
3. 요구량 입력, 호환·성능 검증, 오류 해결, 자동 추천.
4. 변경 영향 확인, Undo/Redo, Draft 영구 저장, 파일 import/export.
5. 키보드 포커스 복원, 실제 PDF 인쇄 확인 및 접근성 검증.

## 초안 검증 기록

로컬 미리보기에서 세 제품군 전환, 섀시 선택 전 다음 단계 차단, 카드 선택, XDM 전환형 TX/RX 수량 합산, SPX 12포트 수량, VDM 2포트 카드 예외와 미확인 연결 표시, PDF/CSV/JSON 미리보기를 점검했다. 320/480/720/1024px 폭과 다크 모드를 확인했다. 이 검증은 화면 초안의 동작에 대한 것이며 제품 호환성 검증 결과가 아니다.
