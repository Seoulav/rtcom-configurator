## 3. 제조사에 함께 확인할 질문

| 번호 | 질문 | 답변이 필요한 이유 |
|---|---|---|
| Q1 | 현재 공식 판매 제품과 단종·대체 제품은 무엇입니까? | 웹 장비 목록의 노출 상태를 결정함 |
| Q2 | 제공 사진과 매뉴얼을 회사 웹사이트와 GitHub Pages에 게시할 수 있습니까? | 공개 배포 범위를 결정함 |
| Q3 | 모델별 최신 문서 버전과 개정일은 무엇입니까? | 이전자료가 최신 자료보다 우선 적용되는 문제를 방지함 |
| Q4 | XDM·SPX·VDM의 섀시별 카드 허용표와 금지 조합이 있습니까? | 구성기 검증 엔진을 완성함 |
| Q5 | 카드·전송기·케이블 조합별 공식 최대 거리와 전원 조건은 무엇입니까? | 연결 가능 여부와 필수 부속품을 계산함 |

| Q7 | 제품별 기본 포함품과 주문 시 별도 지정해야 하는 SKU는 무엇입니까? | 실제 발주용 BOM을 생성함 |

## 4. 요청 메일에 첨부할 안내 문구

RTCom 장비를 한 화면에서 검색·비교하고, XDM·SPX·VDM 프레임과 카드를 구성할 수 있는 내부 AV 설계 도구를 제작하고 있습니다. 제품 정보의 정확성과 최신성을 확보하기 위해 위 표의 자료를 요청드립니다. 가능하면 제품별 폴더에 모델명, 문서 버전, 개정일을 포함하여 전달해 주시고, 웹사이트 게시가 가능한 사진·문서의 범위도 함께 회신해 주시기 바랍니다.
