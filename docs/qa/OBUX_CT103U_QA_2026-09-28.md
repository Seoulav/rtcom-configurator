## 2. CT103-U-H / CR103-U 04 제품 사양 요약

- 요청: 사용자 "CT103-U-H / CR103-U 제품 사양서도 요약형태로 수정해줘". XDM-CT103/CR103 요약(0.65.0, "중복표기 삭제하고 최대한 요약")과 같은 기준을 적용했습니다.
- 15행 → 12행:
  - 지원 해상도·최대 전송거리: CT·CR 값이 같아 공통 행 하나로 합침
  - 규격: 한 행으로 합치고 조건에 "CR103-U는 HDMI 1.4b"만 남김
  - 입력·출력 신호: 핀 배열 표기 "HDBaseT 0,1,2,3+/-" → "HDBaseT 1 Port"; CR103-U 출력 "DVI / HDMI (TMDS), 3.5mm stereo audio" → "HDMI 1 Port, 3.5mm Stereo Audio 1 Port"; 입력 신호의 INPUT 버튼 중복 문구 정리
  - 330ft 병기 삭제(0.72.0 인치·lbs 정리와 같은 기준), 전원 조건 "CR103-U 최대 15W" → "CR103-U 소비전력 최대 15W"
- 값(해상도, 100m, DC +12V 2A, 크기, 무게) 자체는 바꾸지 않았습니다.
- 스크린샷: `docs/qa/ct103u-spec-summary-screens/ct103u-spec-1280.png`, `ct103u-spec-390.png`
