# 카드 팝업 "카드별 수량" UI가 사라지는 버그 수정 (2026-09-28)

## 요청

- "입카드선택시 수량을 넣을 수 있는데 다시 조정하려고 누르면 수량이 안보이고 장착됨이 보이는데 이부분 수정해"
- "출력카드 선택시는 수량선택이 안되는 버그가 있어"
- 스크린샷: XDM-12(3입력·3출력, 6/6 완성) 출력 슬롯 1을 다시 열었을 때 "카드별 수량" 칸이 아예 보이지 않고 카드 목록에 "선택"/"장착됨" 표시만 나옴.

## 원인

`src/app.js` `cardChoiceModal()`에서 카드 팝업의 "카드별 수량"(카드마다 −/+ 로 수량을 넣고 "순서대로 장착"하는 기능)을 보여줄지 여부를 `qtyMax>1` 하나로 판단했습니다.

`qtyMax`는 `RtCore.fillTargets(state, slot.id, 999).length`로, "이 슬롯부터 시작해 같은 방향의 **비어 있는** 슬롯까지 몇 칸을 이어서 채울 수 있는가"를 뜻합니다. 이미 있는 카드를 실수로 덮어쓰지 않도록, 다른 슬롯이 이미 차 있으면 그 슬롯은 세지 않습니다.

문제는 프레임의 같은 방향 슬롯이 전부 채워진 뒤에는(예: XDM-12는 입력·출력 각 3슬롯뿐이라 다 채우면) 어느 슬롯을 다시 열어도 "이어서 채울 빈 슬롯"이 0개이므로 `qtyMax`가 항상 1이 됩니다. 이 값 하나로 "수량 UI를 보여줄지"까지 정했기 때문에, 구성을 다 채운 뒤에는 입력·출력 가리지 않고 수량 UI가 통째로 사라지고 카드별 "선택"/"장착됨" 버튼만 남았습니다. 사용자가 입력 카드를 다 채운 뒤 "다시 조정"하려고 열었을 때, 그리고 출력 카드가(슬롯 수가 적어 먼저 다 채워져) 이 상태에 걸렸을 때 각각 겪은 두 현상은 사실 같은 원인이었습니다.

## 수정

- `sameDirTotal`(이 슬롯 방향의 전체 슬롯 수, 채워졌는지와 무관)을 새로 계산해, "카드별 수량" 칸과 카드별 수량 스테퍼, "순서대로 장착" 버튼의 노출 여부는 `sameDirTotal>1`로 판단하도록 바꿨습니다.
- 실제로 몇 장까지 채울 수 있는지 제한하는 `qtyMax`(빈 슬롯 기준, 다른 슬롯의 카드를 덮어쓰지 않음)는 그대로 두어, 이미 다른 슬롯이 다 차 있으면 스테퍼가 "최대 1칸"까지만 허용합니다 — 다른 슬롯을 실수로 덮어쓰는 동작은 추가되지 않았습니다.
- 슬롯이 정말 1개뿐인 방향(예: SPX-M810의 입력 1·출력 1)은 `sameDirTotal===1`이라 수량 UI가 그대로 나타나지 않습니다(기존과 동일).

Playwright로 재현:
1. XDM-12를 선택하고 입력 슬롯 1부터 XDM-HI100 수량 3으로 "순서대로 장착" → 입력 3슬롯 전부 채움.
2. 입력 슬롯 1을 다시 열면(수정 전에는 "카드별 수량" 칸이 사라짐) → 수정 후 "카드별 수량 · 최대 1칸"이 그대로 보임.
3. 출력 슬롯 1도 같은 방식으로 XDM-HOS100 3장을 채운 뒤 다시 열어 같은 결과 확인.
4. SPX-M810(입력·출력 각 1슬롯)에서는 수량 UI가 여전히 나타나지 않음을 확인(회귀 없음).

## 되돌리는 방법

`src/app.js`의 `cardChoiceModal()`에서 `sameDirTotal>1` 조건 3곳(카드별 수량 스테퍼, `qtyBar`, `fillQtyButton`)을 `qtyMax>1`로 되돌리면 이전 동작(구성을 다 채우면 수량 UI가 사라짐)으로 복원됩니다.
