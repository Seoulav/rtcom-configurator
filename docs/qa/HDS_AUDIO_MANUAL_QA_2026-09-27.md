## 2. 판단

- 매뉴얼 7쪽은 추출을 "별도의 세팅 없이" 동작한다고 적었습니다. 사용자 확인에 따라 HD-13U(0.47)와 같이 **병합(딥 스위치 1번 ON, 3.5mm Stereo Audio)과 추출(딥 스위치 1번 OFF, HDMI Embedded Audio) 중 하나를 골라 쓰는 방식**으로 적었습니다.
- 0.43에서 들어간 주요 기능 문장("추출은 이 선택과 무관하게 별도로 동작한다")은 이 사용자 확인과 어긋나서 바꿨습니다.
- EDID 설정 카드(06)의 코드표 12개는 매뉴얼 8쪽 표와 같아서 그대로 두었습니다. 기본값 문구만 매뉴얼 8쪽의 "0번에 두고 전원을 탈착하면 OUTPUT 디스플레이 EDID를 저장"에 맞게 고쳤습니다.
- **HDS-42MU 크기**: 카탈로그 46쪽판 33쪽은 232×80×30mm(3.14in)이고, 매뉴얼 4쪽은 232×65×30mm입니다. 화면 값은 카탈로그 그대로 두고, 조건 칸에 매뉴얼 값을 적었습니다. 제조사 확인 목록(`docs/audit/PRODUCT_ISSUES_ARCHIVE_2026-09-27.md` §7)에 올렸습니다. HDS-21U는 두 자료 모두 160×65×30mm, 0.3kg입니다.

## 3. 변경

- 두 제품에 `audioMux`를 추가해 "07 오디오 설정" 카드를 보여 줍니다.
- 사용자 요청("이럴때는, 연결 삭제해", "좀더 이해하게 쉽게 함축적으로 요약")에 따라 세 제품(HD-13U 포함) 카드에서 "이럴 때"·"연결" 줄을 뺐습니다.
  - HDS 두 제품은 매뉴얼 7쪽 문장을 윗줄 한 문장("딥 스위치 1번 하나로 고른다(ON = 병합, OFF = 추출). 바꾼 뒤 전원 케이블을 한 번 뺐다 꽂으면 적용된다")으로 줄였습니다. 칸마다 "소리가 나오는 곳" 한 줄만 남았습니다.
  - HD-13U는 "소리가 나오는 곳"과 "확인 방법"(LED) 두 줄입니다. HDS는 매뉴얼에 LED 표시가 없어 "확인 방법" 줄이 없습니다.
  - "05 주요 기능"의 HDS 오디오 설명도 두 줄을 한 줄로 줄였습니다.
- 카드 아래 안내: RS-232 볼륨 명령(0.5dB 단위, 뮤트, 매뉴얼 9쪽)
- "02 신호 흐름" 문구: "오디오 병합 또는 추출 중 선택". `audioMux.caption`(새 선택 항목)으로 제품마다 문구를 정합니다. HD-13U는 "오디오 병합(OUT 1) 또는 추출 중 선택"을 유지합니다.
- 주요 기능
  - 선택 방식 한 줄(출처 U)과 요약 한 줄(출처 M1)
  - Priority 딥 스위치 2번 동작(입력 1번 우선, 신호 없으면 자동 전환, M1)
  - HDS-42MU 분배 기능 딥 스위치 3번(출력 1·2번 같은 영상, M1)
- 입출력 표의 오디오 행 조건, 단자 지도 AUDIO IN·OUT 설명에 "MUX·DEMUX 선택 시"를 붙였습니다.
- 매뉴얼을 문서 목록과 출처 M1(4, 6–9쪽)에 등록했습니다.
- "확인 사항"의 작업 기록 I5(0.43)를 0.39 정리 기준대로 뺐습니다.
