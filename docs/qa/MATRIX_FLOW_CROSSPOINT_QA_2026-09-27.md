# 매트릭스 신호 흐름 크로스포인트 QA (0.58.0, 2026-09-27)

## 1. 요청

- "QMS-44 / 88UX 이것도 x:1 선택 후 4분배되는 것처럼 보인다. 이 부분 개선이 필요해. 88에서 보면 너무 복잡해 보일까?"

## 2. 원인

`src/products.js`의 신호 흐름 그림은 입력이 여러 개이면 모든 입력 선을 한 점(매트릭스 상자 가운데)으로 모은 뒤 하나의 대역폭 띠로 출력 패널에 보냅니다. 선택기(n:1)와 모양이 같아서, 매트릭스도 "입력 하나를 골라 모든 출력에 똑같이 보낸다"로 읽혔습니다.

## 3. 바꾼 것

- 매트릭스로 판정되는 제품(`isMatrix`: 일체형 매트릭스이거나 제품 문구에 매트릭스가 있는 제품, 현재 QMS-44UX·QMS-88UX·HDS-42MU)만 바꿨습니다.
- 입력 선은 각 입력 높이 그대로 매트릭스 상자에 들어갑니다(한 점으로 모이지 않음).
- 상자 안에 입력 가로줄 × 출력 세로줄 크로스포인트를 그리고, 위쪽에 출력 번호를 적었습니다.
- 출력마다 입력 하나를 고른 예시 점(보라색)을 찍었습니다. 마지막 출력은 첫 출력과 같은 입력을 골라 "한 입력을 여러 출력에 보내는 것"도 보여줍니다. 상자 위에 "● 선택 예시"를 적어 고정 배선이 아님을 밝혔습니다.
- 출력 캡션을 "독립 출력"에서 "출력마다 입력 선택"으로 바꿨습니다. QMS-88UX의 멀티뷰 9·10번 갈래와 오디오 추출 표시는 그대로입니다.
- 분배기·선택기(HD-210U, HDS-21U 등)는 그대로입니다.

## 4. 88UX 복잡도 판단

8×8은 점 64개이지만 선택 점은 8개뿐이고 나머지는 옅은 회색 점이라, 화면에서는 입력 8줄과 보라 점 8개만 눈에 들어옵니다(`docs/qa/matrix-flow-screens/flow-qms-88ux.png`). 입력 선 64개를 모두 잇는 방식보다 훨씬 단순합니다.
