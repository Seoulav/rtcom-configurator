# HD-13U 오디오 설정 잘림·HD-210U 딥 스위치 설정 QA (0.61.0, 2026-09-27)

## 1. 요청

- "13U 07 오디오가 잘린다. 13U 병합·추출 모두 선택해서 1개만 가능. 210U는 병합만 가능 알지?"(공개 화면 첨부: 07 오디오 설정이 05 아래 좁은 칸에서 추출 칸이 잘리고, 06 EDID보다 위에 있음)
- "210U 매뉴얼을 읽고 DIP 스위치 셋팅을 아까처럼 만들어줘"(0.58.0 HDS 딥 스위치 설정 카드와 같은 방식)

## 2. HD-13U 07 오디오 설정

- 원인: PR #38에서 06 EDID 설정을 전체 폭으로 옮기면서 오디오 설정(`audioMux.modes`)은 05 옆 좁은 칸(sideCard)에 남겼습니다. 병합·추출 두 칸이 약 360px 칸에 나란히 들어가 오른쪽이 잘렸고, 좁은 칸이 전체 폭 카드보다 먼저 나와 07이 06보다 위에 보였습니다.
- 수정: EDID 설정이 있으면 `06 EDID → 07 오디오` 순서로 둘 다 전체 폭 아래에 둡니다. EDID가 없는 제품만 오디오 설정을 05 옆에 붙입니다. 현재 `audioMux.modes`가 있는 제품은 HD-13U 하나입니다.
- 결과(1280px): 오디오 설정 카드 넘침 없음, 카드 순서 01·04·05 | 02·03 | 06·07. 왼쪽 칸(01·04·05)이 오른쪽 칸(02·03·제조사 자료)보다 약 270px 짧아 05 아래에 빈 공간이 생깁니다.
- 동작 방식은 그대로입니다: 병합(MUX)·추출(DEMUX)을 모두 지원하지만 로터리 '0' + SET 버튼으로 하나만 골라 씁니다.

## 3. HD-210U 07 딥 스위치 설정

- 근거: HD-210U 사용자 매뉴얼 Ver.1.2 7쪽 "오디오 병합 및 추출", "DDC Buffer / DDC Level Shifter 선택"(사용자 제공, `sources` 코드 `M-HD210`).

| 번호 | OFF(내림) | ON(올림) |
|---|---|---|
| 1번 오디오 병합 | HDMI Audio(원래 소리)를 모든 출력으로 | 3.5mm Stereo Audio를 모든 출력(OUT 1~10)에 믹스 |
| 2번 DDC 방식 | DDC Buffer 모드 | DDC Level Shifter 모드 |

- 1번 아래 안내: "HD-210U는 병합만 되고, 소리를 따로 빼내는 추출(AUDIO OUT)은 없다."(사용자 확인. 후면에도 AUDIO IN만 있음)
- 2번 아래 안내: "DDC는 소스와 디스플레이가 EDID·HDCP 정보를 주고받는 통신선이다."(용어 설명)
- 그림: 정면 사진(1012×154)의 빨간 MODE 딥 스위치는 레버 3개로 보입니다. 그림은 3개로 그리고 매뉴얼에 있는 1·2번만 설명합니다. 3번 기능은 매뉴얼에 없습니다.
- 매뉴얼에 딥 스위치를 바꾼 뒤 전원을 다시 넣으라는 문장이 없어, HDS 카드의 "전원 케이블 1회 탈착" 안내는 넣지 않았습니다.
- 겹침 정리: 04 제품 사양의 "딥 스위치 1 · 오디오", "딥 스위치 2 · DDC" 행 삭제. 05 주요 기능 두 문장을 "오디오 병합 지원(딥 스위치 1번, 07 딥 스위치 설정 참고)", "DDC Buffer·Level Shifter 선택 지원(딥 스위치 2번)"으로 요약. 06 EDID 설정 설명의 딥 스위치 문장을 "'07 딥 스위치 설정' 참고"로 바꿈.
- 신호 흐름은 그대로 "오디오 병합"만 표시하고 AUDIO OUT이 없습니다.
