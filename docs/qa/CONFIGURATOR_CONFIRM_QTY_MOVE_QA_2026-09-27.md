## 2. 확인 창

- 대상: 제품군·섀시 변경(카드가 있을 때), 새 구성, 파일 불러오기, 로고로 첫 화면 이동. 모두 `src/app.js`에 있습니다. `src/workspace.inc.js`는 `index.html`이 읽지 않는 옛 파일이라 두었습니다.
- 모양: 흐린 배경, 둥근 흰 카드, 원형 아이콘, 제목, 설명, 취소·확인 버튼
  - 아이콘은 초기화처럼 되돌릴 일이 생기는 작업이면 주황 경고, 그 밖에는 파랑 안내입니다.
  - 확인 버튼 글자는 작업에 맞춰 "변경", "새로 시작", "바꾸기", "이동"으로 적었습니다.
- 동작
  - `rtConfirm()`은 Promise를 돌려주고, 호출하는 곳은 `await`으로 결과를 기다립니다.
  - Esc를 누르거나 바깥을 누르면 취소입니다.
  - `<dialog>`를 지원하지 않는 브라우저에서는 기본 확인 창으로 대신합니다.

## 3. 수량 채우기

- 팝업 맨 위의 "수량 − N +"
  - 최대값은 선택한 슬롯에 채울 수 있는 칸 수, 곧 "선택한 슬롯 + 같은 방향 빈 슬롯 수"입니다.
  - 채울 칸이 1칸뿐이면 막대를 보이지 않습니다.
- 채우는 순서(`RtCore.fillTargets`)
  1. 선택한 슬롯
  2. 선택한 슬롯 뒤쪽 번호의 빈 슬롯
  3. 모자라면 앞쪽 번호의 빈 슬롯
  - 이미 카드가 있는 슬롯은 건너뜁니다.
- 채운 칸마다 기본 전송기 연결을 똑같이 붙입니다. 실행 취소 한 번이면 한꺼번에 되돌아갑니다.
- 수량 버튼은 화면만 바꾸고, 실행 취소와 저장 대상이 아닙니다. 팝업을 다시 열면 1로 돌아갑니다.

## 4. 슬롯 이동(`RtCore.moveCard`)

- 입력 슬롯끼리, 출력 슬롯끼리만 옮길 수 있습니다. 방향이 다르거나 빈 슬롯에서 시작하면 아무 일도 일어나지 않습니다.
- 옮길 곳이 비어 있으면 이동하고, 카드나 블랭크가 있으면 서로 맞바꿉니다.
- 전송기 연결(`links`)과 포트 지정(`portAssignments`, `슬롯:포트` 키)도 함께 옮깁니다.
- 방법
  - 마우스: 장착한 슬롯을 끌어 같은 방향 슬롯에 놓습니다. 놓을 수 있는 칸에는 파란 점선이 보입니다.
  - 모든 기기: 장착한 슬롯을 눌러 연 팝업의 "다른 입력(출력) 슬롯으로 이동"에서 목록을 고르고 "이동"을 누릅니다. 목록에는 각 슬롯이 비어 있는지, 맞바꾸게 되는지가 함께 표시됩니다.
- 저장 형식(`rtcom.configuration.v1`, schema 3, 슬롯 ID)은 바뀌지 않습니다. 값만 다른 슬롯 ID로 옮깁니다.

## 6. 참고

사용자 휴대폰 캡처에서 카드 목록 가운데 줄이 납작하게 겹쳐 보인 현상은 Chromium에서 재현되지 않았습니다. 같은 카드(CIS100) 설명이 반복되어 보여서 휴대폰 브라우저의 일시적인 그리기 문제로 봅니다. 다시 보이면 기종과 브라우저를 확인합니다.
