## 그린 기준

- 생성 스크립트: `scripts/tools/draw_xdm_spx_rear_frames.cjs`. 슬롯·나사·RJ45·DB9·IEC 등 부품과 렌더링은 `scripts/tools/draw_vdm_frames.cjs`와 공용입니다(공용화 뒤 VDM 그림 15장이 바이트 단위로 같게 다시 나오는 것을 확인).
- XDM: 회색 금속 몸체, 윗면·전원 위 빗살 통풍구, 오른쪽(XDM-12는 아래 줄) 제어 단자 DANTE(RJ45 2개)·LAN·RS-232·FIRMWARE, 전원 모듈 2개(IEC + 빨간 스위치 + 팬 타공 + 손잡이, 100-240VAC 50/60Hz). 라벨은 매뉴얼 후면 사진 표기를 따랐습니다.
- SPX: 검은 몸체, 제어 단자 LAN·RS232·S/P, 전원(빨간 스위치 + 퓨즈 + IEC). M3236은 좌우 통풍구·손잡이, M2472·M24120은 윗면·아랫면 통풍구와 가운데 "MADE IN KOREA" 판.
- XDM-216: 후면 사진이 없어 XDM-144 모양에 입력·출력 슬롯 줄을 하나씩 더했습니다(입력·출력 각 18칸 × 3줄 = 54슬롯, 카드 비율 약 9.6:1). 캡션은 "후면 그림 · XDM-144 후면 기준"입니다. 실제 후면 배치는 제조사 사진으로 확인이 필요합니다.
- 좌표: 원래 사진 픽셀 좌표계에서 그리고 긴 변 2000px로 렌더링했습니다. `src/app.js` `rearPhotos` 크기·슬롯 영역은 원래 값 × 같은 배율이라 슬롯 위치·비율 검사가 그대로 통과합니다.

## 확인

- 화면: `docs/qa/xdm-spx-rear-art-screens/03-<모델>-slots.png`(XDM-12·36·216, SPX-M810·M3236·M24120). 카드를 장착했을 때 카드 판넬과 슬롯 번호표가 그림 슬롯 칸에 정확히 겹칩니다.
- e2e 검사 추가: XDM 6종·SPX 5종 후면 미리보기가 평면 그림(긴 변 2000px, 대체 문구 "그림"), XDM-216 후면 그림 위 입력 54·출력 54 슬롯.
- 단위 테스트: XDM·SPX -rear-art 11장 참조, rearPhotos 목록에 XDM-216 추가(슬롯 비율 검사 포함).
