# HDS-21U·HDS-42MU 딥 스위치 설정 카드 QA (0.58.0, 2026-09-27)

## 1. 요청

- "42MU 스위치 셋팅 변화를 이런식으로 딥스위치를 만들어서 설정값을 설명하면 어때?"(사용자 제공 딥 스위치 그림과 HDS-42MU 매뉴얼 딥 스위치 1~3번 문단)
- "이게 되면 42MU, 21U에서 07 오디오 설정을 딥스위치 설정으로 변경해서 설명하면 될거같아"

## 2. 바꾼 것

| 위치 | 전 | 후 |
|---|---|---|
| 07 카드 | 오디오 설정(병합·추출 두 칸) | 딥 스위치 설정(스위치 번호마다 OFF·ON 그림과 설명) |
| 04 제품 사양 | "딥 스위치 1 · 오디오", "딥 스위치 2 · Priority", "딥 스위치 3 · 분배"(42MU) | 삭제(07 카드로 이동) |
| 05 주요 기능 | 오디오·Priority 긴 문장, 42MU는 오디오 문장 2줄 | 한 줄 요약. 42MU는 "출력 1·2번 분배 지원(딥 스위치 3번)" 추가 |
| 03 단자 지도 7번 MODE | "딥 스위치 4개" | "딥 스위치 3개", 설정은 07 카드 참고 |
| 02 신호 흐름 | "오디오 병합 또는 추출 중 선택" | 그대로 |

- 그림: 제품 사진과 같은 빨간 몸체에 스위치 3개를 그리고, 설명하는 번호만 흰 레버로 또렷하게 그립니다. 위쪽이 ON입니다.
- 스위치 개수: 두 제품 모두 정면 사진을 확대해 레버 3개를 확인했습니다. HDS-21U 매뉴얼은 1·2번만 설명하므로 카드에도 1·2번만 적었습니다. 3번 스위치의 기능은 사용자 확인이 필요합니다. → 0.64.0에서 해소(§6).
- 카드 아래 안내: "스위치를 바꾼 뒤 전원 케이블을 한 번 뺐다 꽂아야 적용된다."와 기존 오디오 설정 카드의 볼륨(RS-232) 안내를 옮겨 적었습니다.

- 실크 표기: HDS-42MU 실물 실크가 잘못 인쇄되어(파란 로터리 아래 "MODE", 빨간 딥 스위치 아래 "EDID") 사진도 그렇게 찍혀 있었습니다. 사용자 확인(2026-09-27)에 따라 사진 속 두 글자 영역(x 316~348·365~397, y 110~125, 원본 px)을 서로 바꿨습니다. 대상은 `output/design/assets/products/hds-42mu-front.webp`, `hds-42mu-front-rear.webp`(WebP 품질 0.95로 다시 저장)입니다. 카드 머리글은 "전면 MODE 딥 스위치"입니다. 되돌리려면 두 사진 파일만 이전 커밋에서 되살리면 됩니다(`git checkout <이전 커밋> -- <파일>`).

## 3. 데이터 형식

`dipSwitch`: `label`, `count`(1~12), `onUp`, `source`(sources 코드), `rows[]`(`n`, `title`, `off{name,text}`, `on{name,text}`, `note`), `apply`, `note`. `scripts/build-product-index.cjs`가 번호 범위·중복·빈 문자열을 검사합니다. `audioMux`는 신호 흐름 표시에 필요한 `mode`·`source`만 남겼고, `modes`가 없으면 07 오디오 설정 카드는 그리지 않습니다(HD-13U는 그대로).

## 6. 후속: HDS-21U 3번 스위치(0.64.0)

- 사용자 확인(2026-09-27): "HDS-21U와 42MU의 딥스위치는 동일해".
- HDS-21U `dipSwitch.rows`에 HDS-42MU와 같은 3번 분배 행(OFF 출력별 선택 / ON 출력 1·2번 같은 영상)을 넣었습니다. 행 안내: "HDS-42MU와 같은 딥 스위치다. HDS-21U는 HDMI 출력이 1개다."(화면에는 출처 표기를 넣지 않음, 0.52 기준) HDS-21U에서 분배 스위치가 실제로 무엇을 바꾸는지는 매뉴얼에 없어 적지 않았습니다.
- HDS-21U 매뉴얼 Ver.1.0은 1·2번만 설명합니다(HDS-42MU 매뉴얼 Ver.1.0 "화면분배기능 설정(Distributor)" 문단이 3번 근거). 출처 `U` 범위에 "딥 스위치 1~3번은 HDS-42MU와 동일"을 더했습니다.
- 05 주요 기능에는 분배 줄을 넣지 않았습니다(HDMI 출력 1개 제품이라 오해 방지).
- 단자 지도 7번 MODE 설명: "1번 오디오 병합·추출, 2번 Priority, 3번 분배, HDS-42MU와 같음".
- e2e 기대값: HDS-21U 딥 스위치 행 2 → 3, 그림 4 → 6.
- 되돌리기: 해당 커밋을 `git revert`합니다.
