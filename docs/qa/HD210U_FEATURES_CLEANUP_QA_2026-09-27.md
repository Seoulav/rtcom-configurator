## 2-1. HD-13U(추가 요청 "13U도 동일하게 압축 요약해줘")

| 전 | 후 |
|---|---|
| HDMI 2.0, HDCP 2.2 지원 | HDMI 2.0, HDCP 2.2 지원 |
| EDID 마인더 기능: 외부 연결된 디스플레이 EDID 저장, 내부 저장된 EDID 사용 | 오디오 병합·추출 선택 지원(둘 중 하나만 사용) |
| 오디오는 로터리 '0'+SET 버튼으로 병합(Stereo Audio, 3.5mm 소리를 OUTPUT 1에 믹스)과 추출(HDMI Audio, 입력 소리를 AUDIO OUT으로)을 번갈아 고른다. 자세한 표는 '07 오디오 설정' 참고. | EDID 마인더 기능 지원(외부 EDID 저장, 내장 EDID 선택) |

- 조작 방법(로터리 '0' + SET, OUT 1 LED 확인)과 병합·추출이 나가는 곳은 07 오디오 설정 카드에만 둡니다. "둘 중 하나만 사용"은 사용자 확인(`U`) 근거입니다.

## 2-2. HDS-21U·HDS-42MU 딥 스위치 칸 좌우 바꿈(추가 요청 "21U, 42MU 딥스위치 값 서로 좌우 위치 변경해줘")
