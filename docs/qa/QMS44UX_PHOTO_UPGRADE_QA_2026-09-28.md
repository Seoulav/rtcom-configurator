# QMS-44UX 전면·후면 사진 고화질 교체 + 단자 지도 재보정 QA (2026-09-28)

## 배경

사용자가 QMS-44UX 전면 사진(선명한 실물 촬영)을 채팅에 올렸고, 이어서 같은 각도의 후면 사진도 보내주었습니다. 두 사진 모두 사용자가 직접 촬영한 사진임을 확인했습니다(사용자 답변: "직접 촬영한 사진"). 기존 사이트 사진(카탈로그 스캔, 전면 938×129px·후면 938×104px)은 흐릿해서 버튼·단자 글자를 읽기 어려웠습니다.

## 변경 내용

### 1. 사진 파일 교체

`output/design/assets/products/qms-44ux-front.webp`, `qms-44ux-rear.webp`를 사용자 제공 사진으로 교체했습니다.

- 전면: 938×129 → 2000×273
- 후면: 938×104 → 2000×220

두 사진 모두 기존 사진과 가로:세로 비율이 거의 같아(전면 7.27:1 → 7.33:1, 후면 9.02:1 → 9.09:1) 같은 각도·구도로 촬영된 것으로 보입니다.

### 2. `data/products/qms-44ux.json` 메타데이터

- `images[Front]`·`images[Rear]`의 `resolution`을 새 픽셀 크기로 갱신하고, `note`에 "실물 직접 촬영 사진"이라고 밝혔습니다.
- `source`를 기존 "C"(카탈로그)에서 새로 추가한 "P1"(실물 직접 촬영, 사용자 제공)로 바꾸고 `officialSource`를 `false`로 정정했습니다(제조사 공식 자료가 아니라 사용자가 촬영한 사진이므로). `sources` 배열에 `P1` 코드를 추가했습니다.

### 3. 03 단자 지도(Port Map) 좌표 재보정

기존 좌표(카탈로그 사진 938px 기준)는 새 사진(2000px)에 그대로 쓸 수 없어, 새 사진에 격자(50px 간격)를 겹쳐 그려 각 단자의 실제 픽셀 위치를 다시 측정했습니다(방법: Python Pillow로 격자 이미지를 만들고 구간별로 잘라서 확인).

| 번호 | 항목 | 이전(938px 기준) | 새 좌표(2000px 기준) |
|---|---|---|---|
| 1 | INPUT 1–4 | 285–545 | 640–1200 |
| 2 | OUTPUT 1–4 | 615–882 | 1285–1805 |
| 3 | RS-232C | 124–194 | 270–390 |
| 4 | LAN | 206–247 | 445–540 |
| 5 | DOWNLOAD(신규) | (없음) | 160–215 |
| 6 | DC 12V | 40–75(기존 5번) | 50–150 |

### 4. DOWNLOAD 포트 신규 확인

새 후면 사진에서 "+12V DC"와 "RS232C" 사이에 실크 인쇄로 "DOWNLOAD"라고 적힌 Mini-USB(B타입) 포트를 확인했습니다. 기존 카탈로그 사진은 해상도가 낮아 이 글자를 읽을 수 없어 단자 지도에 없었습니다. 번호 규칙(HDMI 입력 → 출력 → 오디오 → 전송 → 제어 → 표시·조작 → 전원 마지막)에 따라 RS-232C·LAN(제어) 다음, DC 12V(전원) 앞인 5번으로 넣었습니다.

**확인 필요**: 이 포트의 정확한 용도(펌웨어 업데이트 등)는 매뉴얼 원문으로 대조하지 않았습니다. `desc`에 "실물 촬영으로 확인, 매뉴얼 대조 전"이라고 적어 두었습니다. QMS-44UX 사용자 매뉴얼(KV.04, `sources`의 "M-Q44")을 나중에 확인해 정확한 기능으로 정정할 수 있습니다.
