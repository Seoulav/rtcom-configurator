`build-product-index.cjs --check`가 확인하는 항목:
- 필수 필드와 id·파일명 일치
- group·itemType·packageStatus 값
- 검토 필요 항목이 있으면 packageStatus도 REVIEW REQUIRED인지
- 제외 모델 없음, 내부 정보 금지어 없음
- 이미지 파일 존재, related 대상 존재, 출처 코드 정의

## 화면 확인 (1366px 데스크톱 / 390px 휴대폰)
- 목록: 데스크톱 4열, 휴대폰 2열. 분류 탭은 휴대폰에서 가로로 밀어서 봅니다.
- 상세
  - 데스크톱: 사진과 제목이 두 칸으로 나뉩니다.
  - 휴대폰: 한 칸으로 쌓이고, 사양 표는 행마다 "분류·항목·값·조건"을 세로로 보여 줍니다.
- 화면 가로 스크롤: 모든 경우 0입니다.
- 화면 확인에서 발견해 고친 것
  - 제목 영역 좌우 여백 없음
  - 제목에 포커스 테두리가 보임
  - 같은 관련 제품이 두 번 표시됨 → 한 번만 표시
  - 짝 제품 RX 사진 캡션이 "Perspective 자리"로 보임 → RX 사진은 role `Other`로 바꿈
  - 휴대폰 사양 표가 좁게 눌림
