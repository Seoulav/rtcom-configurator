# HD-108U 전면·후면 사진 고화질 교체 + 단자 지도·EDID 로터리 재보정 QA (2026-09-28)

## 배경

사용자가 QMS-44UX 사진 교체 작업(`docs/qa/QMS44UX_PHOTO_UPGRADE_QA_2026-09-28.md`)에 이어 HD-108U 전면·후면 사진(흰 배경, 정사각 2000×2000 스튜디오 컷)을 보내주었습니다. 사진 출처를 확인한 결과 "제조사에서 입수"한 공식 이미지입니다(QMS-44UX의 실물 촬영 사진과는 출처가 다름).

## 변경 내용

### 1. 사진 파일 가공·교체

원본은 흰 배경 위에 제품이 떠 있는 2000×2000 정사각 이미지라, 사이트의 기존 스타일(제품 실루엣에 맞춰 가로로 길게 자른 사진)에 맞춰 다음 순서로 가공했습니다.

1. 흰 배경(비-흰색 픽셀 기준) 바운딩 박스를 찾아 여백 20px만 남기고 잘라냄(전면 1368×196, 후면 1352×197).
2. 폭 2000px로 통일해 비율 유지 리사이즈(전면 2000×287, 후면 2000×291).
3. 03 단자 지도용 합성 사진(위 전면·아래 후면)을 새로 제작: 위 여백 20px, 전면, 간격 100px, 후면, 아래 여백 20px → 2000×718.

`output/design/assets/products/hd-108u-front.webp`, `hd-108u-rear.webp`, `hd-108u-front-rear.webp` 3개 파일을 교체했습니다.

- 전면: 1012×154 → 2000×287
- 후면: 1016×160 → 2000×291
- 합성(단자 지도용): 1016×394 → 2000×718

### 2. `data/products/hd-108u.json` 메타데이터

- `images[Front]`·`images[Rear]`·`images[Other]`의 `resolution`을 새 크기로 갱신하고 `note`에 "제조사 제공 고화질 이미지"라고 밝혔습니다.
- `source`를 "C"(카탈로그)에서 새로 추가한 "I1"(제조사 제공 고화질 이미지)로 바꿨습니다. `officialSource`는 계속 `true`(제조사 공식 자료 맞음, 카탈로그 스캔이 아닐 뿐).
- `sources` 배열에 `I1` 코드를 추가했습니다.

### 3. 03 단자 지도(Port Map) 재보정

새 합성 사진(2000×718, 전면 y 20–307 / 후면 y 407–698)에 격자를 겹쳐 그려 각 단자의 실제 픽셀 위치를 다시 측정했습니다.

| 번호 | 항목 | 대상 사진 | 이전(구 사진 기준) | 새 좌표 |
|---|---|---|---|---|
| 1 | HDMI IN | 후면(y=400) | x 98–158 | x 1630–1720 |
| 2 | HDMI OUT 1–8 | 후면(y=400) | x 189–892 | x 200–1545 |
| 3 | EDID | 전면(y=0) | x 783–817 | x 1510–1600 |
| 4 | DC 12V | 후면(y=400) | x 928–962 | x 1820–1910 |

**참고**: 새 후면 사진은 기존 카탈로그 사진과 좌우가 반대로 찍혀 있습니다(기존: HDMI IN이 왼쪽 끝 → OUT1~8 → DC 12V 오른쪽 끝, 새 사진: OUT8~1 → HDMI IN → DC 12V 오른쪽 끝). 실측으로 좌표를 새로 잡았으므로 문제 없습니다.

### 4. 06 EDID 설정 카드 — `edidSwitch` 좌표 재보정

`edidSwitch`는 03 단자 지도와 달리 **전면 단독 사진**(`images[Front]`, 2000×287) 좌표계를 씁니다. 같은 격자 측정으로 로터리 스위치 강조 상자를 다시 잡았습니다.

- 이전(1012×154 기준): x1=783, y1=48, x2=817, y2=85
- 새 좌표(2000×287 기준): x1=1518, y1=108, x2=1595, y2=187
