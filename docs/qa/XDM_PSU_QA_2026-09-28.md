# XDM-PSU(16채널 모듈형 전원 장치) 반영 QA (0.72.0 준비, 2026-09-28)

## 1. 요청·결정

- 사용자: "XDM CIS COS를 통해서 CTR100 전원을 주려면 별도 장치가 필요해. 이거 보고 이해 가능할까?"(XDM-POE ASSY 도면 PDF, MAX2 표기 구성도·모듈 사진 제공)
- 사용자 결정(추천안 채택):
  - 모델명: **XDM-PSU / XDM-POH / XDM-PHX**
  - XDM-POH는 **CTR100(Tx) 1대당 1개**, XDM-PHX는 **COS100 카드 1장당 1개**
  - XDM-PSU를 쓰면 **CTR100 개별 전원 불필요**
  - XDM-CT103/CR103은 제조사 확인 전까지 지금 표기 그대로
  - XDM-PSU 제품정보 페이지 추가

## 2. 근거

- `XDM-POE2U_030_ASSY.pdf`(도명 XDM-POE, 도번 ALT-XDM POE-000_V10, 2024.07.23, `.source-materials/`, git·배포 제외): 정면 "XDM-PSU 16 Channel Modular Power Supply System for XDM Extenders"·채널 LED 1~16, 후면 모듈 16칸(POH "CIS Card/Extender" RJ45 2개 × 8, PHX "COS Card" 2핀 +/− × 8 예시), AC 100~240V 50~60Hz, 19인치(482.6) 2U(88.1) × 깊이 250(본체 폭 430).
- 사용자 제공 구성도(MAX2-20X Frame): CIS100 → CAT → PSU RJ45 → CAT → CTR100 Tx, PSU → 2 Pin Power Cable → COS100 → CAT → CTR100 Rx, "Customizable up to 16 ports". 모듈 사진 실크는 MAX2-POH(CIS Card·Extender)·MAX2-PHX(COS Card +/−).
