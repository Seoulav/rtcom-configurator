# 송신기·수신기 라벨 색상 구분 QA (2026-09-28)

## 배경

사용자가 FT103-U-H/FR103-U 제품 상세 "02 PORT MAP"의 "송신기 FT103-U-H" 라벨(흰 배경 흰 카드 위 검은 글자)이 눈에 띄지 않는다며 색을 넣어 구분해 달라고 요청했습니다. 색상 기준을 확인한 결과 "송신기=파랑, 수신기=주황"으로 확정했습니다(구성기 슬롯 번호표의 입력 파랑(#007AFF)·출력 주황(#E8590C)과 같은 색).

1차로 제목이 "송신기"·"수신기"로 **시작하는** 9종(18곳)만 반영했는데, 사용자가 "모든 제품을 그렇게 해줘"라고 다시 요청해 전체 제품 데이터를 훑어보니 XDM-FT101/FR101 1종이 빠져 있었습니다. 이 제품은 송신기(FT101)·수신기(FR101) 사진이 따로 있지 않고, 송신기 앞면·뒷면만 합친 사진 한 장에 제목이 "위 앞면(송신기), 아래 뒷면"으로 되어 있어(문장 **중간**에 "송신기") `startsWith` 검사에 걸리지 않았습니다. 검사 방식을 `includes`로 넓혀 반영했습니다(같은 제목 안에 "송신기"·"수신기"가 함께 들어간 경우는 없음을 전체 데이터로 확인).

## 영향 범위

`src/products.js`의 `portMapBlock()`이 `map.title`이 있을 때(송신기/수신기 사진이 있는 화면) 그리는 `<span class="rt-pg-on">` 라벨에, 제목에 "송신기"가 들어 있으면 `rt-pg-on-tx`, "수신기"가 들어 있으면 `rt-pg-on-rx` 클래스를 추가로 붙였습니다. 같은 `rt-pg-on` 클래스를 쓰는 "정면/후면" 전환 버튼(`<button>` 요소, `map.title`이 없는 화면)은 셀렉터가 `span.rt-pg-on-tx`/`span.rt-pg-on-rx`라 영향받지 않습니다.

`map.title`에 "송신기"·"수신기"가 들어간 제품 10종(19곳):

- 송신기·수신기 라벨이 한 쌍씩(9종 18곳): ft101-u-fr101-u, ft103-u-h-fr103-u, ct101-u-cr101-u, ct103-u-h-cr103-u, ct104-u-cr104-u, xdm-ct103-cr103, obux-1c, obhd-2c, spx-rx-tx
- "송신기"만 문장 중간에 들어간 라벨 하나(1종 1곳): xdm-ft101-fr101
