# EDID 로터리 대표 설정 그림 QA (0.59.0, 2026-09-27)

## 1. 요청

- "EDID 로터리 스위치도 대표적인 것을 DIP 스위치처럼 예상 이미지 만들어 봐줘"(0.58.0 딥 스위치 설정 카드에 이어서)

## 2. 바꾼 것

- `src/products.js`에 `rotaryGraphic(code)`와 `edidExamples(es)`를 추가했습니다. EDID 설정 카드의 설명·기본값 아래, 설정 방법(외부·내부 EDID) 위에 그림 줄을 넣었습니다.
- 그림: 제품 사진과 같은 파란 로터리입니다. 둘레에 0~F 16칸 눈금과 글자를 두고, 가운데 손잡이의 화살표가 고른 코드를 가리킵니다. 0이 위쪽이고 시계 방향으로 커집니다. 고른 글자는 파란 원 안에 흰 글자로 표시합니다.
- 보여주는 코드: `edidSwitch.default`의 앞 글자(기본값)와 `table[].highlight`가 켜진 코드를 코드표 순서대로, 최대 4개까지 보여줍니다. 기본값 그림은 파란 테두리와 "기본값" 표시로 구분합니다.
- 실물의 눈금 방향과 글자 배치는 사진이 작아 확인하지 못했습니다. 그래서 그림은 "예상 이미지"이고, 코드와 기능은 매뉴얼 코드표 그대로입니다.

| 제품 | 그림으로 보여주는 코드 | 비고 |
|---|---|---|
| HD-13U·HD-104U·HD-108U·HD-210U | 기본값 + 1·7번 | 0.41.0 강조 그대로 |
| HDS-21U·HDS-42MU | 0(기본값)·3·9번 | 이번에 3·9번 강조 추가(1080p60·4K60 PCM 2CH) |
| FT103-U-H/FR103-U | 0(기본값)·3·6번 | 이번에 3·6번 강조 추가(1080p60·4K30 PCM 2CH, 최대 해상도 4K30) |
