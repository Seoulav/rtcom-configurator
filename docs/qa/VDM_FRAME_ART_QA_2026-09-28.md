## 그린 기준

- 몸체 색: VDM-16X·VDM-48X 실물 사진처럼 검은 몸체로 그려, 사진이 있는 모델과 목록에서 어울리게 했습니다.
- 전면(매뉴얼 1.4 Front View): 7" LCD 터치 스크린, 전원 On/Off 스위치, 접이식 핸들. 로고·모델명·문구 배치는 VDM-16X 실물 사진과 각 모델 매뉴얼 전면 도면을 따랐습니다. 80X·180X는 위 제어 모듈 + 아래 통풍 판 구조입니다.
- 후면(매뉴얼 1.5 Rear View, 2.2 Router Frame Specifications pp.12–20):
  - 입력·출력 카드 슬롯(빈 블랭크 판넬 + 손나사). 칸 수는 구성기 슬롯 수(8X 2/2 … 256X 64/64)와 같습니다.
  - 오디오 매트릭스 라우터(5핀 피닉스 줄): 16X~64X는 가운데 세로 칸, 80X 이상은 입력·출력 사이 띠(냉각 팬과 함께).
  - 통신 단자: HDMI·LAN·REMOTE(RS-232)·FIRMWARE(USB), 라벨은 VDM-16X 실물 사진 기준. 80X·128X·256X는 남는 슬롯 칸, 180X는 오른쪽 세로 판.
  - 전원: 이중화 IEC 인렛(100-240VAC 50/60Hz). VDM-8X는 매뉴얼 사양대로 외부 DC 12V 입력 2개입니다.
- 좌표: 원래 도면 픽셀 좌표계(viewBox)에서 그리고 긴 변 2000px로 렌더링했습니다. `src/app.js` `rearPhotos`의 크기·슬롯 영역은 원래 값에 같은 배율을 곱한 값이라 슬롯 위치와 비율 검사(`tests/site.test.cjs`)는 그대로 통과합니다. 스크립트를 실행하면 새 좌표를 출력합니다.
