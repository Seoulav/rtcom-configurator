HD-210U는 HDMI 신호용 고성능 분배기입니다.

True HDMI 2.0 3840x2160p 60Hz 4:4:4를 지원하며, 두 개의 입력 중 하나를 선택해 신호 손실 없이 10개의 동일한 출력으로 분배합니다. HDCP·EDID를 완벽 지원해 호환 이슈 없이 사용할 수 있고, 외부·내부 EDID를 쓰는 EDID 마인더 기능과 아날로그 오디오 병합 기능을 지원합니다.

주요 기능

  • HDMI 2.0, HDCP 2.2 지원
  • EDID 마인더: 외부 디스플레이 EDID 저장, 내부 EDID 사용
  • 아날로그 오디오 병합(AUDIO IN)
