## 1. 한국어 응답을 시스템으로 강제

### 요청

- 사용자 지시 2026-10-12: "제발 한글로 설명해줘 이건 너무 자주 어긴다."
- 이어서 "한국어 규칙을 시스템으로 강제하기 진행해"라고 지시했습니다.
- CLAUDE.md에는 0.185부터 "처리 과정은 반드시 한국어로"가 있었습니다. 그런데 PR 알림 확인이나 배포 확인 같은 짧은 안내를 영어로 쓰는 일이 반복되었습니다.

### 처리 (`.claude/settings.json`, `scripts/korean-reply-hook.cjs`)

| 장치 | 동작 |
|---|---|
| `language: "korean"` | Claude Code의 응답 언어 설정입니다. 세션에 "항상 한국어로 답할 것" 지시가 들어갑니다. |
| UserPromptSubmit 훅 | 사용자가 요청을 보낼 때마다 "보이는 모든 글(중간 안내·알림 확인·질문·최종 보고)은 한국어로" 알림을 모델 문맥에 넣습니다. |
| Stop 훅 | 답변을 끝내기 직전에 마지막 답변의 한글 비율을 잽니다. 대부분 영어면 `decision: block`으로 끝내지 못하게 하고 "같은 내용을 한국어로 다시 작성" 사유를 돌려줍니다. |

- **영어 판정:** 다음 항목은 영어 글자로 세지 않습니다.
  - 코드 블록, 인라인 코드, 주소, 파일 경로
  - 숫자가 섞인 낱말(모델명 `XDM-WOS100` 등), 대문자 약어(`HDMI`·`PR` 등)

  남은 글에서 영어 글자가 40자 이상이고 한글 ÷ (한글 + 영어)가 35% 미만이면 영어 답변으로 봅니다.
- **마지막 답변 찾기:** 대화 기록(JSONL) 끝 4MB를 읽어, 마지막 사용자 입력 뒤에 나온 가장 마지막 답변 글을 봅니다. PR 알림 같은 시스템 알림도 사용자 입력 칸으로 들어오므로, 알림 처리 턴도 검사합니다.
- **무한 반복 방지:** 다시 쓰는 중(`stop_hook_active`)에는 막지 않습니다. 훅 오류나 잘못된 입력은 조용히 넘어가 세션을 막지 않습니다.
- **CLAUDE.md 보강:** "사용자에게 설명하는 방법"의 한국어 규칙 항목에 이 장치를 적었습니다. `DEVICE_WORKFLOW.md`의 설정 안내에도 한 줄을 더했습니다.

### 시험

- 파이프 시험(훅에 직접 입력을 넣어 보는 시험) 결과는 다음과 같습니다.
  - 영어 답변은 막았습니다(한글 비율 0%).
  - 모델명이 섞인 한국어 답변과 짧은 혼용 답변은 통과했습니다.
  - `stop_hook_active` 상태와 잘못된 입력에서는 아무것도 하지 않았습니다.
  - 이 세션의 실제 대화 기록에서는 통과했습니다.
- `tests/korean-reply-hook.test.cjs` 5개 항목도 확인합니다(판정, 코드·경로 제외, Stop 범위와 반복 방지, 알림, 설정 연결).

### 한계

- Stop 훅은 마지막 답변만 봅니다. 도구 사이의 중간 안내는 UserPromptSubmit 알림과 `language` 설정에 기댑니다.
- 로컬 PC에서는 폴더 설정을 신뢰해야 훅이 켜집니다(`DEVICE_WORKFLOW.md`).

## 2. HOS100 멀티뷰 분할 예시를 QMS-88UX와 같은 모니터 그림으로

### 요청

사용자 요청 2026-10-12: "분할 구성예시를 QMS-88UX 분할예시와 같은 디자인 컨셉으로 진행해줘"

### 처리

- `src/products.js`의 06 화면 구성 모드 한 화면 분할 그림을 `monitorLayoutSvg(cells, opts)`로 떼어 냈습니다. 이 그림은 다음 요소로 그립니다.
  - 모니터 200×134, 검은 베젤, 스탠드
  - 입력별 색 그러데이션 화면, 흰 테두리, 산 무늬, 번호
  - 칸이 덮지 않는 곳은 검은 여백
- 떼어 낸 함수는 `globalThis.RtMonitorLayoutSvg`로 내보냅니다.
  - QMS 06의 `layoutShapeSvg`가 이 함수를 그대로 부르므로 QMS 그림 결과는 같습니다(칸 클래스 `rt-pg-cell`, e2e 칸 수 검사 유지).
  - `opts.labels`(번호 대신 쓸 글자)와 `opts.cellClass`(칸 클래스)를 더했습니다.
- `src/app.js` HOS100 팝업의 레이아웃 6종을 화면 0~100 좌표로 바꾸고 이 함수로 그립니다(칸 클래스 `rt-hos-cell`).
  - Full 1~4는 "1~4" 글자로 표시합니다.
  - Bottom·Right는 매뉴얼 KV08 33~34쪽처럼 큰 화면 양옆·위아래에 검은 여백을 둡니다.
  - 포트 표시(분할/불가/1번 동일)와 짝 포트 안내는 0.205 그대로입니다.
- e2e HOS 항목에 모니터 그림 6장과 칸 17개 검사를 더했습니다.

화면: `docs/qa/korean-hook-hos-monitor-0.206/hos-multiview-monitor-1280.webp`·`-390.webp`
