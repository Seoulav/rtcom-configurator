# 03 카드 슬롯: 신호 배지와 내 구성 한 줄 요약 (0.167.0)

## 요청과 결정

- 사용자 요청 2026-09-29: "카드 정보쪽에 슬롯마다 좀 더 색상이 있어서 구분감이 있으면 좋겠고, 내 구성 탭에는 수량이 좀 더 눈에 띄게 해주거나 그냥 모델명(HDMI) X 수량만 나오면 좋겠어".
- 첫 시험(타일 배경·윗줄·글자·수량을 모두 신호 색으로 칠함)에 대한 사용자 평가: "디자인은 별로인대 구분감은 있다". 사용자가 보여 준 외부 시안(왼쪽 카드 트레이, 신호 배지, 채널 번호)을 바탕으로 시안 A(색 체계 정리)·B(카드 트레이)·C(설계 정보 보강)를 실제 화면에 덧입혀 비교했습니다(`docs/qa/card-signal-badge-0.167/mock-A.png`·`mock-B.png`·`mock-C.png`).
- 사용자 선택: 시안 A("이거 좋다한번 해보자"). B·C는 보류입니다.

## 원칙

색은 작은 신호 배지 하나에만 씁니다. 같은 배지를 카드 목록, 후면 장착 슬롯, 범례, 내 구성에 반복해 한 번 익히면 어디서든 같은 뜻으로 읽히게 합니다. 나머지(타일 바탕, 글자)는 흰색·회색으로 둡니다.

| 신호 | 배지 | 색 |
|---|---|---|
| HDMI | `HDMI` | #2f6fe0 |
| DisplayPort | `DP` | #7c4ddb |
| HDBaseT | `HDBT` | #15924a |
| CATx(SPX) | `CATx` | #15924a |
| 광 전송 | `FIBER` | #0a8aa6 |
| SDI(12G, 3G/HD) | `SDI` | #d0384f |

신호는 카탈로그 신호 표기(`RtCatalog` 카드 두 번째 값)의 첫 단어로 나눕니다(`signalKind`).

## 구현 위치

- `src/app.js`
  - `signalShort`·`signalKind`·`signalAbbr`·`sigBadge`: 배지 HTML.
  - `signalLegend()`: 후면 상태 범례 아래, 지금 제품군에 있는 신호만 카탈로그 표기로.
  - `slotRanges()`: 내 구성 장착 위치를 이어진 구간으로 줄임(예: `IN 1–4·7`).
  - `cardInfoBar()`: 판넬 타일·글자 버튼의 모델명 앞에 배지.
  - `slotButton`: 장착 슬롯 판넬 위에 `.rt-slot-sig` 배지.
  - `configurationSummary()`: 카드 행을 "배지 · 모델명 · 장착 위치 · × N"으로.
- `src/styles.css`: `[data-sig]` 색 변수, `.rt-sig-badge`, `.rt-sig-legend`, `.rt-slot-sig`(슬롯 container 크기에 맞춰 `cqh`·`cqw`로 줄이고, 세로 슬롯은 아래쪽 세로 글자, 높이 13px 이하 슬롯은 숨김), 흰 바탕 `.rt-palette-tile`, 한 줄 `.rt-summary-card`.
- 저장 형식(`rtcom.configuration.v1`, schema 3)은 바꾸지 않았습니다.

- `node scripts/e2e-smoke.cjs` 207/207 통과.
  - 새 검사: 배지 색이 신호마다 다르고 타일 바탕은 흰색, 후면 장착 슬롯·범례(`HDMI,DP,HDBT,FIBER,SDI`)·내 구성 행(`HDMI XDM-HOS100 OUT 1 × 1`)에 같은 배지.
