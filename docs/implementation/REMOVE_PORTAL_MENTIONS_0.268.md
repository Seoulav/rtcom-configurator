# 0.268.0 공개 사이트의 AV Portal 언급 제거 (2026-11-16)

## 1. 요청과 원인

- 사용자 요청 2026-11-16: "알티컴 사이트에서 av포탈 연결되거나 언급되지 않게 전부 지워줘. 알티컴 사이트를 경쟁업체까지 오픈할 계획이야."
- 0.264에서 머리의 "AV Portal에서 제품 찾기" 링크는 이미 지웠지만, 화면 문구와 공개 소스 주석에 AV Portal 언급이 남아 있었습니다. 공개 사이트는 `dist/`만 배포하므로 `dist/`의 텍스트 파일을 전수 검색했습니다(`portal`·`포탈`·`포털`, 대소문자 무시).

## 2. 찾은 곳과 바꾼 내용

| 파일 | 종류 | 이전 | 이후 |
|---|---|---|---|
| `src/app.js` XDM 레이어 비교 팝업 표 | 화면에 보임(출처 칸 10행) | `AV Portal` | `제조사 데이터시트` |
| `src/app.js` 같은 표 RS4 행 비고 | 화면에 보임 | `… · 구성기·AV Portal 미등록` | 이 비고를 삭제 |
| `src/app.js` 팝업 하단 출처 문구 | 화면에 보임 | `AV Portal 제품 상세(Analog Way·NovaStar·Colorlight·Magnimage)` | `각 제조사 데이터시트(…)` |
| `src/app.js` 주석 | 공개 소스 | "AV Portal 상세 페이지(제조사 데이터시트 근거)" | "각 제조사 데이터시트" |
| `src/products.js` 주석 3곳 | 공개 소스 | "AV Portal 상세 JSON 호환…비공개 AV Portal은 이 파일을 읽기만 한다", "AV Portal 검토안", "AV Portal 공통 렌더러 검토안 반영" | 해당 문구 삭제(데이터 형식 `rtcom.products.v1`만 적음) |
| `src/styles.css` 주석 2곳 | 공개 소스 | "AV Portal 링크를 지움" 및 사용자 말 인용, "PHASE 1 portal shell" | "외부 링크를 지움", "PHASE 1 app shell" |

- 제품 데이터 JSON(`data/products/`)과 `index.html`에는 언급이 없었습니다.
- 레이어 비교 표의 값 자체(경쟁사 레이어 수 등)는 그대로이고 출처 이름만 제조사 데이터시트로 바꿨습니다. 이 값은 제조사 데이터시트에서 가져온 것이라(0.203 근거 주석) 출처 표기가 사실과 같습니다.

## 3. 바꾸지 않은 것(범위 밖, 사용자 판단 필요)

- **저장소 내부 문서**: `docs/`, `CLAUDE.md`, `README.md`, `CHANGELOG.md`, `scripts/` 주석에는 AV Portal 언급이 많습니다(예: `docs/handoff/AV_PORTAL_*.md`). 이 파일들은 공개 사이트(`dist/`)에 올라가지 않아 이번에 두지 않았습니다. 다만 GitHub 저장소 자체가 경쟁업체에 공개 상태이면 문서로 읽힙니다.
- **AV 빌더 연동**: 구성기 04의 "AV 빌더에서 바로 열기"·구성 파일 내려받기(0.173·0.174)는 AV Portal이 아니라 별도 도구(AV System Builder)로 가는 링크이고 화면에 보입니다. 이번 요청("av포탈")에 포함하지 않았습니다.
- **데이터 계약**: 제품 데이터 JSON의 모양(`rtcom.products.v1`)은 그대로입니다. 비공개 AV Portal이 공개 데이터를 읽는 동작은 영향이 없습니다.

## 4. 재발 방지

- `tests/site.test.cjs`에 시험을 더했습니다. 배포본(`dist/`)을 새로 만들어 `.html·.js·.css·.json·.svg·.txt·.md·.xml` 파일에 `portal`·`포탈`·`포털`이 한 번이라도 나오면 실패합니다. 레이어 비교 표의 출처 칸이 "제조사 데이터시트"로 적혀 있는지도 확인합니다.
- CLAUDE.md "저장소 역할"에 "공개 사이트에는 AV Portal을 언급하거나 연결하지 않는다" 규칙을 더했습니다.

## 5. 검증

- 변경 전: `dist/`에서 `src/app.js`·`src/products.js`·`src/styles.css` 3개 파일이 걸렸습니다. 변경 후 같은 검색 결과는 0건입니다.
- main(0.267, 다른 세션의 XDM-MR4S 크게 보기)을 병합한 뒤 다시 검증했습니다: 단위 테스트 209개 통과(새 시험 1개 포함), `build-product-index --check` 33개 통과, 표기 통일 바뀔 곳 0건, 다크 블록 최신, 화면 시험(`e2e-smoke`) 294/294 통과, 버전 검사 0.267 → 0.268, `git diff --check` 통과. 병합 전에는 번호가 같은 0.267이라 0.268로 옮겼습니다.
- 레이어 비교 팝업을 열어 화면 글에 `portal`·`포탈`·`포털`이 없고 표의 "근거" 칸이 "제조사 데이터시트"로 나오는 것을 확인했습니다(캡처 `docs/qa/remove-portal-0.268/`).

## 6. 되돌리기

PR을 revert하면 됩니다. 화면 문구만 되돌릴 때는 `src/app.js`의 `layerCompareRows` 출처 칸과 팝업 하단 출처 문구를 이전 값으로 바꾸면 됩니다(권장하지 않음).
