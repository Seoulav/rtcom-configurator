# SPX-R6 크기·무게·어댑터 규격 추가(0.216)

## 1. 목적

알티컴에 보낸 질문 7번(SPX-R6 크기·무게·전원 어댑터 규격)의 답을 04 제품 사양에 반영합니다. 답은 2026-10-14에 사용자가 카카오톡으로 전달했습니다.

## 2. 답 내용과 반영 위치

| 항목 | 답 | 반영 |
|---|---|---|
| 크기(W×H×D) | 440×43.6×170mm | `data/products/spx-r6.json` Physical 행 "크기(W×H×D)" |
| 무게 | 2.9kg | 같은 파일 Physical 행 "무게" |
| 외부 전원 어댑터 규격 | 12V 5A 60W | 같은 파일 Power 행 "외부 전원 어댑터 규격", 조건 "외부 전원 어댑터 1개로 모듈 6개 공급" |

- 출처 코드 `U3`("알티컴 답변(사용자 전달)")를 `sources`에 더했습니다.
- `verificationSummary`의 "사양서에 없어 적지 않았다" 문장을 답을 반영한 내용으로 고쳤습니다.
- 크기 표기는 기존 규칙(`×`, 단위 뒤 `mm`)을 따르고, 순서는 답의 W×H×D 순서를 그대로 썼습니다.

## 3. 변경하지 않은 것

- 사양서 원문 행(S1)과 모듈 구성, 전송 거리, 단자 지도, 그림은 바꾸지 않았습니다.
- 공개 JSON의 키 이름과 스키마 3은 그대로입니다.

## 4. 검증

- `node --test tests/*.test.cjs`, `node scripts/build-product-index.cjs --check`, `node scripts/package-site.cjs`, `node scripts/check-version.cjs`, `git diff --check`로 확인합니다(결과는 PR 설명에 기록).

## 5. 되돌리기

- 이 PR을 되돌리면(`git revert`) SPX-R6 04 제품 사양의 세 행과 `U3` 출처가 빠지고, 답 기록만 이전 상태("사양서에 없어 적지 않음")로 돌아갑니다.
