# VDM 실제 슬롯 구성 (0.10.0)

- 요청: "VDM도 XDM처럼 개선하자" + VDM 자료 압축 파일(매뉴얼 KV07·KV05, VDM-48X 사진)
- 결정(사용자, 2026-09-26): VDM-288X는 특수 상황실용 커스텀 모델로 유지, VDM 카드는 현재 10종 유지
- 근거: 근거 문서 U06

## 슬롯 구성 (매뉴얼 KV07 2.2 Router Frame Specifications, 쪽 번호는 PDF 기준)

| 모델 | 입력 | 출력 | 화면 배치 |
|---|---|---|---|
| VDM-8X | 2 | 2 | 가로 보드, 입력 왼쪽·출력 오른쪽 (도면 p.12) |
| VDM-16X | 4 | 4 | **후면 사진(p.7) 위 슬롯**, 세로 보드 |
| VDM-32X / 48X / 64X | 8 / 12 / 16 | 같음 | 세로 보드 "입력 4열 \| 출력 4열"을 2·3·4단 (도면 pp.14–16) |
| VDM-80X / 128X / 180X | 20 / 32 / 45 | 같음 | 입력 위·출력 아래, 10·16·15열로 단순화 |
| VDM-288X | - | - | 커스텀 제작이라 슬롯 표 없음. 논리 슬롯 + `VDM_288X_CUSTOM` 확인 필요 안내 |

- 80X·128X·180X의 열 수는 도면을 보고 단순화한 값입니다. 실제 보드 번호 순서와 위치는 도면·실물로 확인이 필요합니다.
- 매뉴얼에는 VDM-256X(64·64)가 있지만 구성기 모델 목록(21종 계약)에는 없습니다. 추가 여부는 결정되지 않았습니다.

## 변경

- `src/core.js`
  - `slotPlans.VDM`을 추가했습니다.
  - 예전 VDM 저장본의 논리 슬롯(A·B)은 실제 슬롯 1·2로 변환합니다. VDM은 모든 모델이 2장 이상이라 제외되는 카드는 없습니다.
  - 검증에 `SLOT_LAYOUT`(근거 VDM 매뉴얼)과 `VDM_288X_CUSTOM`을 추가했습니다.
- `src/app.js`
  - `vdmRacks`(배치·열 수), `slotRatios`(판넬 비율), VDM 블랭크 커버와 판넬 사진을 추가했습니다.
  - `rearPhotos['VDM-16X']`를 추가했습니다(잘린 사진 449×278 기준 좌표, 보드 고정 나사 간격 40.7px로 측정).
  - VDM-16X·48X 전면 사진을 넣었습니다. 섀시 최대 채널은 슬롯 수 × 4로 계산합니다.
- `src/catalog.js`: VDM-288X 설명에 "특수 상황실용 커스텀"을 추가했습니다. 모델·카드 수는 그대로입니다.
- `src/styles.css`: 슬롯 모양을 `--rt-slot-ratio`(XDM 9.7, SPX 13.8, VDM 5.7)로 계산합니다.
- 자산: `scripts/tools/extract_vdm_assets.py`로 매뉴얼 보드 사진에서 카드 10종 판넬을 잘랐습니다.
  - 매뉴얼의 SDI 입력 보드는 VDM-SIS4 하나뿐이라, 이 사진을 구성기 카드 `SIS4-U`에 씁니다.
  - 블랭크 커버는 HIS4-U 판넬의 나사 끝부분과 줄별 중간값 색으로 합성했습니다.
  - 16X 후면 사진은 매뉴얼 설명 번호와 지시선을 빼고 장비 본체만 잘랐습니다.
