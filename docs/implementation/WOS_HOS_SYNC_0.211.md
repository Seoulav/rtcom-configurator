# 0.211 XDM-WOS100·HOS100 차이: 출력 동기(싱크)

## 요청

사용자가 알티컴 답을 전달했습니다(2026-10-13).

1. "WOS100과 HOS100 가장 큰 차이는 SINK입니다. HOS100에서 레이어를 만들 수 있으나 동기가 맞지 않아 LED적용이 어렵습니다."
2. 4K 모니터·8K LED 질문(아래 "이어진 질문") 뒤에 "WOS100 2장 3장 사용 시 S-BOX 1,2 에대한 동기입니다", "라고하네"

- **"SINK" 해석:** 뒤 문장의 "동기가 맞지 않아"와 같은 뜻이므로 출력 동기(SYNC, 싱크)로 보고 적었습니다.
- **WOS100 동기의 뜻:** WOS100 2~3장으로 LED S-BOX 1·2에 나눠 보낼 때 카드 사이 동기가 맞는다는 뜻입니다.
- **출처:** "라고하네"라는 말로 보아 알티컴에서 들은 내용이므로 `xdm.json` `U6`를 "알티컴 확인(사용자 전달)"로 기록했습니다.

- **AV Portal:** 라인업 `summary` 문장만 늘었습니다. 키와 `io`는 바뀌지 않았습니다.

## 이어진 질문: 4K 모니터와 8K LED

사용자 질문(2026-10-13): "wos카드 출력에 4k모니터 연결시 sync는 의미없고 만약 wos카드를 4장 사용해서 8k led전광판에 사용시는 문제가 된다고 보면 될까?"

| 경우 | 출력 동기가 필요한가 | 근거·비고 |
|---|---|---|
| 출력 1개 → 4K 모니터 1대(화면마다 다른 내용) | 필요 없음 | 디스플레이가 신호 하나에만 맞추므로 출력 사이 동기를 따질 일이 없습니다. HOS100도 문제없습니다. |
| 출력 여러 개 → LED 화면 하나(예: 8K = 4K 출력 4개) | 필요 | 한 화면을 여러 출력이 나눠 그리면 출력마다 프레임 시점이 달라 움직이는 영상에서 구역 경계가 찢어지거나 어긋날 수 있습니다. 사용자 확인대로 HOS100은 이 이유로 LED 적용이 어렵습니다. |
| WOS100 1장(비디오 월 모드, 4K 출력 4개 = 2×2) | 카드 안 동기는 WOS100의 장점(0.211) | 카탈로그 9쪽: 비디오 월 모드는 HDMI 4포트로 2×2 월 한 면을 구성합니다. 8K(7680×4320)는 4K 2×2라 카드 1장 범위입니다. |
| WOS100 여러 장으로 LED 화면 하나(S-BOX 여러 대) | 맞음 | 알티컴 확인(사용자 전달): "WOS100 2장 3장 사용 시 S-BOX 1,2 에대한 동기입니다". WOS100의 출력 동기가 바로 이 카드 사이 동기입니다. 질문표 §5 12번은 이 답으로 정리했습니다. |

- **레이어 모드와 비디오 월 모드:** 0.210에서 확인한 대로 레이어를 쓰면 카드 4포트가 같은 화면을 냅니다. 그래서 레이어 모드로는 카드 1장이 합성 화면(4K) 1개만 냅니다. 8K 한 면을 레이어 모드 카드 4장으로 채우면 카드 사이 동기가 문제가 됩니다.
- **사이트 반영:** 카드 사이 동기 답을 받은 뒤 WOS100 LED 모드 상자, HOS100 팝업 안내 상자, WOS100 카드 사양·출력 카드 TIP·카드 설명, 05 주요 기능, 라인업 요약에 "2~3장으로 LED S-BOX 1·2에 나눠 보낼 때 카드 사이 동기"를 넣었습니다.
- **정리:** 8K를 WOS100 여러 장으로 나눠 그릴 때의 문제는 WOS100이 아니라 동기가 맞지 않는 HOS100에서 생깁니다.
