# XDM-WOS100 포트 배치 확정 (0.240)

사용자 확인 2026-10-16: 알티컴 질문 15번(WOS100 오버레이 포트 배치)에 "현상태가 맞아".

## 1. 결정

- 오버레이(`OW`)로 월을 만들 때 실제 배치는 **"카드 1장 = 디스플레이 1대(OUT 1)"**입니다. 0.224부터 시뮬레이터 기본값이던 그 배치가 맞습니다.
- 가이드 46~47쪽 Wall Port Connection 그림의 "카드 1장 = 디스플레이 2×2" 배치는 실제 배치가 아니며, 가이드 예제 1~8 커맨드를 글자 그대로 다시 만들 때만 씁니다.

## 2. 바뀐 것

| 위치 | 변경 |
|---|---|
| 07 화면 연출 시뮬레이터 "포트 배치" 선택지 | "카드 1장 = 디스플레이 2×2 (가이드 연결 그림)" → "(가이드 예제 재현용)" |
| 시뮬레이터 아래 근거 문단 | "어느 쪽이 맞는지 알티컴 확인을 기다리고 있습니다" → 실제 장비는 "카드 1장 = 디스플레이 1대"가 맞다고 확정 |
| 문서 | 질의서 §5 15번 답 기록, 질문 목록(`docs/handoff/RTCOM_QUESTIONS_2026-10-16.md`)에서 15번 제외, OPEN_ITEMS 해당 항목 완료 처리, `LAYOUT_SIM_0.224.md` 문구 정정 |

## 3. 남긴 것

- "디스플레이 2×2" 선택지는 지우지 않았습니다. 가이드 예제 2·3 프리셋과 테스트(`tests/layout-sim.test.cjs`)가 그 배치로 가이드 원문 커맨드를 재현하기 때문입니다. 완전히 빼려면 그 프리셋과 테스트를 함께 정리해야 하므로 사용자 결정을 받아 따로 진행합니다.
- 커맨드 문법·기본값·저장 형식은 그대로입니다.

## 4. 검증

- 단위 테스트·e2e 통과(문구 외 동작 변경 없음), 표기 통일 도구 0건.

## 5. 되돌리기

`src/layout-sim.js`의 `MAPPINGS` 라벨과 근거 문단 한 문장을 이전 문구로 돌리면 됩니다.
