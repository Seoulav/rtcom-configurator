# VDM-256X 추가 (0.12.0)

- 요청: "vdm256추가해" (2026-09-26). 0.10 작업 때 매뉴얼에는 있으나 모델 목록에 없다고 보고한 항목입니다.
- 근거: 근거 문서 U08 (VDM 국문 매뉴얼 KV07 PDF p.20)
- 기준 커밋: `e523367` (main, 0.11.0 병합)

## 호환성 계약 변경

| 항목 | 이전 | 이후 |
|---|---|---|
| 제품군·섀시·카드 | 3/21/26 | 3/22/26 |
| 슬롯 ID 범위 | `in-1`…`in-54`, `out-1`…`out-54` | `in-1`…`in-64`, `out-1`…`out-64` |
| `catalogVersion` | `2026-09-18-draft.1` | 변경 없음 |
| JSON schema, LocalStorage key | 3, `rtcom.configuration.v1` | 변경 없음 |

- `catalogVersion`을 올리면 이미 저장한 JSON을 불러올 때 "카탈로그 버전이 다릅니다" 오류가 납니다. 이번 변경은 모델 추가만 하므로 올리지 않았습니다.
- 0.11 이하 화면에서 VDM-256X로 저장한 JSON을 불러오면 "지원하지 않는 모델"로 거부됩니다(되돌릴 때 주의).

## 변경

- `src/catalog.js`: VDM 모델 목록에 `VDM-256X`(설명 "256 입력 / 256 출력 · 2랙 폭 39RU")를 VDM-180X와 VDM-288X 사이에 추가했습니다.
- `src/core.js`: `slotPlans.VDM['VDM-256X']=[64,64]`, 슬롯 ID 생성 범위를 64까지 늘렸습니다.
- `src/app.js`: `vdmRacks['VDM-256X']=['vt',32]` — 입력 위·출력 아래, 한 줄 32열(랙 2개 × 16열)로 2줄씩 표시합니다. 매뉴얼에 선 도면만 있어 그림 랙으로 표시합니다.

## 되돌리는 방법

이 PR의 병합 커밋을 revert하면 VDM-256X와 슬롯 55~64가 사라집니다. VDM-256X로 저장한 구성은 revert 전에 JSON으로 백업해 두어야 합니다.
