## 변경(`data/products/mr-4s.json`)

- 개요: "후면 전원 입력이 POWER 1·2 두 개라 어댑터 2개를 연결하면 전원을 이중화할 수 있다." 문장을 추가했습니다.
- 05 주요 기능: "전원 이중화(POWER 1·2 입력) 지원"을 "단일 전원으로 모듈 4개 전원 공급" 다음에 추가했습니다.
- 04 제품 사양(Power): "전원 이중화 · 지원 (POWER 1·2 입력 2개)" 행을 "전원" 행 다음에 추가했습니다.
- 02 Port Map: 2번 이름을 "DC 전원" → "DC 전원 1·2"로, 설명을 "DC 12V 3A 전원 입력 2개(POWER 1·2), 어댑터 2개 연결 시 전원 이중화"로 바꿨습니다(좌표는 그대로이며 두 단자를 함께 감쌉니다).
- 출처: `U`(서울영상테크 SI사업본부 확인)를 추가했습니다.

확인하지 않은 것: 두 어댑터를 함께 꽂을 때의 동작 방식(동시 분담인지 대기 전환인지)과 운전 중 어댑터 교체(핫스왑) 가능 여부입니다. 이 내용은 근거가 없어 적지 않았습니다.
