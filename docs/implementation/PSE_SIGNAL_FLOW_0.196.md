## 1. XDM-CTR100 PSE 03 Signal Flow (`pseDiagram`)

이전 그림은 상자 두 개와 점선 한 줄, 설명 글 두 줄로만 되어 있었습니다. 이번에는 XDM-PSU 그림과 같은 방식으로 다시 그렸습니다.

- 같은 부품을 씁니다. `psuDiagram`의 RJ45·HDMI·이름표·흐르는 케이블·2핀 전원선 그리기를 `psuParts`로 꺼내 두 그림이 함께 씁니다. XDM-PSU 그림 자체는 바뀌지 않았습니다(e2e "8가닥·역방향 1" 그대로 통과).
- 장비 뒷면 그림에는 RJ45·HDMI IN/OUT·피닉스 5핀·상태 LED가 들어갑니다. PSE에는 DC 잭에 전원 어댑터를 꽂고, 상대 기기에는 "PD" 표시만 둡니다.
- 조합 1(PSE를 TX로): 소스 → PSE(TX, DC 12V 1A 어댑터) → CAT(신호 →, 전원 →) → XDM-CTR100(RX, PD) → 디스플레이. 벽부형 XDM-CR103도 쓸 수 있습니다.
- 조합 2(PSE를 RX로): 소스 → XDM-CTR100(TX, PD) → CAT(신호 →, 전원 ←) → PSE(RX, 어댑터) → 디스플레이. 벽부형 XDM-CT103도 쓸 수 있습니다.
- 케이블 위에서 신호(초록)·전원(주황)·HDMI(파랑·보라)가 흐릅니다. "움직임 줄이기" 설정에서는 애니메이션이 멈춥니다(기존 CSS).
- 아래쪽 안내 2줄:
  - TX/RX 딥 스위치 선택 · 최대 100m S/FTP CAT6A 필수 · 전원은 PSE 한쪽에만 연결
  - CIS100·COS100 카드에는 PSE 직결 불가 → XDM-CTR100 + XDM-PSU 사용
- "크게 보기" 확대 창, 범례(입력·HDBaseT 신호·전원·출력·최대 전송 거리), 펼치는 그림 설명을 추가했습니다.
- 값은 제품 데이터에서 가져옵니다. 전원은 `specifications` "전원"(DC 12V 1A), 거리는 "최대 전송 거리"(100m, *S/FTP CAT6A 필수)를 쓰고, 조합 설명은 개요 문구를 그대로 씁니다.
