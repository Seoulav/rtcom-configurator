# 0.193 전송기 최대 전송 거리 한 행 정리

사용자 결정 2026-10-01: Claude 제안안("이 안대로 진행해줘"). 0.166(SPX-TX/RX)·0.181(SPX) 줄 나눔 방식을 전 전송기로 넓혔습니다.

## 바뀐 행
| 제품 | 값(줄 나눔) | 조건 |
|---|---|---|
| FT101-U/FR101-U | 싱글모드 2km / 멀티모드 500m | 1920x1200 @ 60Hz·1080p·Ultra HD 4K |
| FT103-U-H/FR103-U | 싱글모드 2km / 멀티모드 500m | 4K/30 |
| OBHD-2C | 싱글모드 2km / 멀티모드 500m | (없음) |
| XDM-FT101/FR101 | 싱글모드 2km / 멀티모드 300m | (없음) |
| XDM-CT103/CR103 | 4K/60 @ 4:4:4 100m / 1080p 150m (Long Reach, CT103 딥 스위치 2번 ON) | S/FTP CAT6A 필수 (BELDEN 10GXE02 기준) |
| SPX-R6 | 4K/60 @ 4:4:4 50m / 1080p/60 60m | CAT5e 기준 |

- CT101-U·CT103-U-H·CT104-U: 값(100m) 그대로, 조건 문구만 `…, BELDEN CI6522 기준`으로 통일. 해상도 원문("Ultra HD 4K")은 매뉴얼 Hz 확인 전이라 유지.
- XDM-CTR100·CTR100 PSE·OBUX-1C·SPX·SPX-TX/RX: 이미 한 행이라 그대로.
- 줄 순서: 광은 싱글모드 → 멀티모드, 해상도별은 4K → 1080p.
- XDM-CT103 출처 코드는 첫 행의 `C`를 유지(150m Long Reach는 매뉴얼 M1 근거, 값 칸 괄호에 설명).

## XDM-CT103/CR103 전원 조건(같은 PR)
- 사용자 확인 2026-10-01 "COS100+XDM-PSU를 과 함께 써야 가능해": 단자 지도 CR103 전원 설명, 같은 구조인 CT103(CIS100) 전원 설명, 04 사양 "전원(어댑터)" 조건 3곳에 `+XDM-PSU`를 넣었습니다. CIS100도 XDM-PSU POH 모듈로 전원을 받는다는 XDM-PSU·XDM-CTR100 제품 설명과 맞춘 것입니다.

## 코드
- `src/products.js` SPX-R6 03 Signal Flow 범례: 줄 나눔 값을 줄마다 "4K/60 50m · 1080p/60 60m"으로 씀. 다른 전송기 범례(`cableLabelFor`)는 0.166부터 줄 나눔 값을 "이름: 값 · 값"으로 이미 처리.
