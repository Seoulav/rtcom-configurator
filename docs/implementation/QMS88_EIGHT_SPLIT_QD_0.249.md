# QMS-88UX 8분할 도해 번호 정정과 QD 오디오 선택(IS) 명령 (0.249.0)

## 1. 요청과 결정

- 사용자 요청 2026-10-17 "QMS-88Ux out9-10관련해서 제대로 된건지 검증해줘"에서 나온 두 가지를 "1·2번 진행해"로 승인했습니다.
  1. 쿼드 뷰 8분할 도해의 칸 번호 오류 정정
  2. AMX 카드에 QD 오디오 입력 선택(`IS`) 명령 추가
- 월 설정 보강(0.248)은 이미 병합·배포되었습니다(`docs/implementation/QMS88_WALL_TWO_0.248.md`).

## 2. 문제

### 2-1. 8분할 도해
- 매뉴얼 KV.04 23쪽 Output Option 2·3·5·6 도해는 Q1(칸 1~4)과 Q2(칸 5~8)가 각각 2×2 묶음입니다.
  - 옵션 2(좌우): 윗줄 `1 2 5 6`, 아랫줄 `3 4 7 8`
  - 옵션 3(상하): 2열 4행 `1 2 / 3 4 / 5 6 / 7 8`
  - 옵션 5·6: 2·3과 같은 배치에 16:9 비율(5는 위아래, 6은 좌우가 비음)
- 사이트는 옵션 2·3을 한 장(`8분할(비율무시)`)으로 합치고 윗줄 `1 2 3 4`, 아랫줄 `5 6 7 8`로 그렸습니다. 16:9 도해도 같은 번호 배치였고 옵션 3·6은 없었습니다. 칸 번호가 곧 입력 번호이므로 현장에서 입력을 잘못 읽을 수 있었습니다.

### 2-2. QD 오디오 선택
- 매뉴얼 43쪽 `IS` 명령(QD1·QD2 단자에 나올 입력 선택)이 AMX 카드에 없었습니다.

## 3. 변경

- `src/products.js`:
  - `LAYOUT_SHAPES`의 8분할 2종을 4종으로 바꿨습니다: `8분할 좌우(비율무시)`·`8분할 상하(비율무시)`·`8분할 좌우(16:9 비율)`·`8분할 상하(16:9 비율)`. 칸 위치는 23쪽 도해 치수를 재서 정했습니다(비율 5·6의 비는 칸 25×25).
  - `eightSplitNote()`: 8분할 미리보기 아래에 "출력 옵션 N · …" 한 줄(`data-layout-opt`)을 보여 줍니다. 첫 그리기와 레이아웃 버튼 클릭 모두에 넣었습니다.
- `data/products/qms-88ux.json`:
  - `videoModes` QUAD `layouts`를 16종(매뉴얼 12종 + 8분할 4종)으로, `detail` 문구를 "좌우·상하"로 고쳤습니다.
  - `controlExample.builders`에 `qd`(QD 오디오 입력 선택, 43쪽)를 더했습니다: `*255IS` + `Q1Q2`(또는 `Q1`·`Q2`) + `S0`~`S3`.
  - `limits`에 "예시 `ISQ2S3`과 표가 달라 알티컴 확인 대기"를 적었습니다.
- 테스트: `tests/control-example.test.cjs`에 `IS` 시험(매뉴얼 예시 2개 일치, S0~S3 표 안내, `limits` 안내), `scripts/e2e-smoke.cjs`에 8분할 4종 번호 배치·출력 옵션 안내·QUAD 16종·`IS` 화면 확인을 더하고 기존 8분할 점검을 새 이름과 번호 정렬 비교로 바꿨습니다.
- 알티컴 확인 대기 질문 32번(예시·표 불일치, `Q1`·`Q2`의 뜻, QD1만 정하는 형식)과 `OPEN_ITEMS.md` 항목을 추가했습니다.

## 4. 근거와 경계

- 도해 번호·치수: 매뉴얼 KV.04 23쪽(이미지로 직접 대조). 출력 옵션 뜻: 22쪽 표.
- `IS` 형식: 43쪽 `IS + Q1[Quad Input Select: Q1, Q2] + S0[0~3]`와 예시 `*255ISQ1Q2S0!`·`*255ISQ2S3!`. S0~S3 입력 표: 같은 쪽 표(QD1 = 입력 1~4번, QD2 = 입력 5~8번).
- 예시 설명("QD 2번 INPUT 5번")과 표(S3 = 입력 8번)가 달라 사이트는 표를 따랐습니다. `ISQ1S2!`(QD1만)는 매뉴얼 형식을 따른 추정이라 질문에 넣었습니다.
- 바꾸지 않은 것: 도해는 QUAD 레이아웃 기준 예시 하나뿐입니다(다른 레이아웃에 옵션 2·3을 적용한 모습은 매뉴얼에 없음). 9·10번 `OT` 범위와 월 구성 상충은 질문 31번 그대로.
