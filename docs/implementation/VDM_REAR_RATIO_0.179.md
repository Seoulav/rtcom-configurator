# 0.179 VDM 후면 그림 실제 비율로 다시 그리기

사용자 요청(2026-09-29): "VDM 후면 그림도 실제 비율로 다시 그려줘". 0.178에서 XDM·SPX 후면은 맞췄고, VDM은 카드 비율 때문에 남겨 두었습니다(`docs/implementation/FRAME_HEIGHT_DARK_0.178.md` §3).

## 1. 조건

- VDM 후면 슬롯 칸은 0.120부터 **높이 = 너비 × 5.7**(카드 판넬 사진 비율)로 그립니다. 그림 전체를 늘리면 카드가 칸에서 늘어나거나 눌리므로, 슬롯 칸 모양은 바꾸지 않습니다.
- 실제 후면 비율은 몸체 폭 약 440mm ÷ 카탈로그 높이로 봅니다(VDM-256X는 랙 2대 880mm ÷ 39U 1,733.6mm).

모든 그림이 실제보다 **세로가 짧았고**, 슬롯이 아닌 부분으로 높이를 채웠습니다(`scripts/tools/draw_vdm_frames.cjs`).

- 세로 카드 프레임(16X~64X, `vsFrame`): 모자란 높이의 30%는 위 통풍구, 70%는 입력·출력 슬롯 아래 통풍 판에 씁니다. 가운데 칸(오디오 매트릭스·통신 단자·전원)은 아래 통풍 판 끝까지 늘어납니다.
- 가로로 쌓는 대형 프레임(80X~256X, `vtFrame`): `grow=[위, 가운데 띠, 아래]` 비율로 명판 아래 통풍구·가운데 냉각 팬 띠·전원 아래 통풍구에 나눕니다(80X는 가운데 띠만, 128X·256X 0.3/0.4/0.3, 180X 0.35/0.3/0.35).
- 구성기 03 카드 슬롯 좌표(`src/app.js` `rearPhotos`)는 스크립트가 출력한 값으로 바꿨습니다. 단위 테스트의 VDM 슬롯 비율 검사(5.7:1 ±3%)가 그대로 통과합니다.
- 정면 그림은 바꾸지 않았습니다(렌더링 뒤 정면 파일이 바이트 단위로 같음을 확인).

## 3. 확인

- 구성기 03에서 VDM-16X·64X·180X·256X 모든 슬롯에 카드를 꽂아 카드가 칸에 정확히 들어가는 것을 화면으로 확인했습니다.
- 제품정보 프레임 팝업(휴대폰 420px·PC 1280px): 좌우 배치 7종 모두 정면·후면 높이 차이 0px.
- `node --test tests/*.test.cjs` 72개, `node scripts/e2e-smoke.cjs` 219개 통과.

## 4. 남은 차이: VDM 정면 그림

팝업에서 같은 높이로 놓으면 후면 폭은 정면 폭의 약 91%(440 ÷ 483)가 되어야 합니다. 정면 그림 중 아래 모델은 실제(483mm ÷ 높이)보다 가로가 넓습니다.

| 모델 | 정면 가로:세로 | 실제 | 차이 |
|---|---|---|---|
| VDM-8X | 3.24 | 3.65 | −11% |
| VDM-32X | 1.03 | 0.91 | +13% |
| VDM-64X | 0.61 | 0.45 | +35% |
| VDM-128X | 0.41 | 0.29 | +40% |
| VDM-256X | 0.62 | 0.56 | +12% |

정면은 슬롯 좌표와 관계가 없어 그림 크기만 바꾸면 됩니다. 사용자 결정이 있으면 다음 작업으로 맞춥니다.
