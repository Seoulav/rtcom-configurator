# QMS-88UX 비디오 월 설정: 월 2개 이어 쓰기와 일관성 검사 (0.248.0)

## 1. 요청과 결정

- 사용자 요청 2026-10-17 "QMS-88Ux out9-10관련해서 제대로 된건지 검증해줘" → 검증 범위를 "amx커맨드 부분"으로 확인("amx커맨드 부분을 이야기하는거야") → 발견한 문제 중 "1번 진행해줘"(월 설정 빌더 보강).
- 같은 검증에서 나온 쿼드 뷰 8분할 도해 칸 번호 오류(`src/products.js` `8분할(비율무시)`·`8분할(16:9 비율)`), QD 오디오 선택 `IS` 명령 추가는 이번 요청에 없어 하지 않았습니다.

## 2. 문제

- 매뉴얼(KV.04) 35쪽 `OW` 첫 예시는 월 2개를 한 줄에 이어 씁니다: `*255OWO01-10M13H02V02O01O02O03O04H03V02O05O06O07O08O09O10!`.
- 카드의 빌더(`controlExample.builders[wall]`)는 월 한 묶음(H·V·포함 출력)만 만들어, 06 카드의 "2×2 + 2×2" 월을 AMX 카드에서 만들 수 없었고 단위 테스트도 이 예시를 확인하지 않았습니다.
- 칸 수와 포함 출력 수가 어긋나거나 월 범위 밖의 출력을 넣어도 아무 안내 없이 명령이 만들어졌습니다.

## 3. 변경

- `data/products/qms-88ux.json` `wall` 빌더: 입력 `h2`·`v2`·`members2`(모두 선택, 비우면 월 1개), `order`에 이어 붙임, `rangeParam: "range"`·`walls` 설정, 라벨을 "월 1 …"로 정리하고 요약 문구에 월 2개 안내를 넣었습니다.
- `src/control-example.js`:
  - `paramText`: `optional`인 숫자·번호 목록·글자 입력은 비어 있으면 명령에서 뺍니다(기존 `optional`은 선택 목록뿐이었고, 다른 제품 JSON에는 숫자·목록 `optional`이 없어 영향이 없습니다).
  - `wallCheck`: `walls` 설정이 있는 빌더만 검사합니다. 월 2가 일부만 적히면 오류(명령 대신 안내), 칸 수 불일치·범위 밖 출력·범위에 남은 출력·월 사이 겹침은 경고(`warn`)로 보여 주고 명령은 만듭니다.
  - `output()`: 경고가 있으면 명령 아래에 `data-ce-warn` 안내를 보여 줍니다.
- 테스트: `tests/control-example.test.cjs`에 월 2개 예시(매뉴얼 35쪽 첫 예시 포함)와 검사(경고 4종·오류·9·10번 포함 월) 2건, `scripts/e2e-smoke.cjs`에 화면 확인 1건을 더했습니다.

## 4. 근거와 경계

- 월 2개 규칙은 매뉴얼 35쪽 첫 예시와 19쪽 설명(2×2 월 최대 2개, 또는 월 1개 3×3·2×5)입니다. 두 쪽이 서로 달라(35쪽은 2×2 + 3×2) 월 크기 제한은 두지 않고 경고만 했습니다. 알티컴 확인 대기: 질문 31번.
- 매뉴얼이 일치하지 않는 입력(칸 수 ≠ 포함 출력 수)을 장비가 거부하는지는 적혀 있지 않아 오류가 아닌 경고로 처리했습니다.
- SPX의 `OW` 빌더와 QMS-88UX의 `OT`(출력 01~08)는 바꾸지 않았습니다.
