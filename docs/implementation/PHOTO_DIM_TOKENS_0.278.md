## 2번: 다크 모드 제품 사진

- 방식: 다크에서만 사진 밝기를 90%(`filter:brightness(.9)`)로 낮추고, 사진 받침을 같은 밝기의 옅은 회색 `#E6E6E6`으로 맞춥니다.
  - 사진 파일의 흰 배경(255)은 밝기 90%에서 약 230이 됩니다. 받침(`#E6E6E6` = 230)과 같아져 경계가 보이지 않습니다.
  - 색 자체는 바꾸지 않고 밝기만 낮춥니다(색 뒤집기·어둡게 칠하기는 0.276 결정대로 하지 않음).
- 대상(전 제품 조사, 다크 1280px)

| 곳 | 받침 | 사진 |
| --- | --- | --- |
| 제품 목록 썸네일(33) | 칸 전체 `#E6E6E6` | 밝기 90% |
| 02 Port Map 사진 그림(26개 제품, SVG `image`) | 그림 판 `#E6E6E6`(0.238의 흰 판 대신) | 밝기 90% |
| 제조사 원본 다이어그램(12) | `#E6E6E6` | 밝기 90% |
| 정면·후면 사진(`rt-pg-face`, QMS-44UX·MR-4S) | 그대로(틀 안에 "정면" 글자가 있음) | 밝기 90% |
| EDID 사진(10) | 그대로 | 밝기 90% |
| 사진 확대 팝업(사진 탭·사진·돋보기) | `--rt-photo` 다크 값 `#E6E6E6` | 밝기 90% |

- 바꾸지 않은 것: 구성기 카드 판넬 사진(0.178 결정, 옅은 회색 받침 유지), 프레임·카드 그래픽 그림, 카탈로그·매뉴얼 문서 팝업.
- 함께 고친 버그: 제품 목록 썸네일 가운데 세로로 긴 사진(SPX·HD-D102U 등)이 사진 칸(150px) 아래로 넘쳐 분류 글자를 덮었습니다. 수정 전부터 있던 문제이며, 회색 받침 때문에 더 잘 보이게 되어 함께 고쳤습니다. 사진이 칸 안쪽 크기(`width:100%;height:100%;object-fit:contain`)에 맞게 줄어듭니다. 이 부분만 라이트 화면에서도 바뀝니다.
- 위치: `scripts/tools/dark_tokens.cjs`의 `PHOTO_PLATE`·`PHOTO_DIM`·`photoCss()`, 다크 변수 `--rt-photo`. 썸네일 칸 규칙은 `src/styles.css`의 `.rt-pg-gridcard .rt-pg-photo`.

## 3번: 공통 디자인 토큰 파일 `src/svt-tokens.css`

- `:root`에 `--svt-*` 변수로 공통 값을 정의합니다.
  - 글꼴: `--svt-font-sans`(Pretendard), `--svt-font-min`(12px)
  - 라이트: 바탕·본문·보조 본문·설명 글자, 강조 글자(`#0057D8`)·선택 강조(`#007AFF`), 주요 버튼 그라데이션·글자·그림자, 앱 아이콘 그라데이션
  - 다크: 페이지·카드·카드 2·글자·보조 글자·설명 글자·강조 글자·선택 강조·사진 받침
  - 신호 색(구성도 범례, 0.242): HDMI·DP·SDI·CAT·광
- 이 사이트의 연결
  - `index.html`이 `src/svt-tokens.css`를 `src/styles.css`보다 먼저 불러옵니다. 제품별 페이지(`product-<id>.html`)는 `index.html`을 복사해 만들므로 함께 적용됩니다. `scripts/package-site.cjs` 배포 목록에도 넣었습니다.
  - `src/styles.css`: 구성기 기본 변수(강조·버튼·글꼴), 제품정보 변수(바탕·글자·강조·글꼴·신호 색), 신호 배지 5종, 주요 버튼 그라데이션 5곳·그림자 4곳·앱 아이콘 2곳이 `var(--svt-*)`를 읽습니다.
  - 다크 블록(`scripts/tools/dark_tokens.cjs`): 손으로 정한 다크 기준값, 그림 판·보고서 미리보기의 라이트 되돌리기 값, 사진 받침이 `var(--svt-*)`를 읽습니다. 자동으로 만드는 덮어쓰기 규칙은 바뀌지 않았습니다(생성 결과 비교로 확인).
- 다른 사이트에서 쓰는 방법: 이 파일을 그대로 복사해 사이트 CSS보다 먼저 불러오고 `var(--svt-*)`로 참조합니다. 다른 사이트(다른 저장소)에 적용하는 일은 이번 범위에 넣지 않았습니다.
- 파일을 불러오지 못하면 `var(--svt-*)`가 비어 색과 글꼴이 기본값으로 돌아갑니다. 같은 폴더의 정적 파일이라 `styles.css`와 같은 조건으로 불러옵니다.
