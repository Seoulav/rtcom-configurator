# 0.178 전송기 LED 문구 삭제 · 단자 지도 가운데 선 · 프레임 높이 · 다크 모드 카드 가독성

사용자 요청(2026-09-29, 휴대폰 삼성 인터넷 화면 3장 첨부):

1. XDM-CTR100 외 모든 전송기에서 "동작 상태 LED 4개 표시 지원(…)" 설명 삭제
2. 좌우 이동식(가로 스크롤) 그림에 가운데 선이 보이는 문제 해결
3. 모듈러 매트릭스 프레임 정면·후면 상하 높이가 안 맞는 문제 일괄 점검 후 수정
4. 블랙 테마(휴대폰 브라우저 다크 모드)에서 슬롯 카드 가독성 개선

## 1. 동작 상태 LED 문구

- 전송기 전체(`data/products/*.json`의 `features`)를 찾아보니 이 문구는 XDM-CTR100("동작 상태 LED 4개 표시 지원")과 XDM-CTR100 PSE(괄호 설명 포함) 두 곳에만 있었고, 두 항목을 모두 지웠습니다.
- 단자 지도의 "6 상태 LED" 번호표·설명은 단자 위치 안내라서 그대로 둡니다.

## 2. 가로 스크롤 그림의 가운데 세로 띠

- 원인: "옆에 더 있음" 그러데이션(0.28)을 스크롤 칸(`.rt-pg-svg-wrap`) 자신의 `::after`(절대 위치)로 그렸습니다. 스크롤 칸 안의 절대 위치 요소는 내용과 함께 밀리므로, 옆으로 밀면 띠가 그림 가운데에 남았습니다. 다크 모드에서는 흰 그러데이션이 어둡게 바뀌어 검은 선처럼 보였습니다.
- 수정: `src/products.js` `initDiagramScroll`이 스크롤 칸을 움직이지 않는 바깥 틀(`.rt-pg-svg-frame`)로 감싸고, 그러데이션은 그 틀의 오른쪽 끝에 붙입니다(`src/styles.css`). 창 크기가 바뀌어 다시 불려도 틀을 두 번 씌우거나 스크롤 감시를 두 번 달지 않습니다.
- 대상: 단자 지도, 03 Signal Flow, 시리즈 신호 구성 등 `.rt-pg-svg-wrap`을 쓰는 모든 그림입니다.

## 3. 프레임 정면·후면 높이 점검표

정면 그림은 카탈로그 mm 크기(랙 날개 포함 483mm 폭)로 그렸고, 후면 그림은 매뉴얼 사진 배치를 따라 그려서 비율이 모델마다 달랐습니다. 실제 후면 폭(랙 날개 없는 몸체)은 약 440mm로 봅니다.

| 프레임 | 높이 | 후면 가로:세로(전) | 실제 기준(440÷높이) | 조치 |
|---|---|---|---|---|
| SPX-M810 | 88.1mm | 4.43 | 4.99 | 다시 그림(1923×385 → 2000×400), 좌우 옆판을 넓힘 |
| SPX-M1620 | 177mm | 1.58 | 2.49 | 다시 그림(1040×418 → 2000×804), 가로 1.57배 |
| SPX-M2472 | 365mm | 1.00 | 1.21 | 다시 그림(462×383 → 2000×1658), 가운데 빈 판을 넓힘 |
| SPX-M24120 | 365mm | 1.00 | 1.21 | 다시 그림(459×383 → 2000×1669), 가운데 빈 판을 넓힘 |
| SPX-M3236 | 310.3mm | 1.47 | 1.42 | 차이 4%, 유지 |
| XDM 6종 | 177~1777mm | 0.27~2.64 | 0.25~2.49 | 차이 3~7%, 유지 |
| VDM 9종 | 132.5~1688mm | 모델마다 다름 | — | 유지: 0.120에서 슬롯 칸을 카드 사진 비율(5.7:1)과 똑같이 맞춰 그렸기 때문에, 전체 비율을 바꾸면 카드가 칸에 맞지 않습니다. 필요하면 별도 작업으로 다시 그립니다. |

- 구성기 03 카드 슬롯의 슬롯 좌표(`src/app.js` `rearPhotos`)는 그림 스크립트(`scripts/tools/draw_xdm_spx_rear_frames.cjs`)가 출력한 값으로 바꿨습니다. SPX 판넬 비율(13.8:1)도 테스트 허용 범위(±15%) 안에 들어가서, `tests/site.test.cjs`에 있던 SPX-M1620 예외(9.8:1)를 지웠습니다.
- 제품정보 03 메인프레임 팝업: 좌우 배치(세로로 긴 프레임)는 두 칸을 같은 폭(1fr 1fr)으로 나눠 높이가 서로 달랐습니다. 이제 두 그림을 읽은 뒤 비율 합을 CSS 변수(`--rt-duo-ratio`)로 넘겨 **두 그림을 같은 높이**로 그립니다. 위아래 배치(가로로 긴 프레임)는 0.154처럼 가로폭을 같게 둡니다.
- 구성기 02 프레임 선택 미리보기는 0.132부터 정면·후면을 같은 높이(`--rt-fh`)로 그리고 있어 바꾸지 않았습니다.
- 확인 결과(휴대폰 420px·PC 1280px, 좌우 배치 15종): 정면·후면 높이 차이 0px.

## 4. 다크 모드 카드 가독성

- 사이트는 밝은 화면(`color-scheme: light`) 하나입니다. 삼성 인터넷·크롬의 "웹 페이지 어둡게"는 흰 판을 검게 바꾸는데, 카드 판넬 사진은 검은 몸체라 어둡게 바뀐 판 위에서 거의 보이지 않았습니다.
- 수정: 카드 사진(`assets/cards/`)과 사진을 받치는 판(카드 선택 팝업·카드 상세 팝업·프레임 팝업)에만 `color-scheme: only light`를 줘서 강제 어둡게 하기에서 뺐습니다. 제품정보 04 카드 라인업 썸네일과 구성기 카드 타일 사진에는 옅은 회색 판(`#eef1f5`)을 깔았습니다.
- 확인: 크로미움 강제 다크 모드(`--blink-settings=forceDarkModeEnabled=true`)로 04 카드 라인업·카드 선택 팝업을 찍어 판넬 단자가 보이는 것을 확인했습니다. 삼성 인터넷은 크로미움 기반이지만 다크 모드 처리가 따로 있어, 공개 후 휴대폰에서 한 번 더 확인해야 합니다.
