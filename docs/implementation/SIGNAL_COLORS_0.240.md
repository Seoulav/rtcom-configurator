# 신호 색 통일 0.240

## 근거
- 사용자 제공 구성도(2026-10-16, 컨퍼런스룸 AV 구성도 260903 PDF) 범례에서 뽑은 색: 광 `#00B0F0`, SDI `#000000`, LAN `#00B050`, HDMI `#FF0000`, A.AUDIO `#7030A0`, USB `#0000FF`, 접점 `#E97132`.

## 결정 과정
- 1차 안: DP 신호 레드 `#E5242B`, HDMI 남색 유지("추천하는 레드 좋아보여").
- 사용자 지적(2026-10-16): "구성도 그릴때 HDMI,DP모두 레드로 했어 Dp를 오렌지로 해주면 어때?" → Claude 의견(HDMI는 구성도와 같은 빨강, DP는 범례 접점 주황 `#E97132`·사이트 전원선 주황 `#E39A2F`와 구별되는 짙은 주황) → 사용자 선택 "1번으로 진행해줘".

## 바꾼 것
| 신호 | 구성기 신호 배지(이전 → 0.240) | 제품정보 신호 구성도·전송기 그림(이전 → 0.240) | 구성도 범례 |
|---|---|---|---|
| HDMI | `#002060` → `#E5242B` | `#007AFF` → `#E5242B` | `#FF0000` |
| DP | `#FF0000` → `#C55A11` | `#5E5CE6` → `#C55A11` | 없음 |
| SDI | `#000000` 그대로 | `#E08A20` → `#000000` | `#000000` |
| HDBaseT·CATx(LAN) | `#00B050` 그대로 | `#1E9E52` → `#00B050`(전송기 그림 CAT 케이블 포함) | `#00B050` |
| 광 | `#00B0F0` 그대로 | `#30B0C7` → `#00B0F0`(전송기 그림 광케이블 포함) | `#00B0F0` |

- HDMI `#E5242B`는 범례 순색 `#FF0000`과 거의 같아 보이면서 흰 글자 대비가 4.55:1(순색 4.0:1)입니다.
- DP `#C55A11`은 빨강과 색상각이 26° 떨어져 작은 배지에서도 구별되고, 흰 글자 대비 4.33:1입니다. 범례의 접점 주황 `#E97132`(흰 글자 3.06:1)보다 짙어 접점과도 구별됩니다. 사용자 구성도에서도 같은 색을 쓰려면 PowerPoint 사용자 지정 색에 `C55A11`을 넣습니다.
- 0.170~0.239의 HDMI 남색(사용자 요청 2026-09-29)은 DP 빨강과 구별하려던 값이라, DP가 주황이 되면서 범례대로 빨강으로 돌렸습니다. 구성기 완성도 막대 범례 점도 같은 색입니다.
- 다크 화면에서는 신호 배지와 제품정보 범례 점에 옅은 테두리를 둡니다(SDI 검정이 묻히지 않게, `scripts/tools/dark_tokens.cjs` 손 규칙).
- 그대로 둔 것: 입력·출력을 뜻하는 파랑·보라(신호 종류가 아님), 멀티뷰 보라, 화면 연출 시뮬레이터 창 색, 장비 상태 LED 초록, 전원 주황.
