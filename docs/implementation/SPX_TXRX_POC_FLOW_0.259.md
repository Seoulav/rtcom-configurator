# 0.259.0 SPX-TX/RX PoC 전원 연결 표현 (2026-10-20)

## 1. 요청과 근거

- 사용자 요청 2026-10-20: 제품정보 SPX-TX/RX 화면을 가리키며 "PoC 기능이 있어서 TX 또는 RX 한쪽에만 DC 어댑터를 꽂으면 돼. 그 부분을 표현해줘."
- 근거: SPX-TX/RX 매뉴얼 Ver.2.0과 기존 제품 데이터(`features`의 "PoC(Power over Cable) 지원(송·수신기 중 한쪽만 전원 연결)", 04 제품 사양 전원 "DC +12V 1A 이상"). 문구로만 있고 그림에는 전원이 없어, 어댑터를 어디에 꽂는지 한눈에 보이지 않았습니다.

## 2. 변경

- `src/products.js`의 `extenderDiagram`에 SPX-TX/RX 전용 그림(`pocPair`)을 더했습니다. 위아래 두 줄입니다.
  - 방법 ① 송신기(TX)에만 어댑터 연결: TX 위에 "DC 12V 1A 이상 어댑터" 상자와 주황 화살표, TX → RX 방향 주황 화살표("같은 케이블로 전원 → 수신기"), RX에는 "전원 케이블 불필요(PoC)".
  - 방법 ② 수신기(RX)에만 어댑터 연결: 같은 그림에서 어댑터가 RX 쪽이고 전원 화살표가 RX → TX 방향, TX에는 "전원 케이블 불필요(PoC)".
  - 두 줄 모두 CATx 케이블이 신호(녹색 점선)와 전원(주황 화살표)을 함께 나릅니다. 아래 글에 "어댑터는 송신기·수신기 중 한쪽에만 연결하면 됩니다(PoC) · SPX-COS12 카드에 연결한 SPX-RX는 매트릭스에서 전원을 받습니다"를 적었습니다.
- 범례에 "전원(PoC)"을 더했고, "그림 설명"(펼침)에 "전원(PoC)" 줄을 더했습니다. 기존 실효 전송 거리 범례(Belden 7814A·10GXE02 조건)는 그대로입니다.
- `data/products/spx-rx-tx.json`
  - 단자 지도 7번(TX DC IN): "송·수신기 중 한쪽에만 연결(PoC)".
  - 단자 지도 6번(RX DC IN): "송·수신기 중 한쪽에만 연결(PoC) · SPX-COS12 연결 시 매트릭스에서 PoC 공급".
  - 04 제품 사양 전원의 조건: "PoC: 송신기 또는 수신기 한쪽에만 연결".
- 다른 전송기 그림(XDM·VDM·OBHD-2C 등)과 PSE 조합 그림은 바꾸지 않았습니다. `pocPair`는 `item.id==='spx-rx-tx'`일 때만 켜집니다.

## 3. 경계

- "한쪽에만 연결"은 사용자 확인(2026-10-20)과 매뉴얼의 PoC 설명에 따른 것입니다. 어댑터 용량(DC 12V 1A 이상)은 기존 사양 값입니다. 케이블 길이에 따른 전원 공급 한계나 양쪽 모두 연결했을 때의 동작은 매뉴얼에 근거가 없어 적지 않았습니다.
- SPX-COS12 카드에 연결한 SPX-RX가 매트릭스에서 전원을 받는다는 기존 설명은 그대로 두었고 따로 확인하지 않았습니다.

## 4. 검증

- 화면 확인: 데스크톱 라이트·다크 캡처 `docs/qa/spx-poc-0.259/`. 휴대폰 폭은 다른 긴 연결도처럼 좌우로 밀어 보는 방식입니다.
- 화면 시험(`scripts/e2e-smoke.cjs`)에 항목을 더했습니다. 방법 ①·②, 어댑터 상자 2개, "전원 케이블 불필요(PoC)" 2개, 주황 전원 요소, 범례의 전원(PoC), 그림 설명 문구를 확인하고 HDBaseT 표기가 없는지도 봅니다(0.64 기존 시험과 같은 조건).
- 단위 테스트, 제품 색인, 표기 통일 검사, 버전 검사는 기본 검증 명령으로 확인합니다.
