## 1. QMS 동작 모드 줄 (`ioFlowDiagram`)

원인: QMS-44UX의 MATRIX·QUAD·WALL·DUAL은 장비 전체에 적용하는 동작 모드입니다(`videoModes`, 근거 M-Q44). QMS-88UX의 9·10번처럼 멀티뷰 전용 출력이 없어서 0.194 멀티뷰 묶음이 생기지 않고, 그림에는 MATRIX 모드의 크로스포인트만 보였습니다.

변경:
- 신호 띠 아래에 "동작 모드 선택" 줄을 둡니다. 모드마다 작은 그림과 짧은 이름이 들어갑니다: MATRIX(라우팅, 교차선), QUAD(멀티뷰, 4분할 화면), WALL(비디오 월, 2×2), DUAL(2분할, 세로 분할). MATRIX 칸은 파란색으로 강조하고, 아래에 "격자는 MATRIX 예시 · 레이아웃은 06 화면 구성 모드"를 적습니다.
- 모드 목록은 `videoModes.modes`에서 뽑고, 요약에 "출력 N번"이 들어 있는 모드는 뺍니다. 전용 출력이 있는 모드라는 뜻이기 때문입니다. 결과:
  - QMS-44UX: MATRIX·QUAD·WALL·DUAL 네 모드를 모두 표시합니다.
  - QMS-88UX: MATRIX·WALL만 표시합니다. QUAD·DUAL은 출력 9·10번 멀티뷰 묶음에 이미 그려져 있습니다.
  - videoModes가 없는 HDS-42MU 등은 그대로입니다.
- 주 출력 묶음 설명에 다른 모드를 덧붙입니다. 예: QMS-44UX "출력마다 입력 선택 · 멀티뷰·비디오 월·2분할 모드".
- 그림 설명에 "동작 모드: … 중 하나를 골라 씁니다. 그림의 격자는 MATRIX 모드 예시입니다."를 추가합니다(모드 요약은 데이터 원문 그대로).
- 모드 그림에는 원을 쓰지 않습니다. e2e가 크로스포인트 원 개수(입력×출력)를 세기 때문입니다.

## 2. 전송기 그림 범례·그림 설명 (`extenderDiagram`, `rackExtenderDiagram`)

- 케이블 범례를 그림과 같은 점선으로 바꿨습니다(HDBaseT(CATx)·CATx·광케이블).
- 최대 전송 거리는 색 표시 없이 글로만 적습니다. 범례 셋째 값 `'none'`을 새로 추가했습니다. 사양 이름에 이미 "전송 거리"가 들어 있으면 앞말을 다시 붙이지 않습니다(SPX-TX/RX).
- 펼치는 "그림 설명"을 추가하고, 같은 내용을 SVG `aria-label`에도 넣었습니다.
  - 일반 송·수신기: 입력(소스 → TX HDMI IN, 규격·해상도) → 전송(케이블·커넥터) → 출력(RX HDMI OUT → 디스플레이) → 최대 전송 거리 → 그 외 신호
  - XDM-CTR100: 조합 1(CIS100·COS100 카드 직결, XDM-PSU 전원)·조합 2(PSE 1:1 연장)
  - XDM-CTR100 PSE: PSE 조합과 "CIS100·COS100 카드에는 PSE가 아닌 CTR100" 주의
  - SPX-R6: 모듈 6개 구성·PoC·IR 제어·전원 어댑터·CAT5e 기준 거리
- 그림 설명에 쓴 값은 기존 `io`·`specifications`와 그림 안에 이미 있던 문구만 씁니다(새 사실 없음). XDM-PSU 그림은 전송기가 아니어서 이번 범위에서 뺐습니다.
