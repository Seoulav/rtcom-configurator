## 3. 변경 내용

- **T1:** `--pg-muted:#8A8A8E` → `#6A6A6F`.
- **T2:** 인쇄·보고서 제외 187곳(12px 151, 13px 34, 14px 2). 랙 슬롯 번호(`.rt-rack-slot-no`)도 11px → 12px이며 XDM-144(슬롯 72개)에서 칸을 넘치지 않았습니다.
- **T3:** 그라데이션 6곳을 `linear-gradient(135deg,#3370e6,#6d5cf0)`로, 그림자 4곳을 `#4f62ea33`으로 바꿨습니다.
- **T4:** `--rt-accent:#0057D8`(29줄), 단색 `#3978ee` 29곳을 `var(--rt-accent)`로, 반투명 12곳을 `#0057d8`+같은 투명도로, `.rt-brand-mark`를 `linear-gradient(150deg,#0A84FF,#5E5CE6 55%,#BF5AF2)`로 바꿨습니다. `#2f63c8`(마우스 올림)과 제품정보 `--pg-accent:#007AFF`는 그대로입니다.
- **T6:** `.rt-step:disabled{opacity:1;color:#6A6A6F}`, `.rt-step:disabled i{opacity:.7}` 추가. 다른 비활성 버튼의 투명도는 그대로입니다.
- **T7:** 720px 이하에서 `.rt-top-links .rt-meta`를 숨기고 `.rt-tools`를 한 줄 가로 스크롤로 바꿨습니다. `appVersion()`은 숨겨진 요소의 글자(textContent)를 읽으므로 동작에는 영향이 없습니다.

### 3.1 원래 값으로 되돌린 규칙(지시서 "칸을 넘치면 그 규칙만 되돌림" 예외)

- `.rt-palette-tile .rt-sig-badge`(03 카드 정보의 3열 카드 타일): 신호 배지 글자를 9.5px로 둡니다. 390px에서 타일 안 모델명은 원래 칸보다 길어(`strong`이 줄바꿈 없이 한 줄) 오른쪽으로 넘치는데, 배지를 12px로 올리자 넘침이 7px 더 늘어 GitHub 검사(e2e)에서 페이지 가로 넘침 6px이 났습니다(로컬은 0px, 글꼴·렌더링 차이). 타일 글자를 칸에 가두는 방법은 모델명이 "XI"처럼 잘려 읽을 수 없어 쓰지 않았습니다.
- 모델명 잘림은 수정 전에도 있던 문제입니다(타일이 3열이라 안쪽 폭 59px, 모델명 약 75px). 3열 → 2열 또는 줄바꿈 같은 개선은 이번 범위가 아니라 따로 제안합니다.
- `.rt-report`(보고서 본문 12.5px)와 `.rt-report .rt-sig-badge`(8.5px): 인쇄 보고서에 쓰이므로 이전 값 그대로입니다.
