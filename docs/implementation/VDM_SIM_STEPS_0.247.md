# VDM 분할 화면 시뮬레이터 단계형 개선 (0.247.0)

## 1. 요청

- 사용자 지적 2026-10-17(휴대폰 화면 캡처 첨부): "07, 부분은 좀 이해가 안되 xdm처럼 개선해줘".
- 캡처에는 07 카드가 탭과 안내 문장만 보이고 그 아래 그림·커맨드가 비어 있었고, 아래 08 카드는 정상이었습니다.

## 2. 원인

- **안쪽이 빈 문제:** 07 안쪽은 `src/quad-view.js`·`src/vdm-wall.js`가 그립니다. 사용자 휴대폰에 예전 `index.html`(두 스크립트 태그가 없는 판)이 캐시에 남고 새 `products.js`만 받아지면 두 모듈이 없어 안쪽이 비고, 오류 없이 안내 문장만 남습니다. 같은 상황을 시험에서 재현했습니다(index.html에서 태그를 지우고 열면 안쪽 0칸).
- **이해하기 어려운 구성:** 정상 화면도 큰 카드 8장 + 큰 미리보기 + 입력칸 4개 + 설정 칸 5개 + 커맨드 6줄이 한 번에 길게 이어져 무엇을 먼저 해야 하는지 알기 어려웠습니다.

## 3. 변경

- `src/quad-view.js`·`src/vdm-wall.js`: 화면을 XDM 시뮬레이터처럼 "사용 순서 3칸 → ① 모양(월 크기) → ② 칸마다 넣을 입력(배열 확인) → ③ 커맨드" 단계형으로 다시 짰습니다. 쿼드뷰는 작은 그림 8개 + 큰 미리보기 1개, 레이아웃이 쓰는 채널만 입력칸을 보여 줍니다. 출력 번호·번호 자릿수·입력 연결 끄기·베젤 보정은 `<details>` "고급 설정"으로 접고 펼침 상태를 유지합니다. 명령 문자열과 데이터 규칙은 그대로입니다.
- `src/products.js`: 안내 문장을 짧게 줄이고, `mountSplitSims()`가 두 모듈이 없으면 `?v=시간`을 붙여 직접 불러온 뒤 그리며, 끝내 못 불러오면 "새로고침" 안내를 보여 줍니다.
- `src/styles.css`: 사용 순서 칩·단계 제목·작은 그림 격자·입력 칸·고급 설정 스타일.
- 시험: e2e에서 단계 구조(사용 순서 3칸·①②③·그림 8개·미리보기 1개·입력 4칸·고급 설정 접힘)와, index.html에서 두 태그를 지운 상태에서도 07이 채워지는 것을 확인합니다. 기존 쿼드뷰·월 시험은 고급 설정을 펼친 뒤 값을 바꾸도록 맞췄습니다(총 281건 통과).

## 4. 되돌리기

- 위 4개 파일(`quad-view.js`·`vdm-wall.js`·`products.js`·`styles.css`)과 시험을 되돌리면 0.246의 한 화면 구성으로 돌아갑니다. 명령 규칙과 데이터는 바뀌지 않았습니다.
