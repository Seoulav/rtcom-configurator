# Analog Way 방식 화면 개편 1·2단계 (0.8.0)

- 요청: "https://www.analogway.com/configurator 와 거의 비슷하게" + 사용자 제공 XDM 사진 압축 파일
- 기준 커밋: `0228125` (0.7.0 병합)
- 참고 범위: Analog Way 구성기의 화면 흐름과 조작 방식(섀시 카드 선택, 후면 슬롯 클릭, 팝업 선택, 요약)만 참고했습니다. Analog Way의 이미지·로고·문구·코드는 사용하지 않았습니다. Analog Way 사이트는 작업 환경 브라우저에서 인증서 문제로 열리지 않아, 페이지 원문(단계 구성, 카드 선택 방식)으로 흐름을 확인했습니다.

## 사용자 제공 자료

| 자료 | 수량 | 처리 |
|---|---|---|
| 입력 카드 후면 판넬 (HI, HIS, DPI, CIS, FIS, SIS) | 6 | 판넬 금속면만 잘라 1200px WebP |
| 출력 카드 후면 판넬 (HOS, DPOS, COS, FOS, SOS, WOS) | 6 | 〃 |
| 프레임 전면 (XDM-12, XDM-36) | 2 | 배경 투명 영역 제거 후 WebP |

- 원본은 약 30MB, 결과는 약 420KB입니다. 원본은 `.source-materials/`(Git 제외)에 두고 저장소에는 넣지 않았습니다.
- 가공 스크립트 `scripts/tools/prepare_xdm_images.py`로 같은 결과를 다시 만들 수 있습니다. 판넬 위로 튀어나온 기판 부품과 흰 배경은 "가로폭의 85% 이상을 채우는 줄"만 판넬로 인정하는 방식으로 제외했고, 판넬 안의 얇은 밝은 줄에서 끊기지 않도록 폭의 2% 이하 틈은 이었습니다. 12종 모두 약 1200×125(가로:세로 ≈ 9.7:1)로 맞췄고 눈으로 확인했습니다.
- 기존 카탈로그 추출 카드 JPG 12장은 판넬 사진으로 교체했습니다.

## 화면 변경

| 단계 | 이전 | 이후 |
|---|---|---|
| 02 섀시 | 목록 + 미리보기 | 전면 사진 카드 그리드. 입력·출력 슬롯 수, 최대 채널. 전면 사진이 없는 모델은 제품군 사진, 슬롯 자료가 없는 모델(XDM-288, SPX, VDM)은 "슬롯 구성 제조사 확인 필요" |
| 03 카드 | 논리 슬롯 도식 + 오른쪽 카드 목록 + 매뉴얼 사진 상시 표시 | 후면 랙 그림(랙 귀, 입력·출력 뱅크, 전원·제어부). 빈 슬롯을 누르면 카드 선택 팝업(`<dialog>`). 장착 슬롯에 실제 판넬 사진. 오른쪽 구성 요약. 매뉴얼 사진은 "비교하기"로 접음 |

- 랙 배치는 매뉴얼 후면 사진 기준입니다: XDM-12는 가로 카드(왼쪽 입력·오른쪽 출력), XDM-20·36은 세로 카드(왼쪽 입력·오른쪽 출력), XDM-72·144·216은 세로 카드(위 입력·아래 출력, 한 줄 18슬롯).
- 세로 슬롯의 판넬 사진은 CSS container query 단위(`cqh`, `cqw`)로 슬롯 크기에 맞춰 -90° 회전합니다.
- XDM-144·216은 랙이 매우 길어지므로 랙 폭을 `2040px / 줄 수`로 제한하되 최소 560px(슬롯 약 26px)를 보장하고, 좁은 화면에서는 랙 영역만 좌우로 밉니다.
- 슬롯 이름은 "IN 1", "OUT 1"로 줄이고 전체 이름은 `aria-label`과 `title`에 둡니다.

## 접근성

- 팝업은 `<dialog>`의 `showModal()`을 사용해 뒤 화면을 비활성화합니다. 열리면 현재 장착 카드(없으면 첫 카드)에 포커스를 둡니다.
- Esc, 닫기 버튼, 바깥 영역 클릭, 카드 선택, 슬롯 비우기 중 어느 것으로 닫아도 누른 슬롯 버튼으로 포커스가 돌아옵니다.
- 팝업이 열린 상태는 저장하지 않는 화면 전용 값(`modalSlot`)이라 저장 파일과 실행 취소 기록에 영향이 없습니다.

## 유지한 계약

LocalStorage key `rtcom.configuration.v1`, JSON schema 3, `catalogVersion`, 슬롯 ID(`in-1`…`out-54`, `in-a`…), 구성기 3/21/26, 계산 로직(`core.js`)은 변경하지 않았습니다. 옛 `chassisView`, `cardsViewV3`는 새 함수로 대체되어 삭제했습니다.
