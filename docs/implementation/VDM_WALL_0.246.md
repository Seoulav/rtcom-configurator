# VDM 비디오 월 시뮬레이터 (0.246.0)

## 1. 요청과 결정

- 사용자 요청 2026-10-17 "VDM Quad는 진행해줘" → 확인 질문에서 "VDM 월만"을 선택하셨습니다(VDM 쿼드뷰는 0.245에 이미 공개, SPX 월 시뮬레이터는 보류).
- 같은 날 "XDM자막 기능 커멘드가 있어?": 있습니다. 제품정보 XDM 08 설정 명령의 "입력 OSD 자막(`ID`)"·"출력 OSD 자막(`OD`)"(Command Guide 68·69쪽)이며 이번에 바꾼 것은 없습니다. 형식 `*255IDI001M01S"Camera 1"!`, 글자 최대 20자, 모드 M00 끄기 · M01·02·03 글자 크기 1·2·4배 · M11·12·13 타임코드(`S"01:05:45"`) 1·2·4배, 입력·출력 범위 지정(`I001-004`) 가능.

## 2. 근거 (VDM 국문 사용자 매뉴얼 KV07, 인쇄 쪽 번호)

| 항목 | 명령·내용 | 쪽 |
|---|---|---|
| 월 카드 | VDM-HOS4S-UW: HDMI 4포트, 최대 1920x1080@60Hz | 44 |
| 월 만들기·1:1 복원 | `*255W11O0112H04V03!` · `*255W11O0112H01V01!` | 85·86 |
| 2×2 월 | `*255W11O0104H02V02!` | 87 |
| 월 여러 개 | `*255W21H02V02O0101O0202O0703O0804H02V02O0301O0402O0903O1004H02V02O0501O0602O1103O1204!`(출력 12개, 2×2 월 3개) | 87 |
| 베젤 보정 | `*255B02O0112D20202020!` · `*255B01O04D08080808!` | 88 |

- W21의 `O` 뒤 숫자는 "출력 번호 + 월 안의 칸 번호(왼쪽 위부터 가로 순서)"이고, 출력은 월 N개를 가로로 나란히 놓은 디스플레이 배열을 왼쪽 위부터 가로로 센 번호입니다(87쪽 표: H1~H6 × V1~V2에 출력 1~6 / 7~12).
- 매뉴얼 예시는 제품 ID를 `999`로 적었고 이 사이트의 VDM 명령은 `255`를 쓰므로 `255`로 만들었습니다.

## 3. 만든 것

- `src/vdm-wall.js`(`RtVdmWall`, 새 파일): `normalize`·`cellsOf`·`commandsFor`(순수 함수), 디스플레이 배열 SVG(월마다 다른 영상, 칸마다 출력 번호), 화면(프리셋 3개·월 개수·가로·세로·시작 출력·번호 자릿수·베젤 4값, 복사·AMX 구성에 담기), 탭 연결.
- 제품정보 VDM "07 분할 화면 시뮬레이터"(이전 "07 쿼드뷰 시뮬레이터")를 "쿼드뷰 · QOS4S-U | 비디오 월 · HOS4S-UW" 두 탭 카드로 바꿨습니다. 카드 번호 07, 주소 `#rt-quad-sim`, 아래 AMX 카드(08)는 그대로입니다. 상단 버튼 이름은 "분할 화면 시뮬레이터"입니다.
- 오류 처리: 출력이 256번을 넘으면 명령 대신 오류 문구, 99를 넘는데 2자리면 경고, 3자리 번호는 "매뉴얼에 예가 없는 이은 예시" 경고.
