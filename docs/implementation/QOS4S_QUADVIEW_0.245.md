## 3. 만든 것

- `src/quad-view.js`(`RtQuadView`, 새 파일): 레이아웃 8종·타이밍 25종 표, `commandsFor()`(입력 연결 C → 타이밍 → 레이아웃 순서), 도해 카드, 시뮬레이터 화면. 그림은 QMS 06 화면 구성 모드와 같은 모니터 그림(`RtMonitorLayoutSvg`)을 씁니다. 칸 번호 자리에는 입력 번호(`IN3`)를 적고 칸 색은 채널(C1~C4)로 구분합니다.
- 제품정보 VDM 시리즈 "07 쿼드뷰 시뮬레이터"(AMX 카드는 08로 이동): 레이아웃 8종 선택, 출력 번호·타이밍·번호 자릿수(2·3자리), C1~C4에 넣을 입력, "카드 첫 출력 포트"(입력 연결 명령용), 명령 복사, "AMX 구성에 담기"(아래 08 카드의 내 AMX 구성에 쌓임).
- QOS4S-U 카드 상세 팝업(구성기·제품정보)과 02 신호 구성 칸, 구성기 VDM 출력 카드 선택 팝업 팁에서 "쿼드뷰 레이아웃 보기" 팝업(8종 도해, 설정 순서, 커맨드)을 엽니다. "제품정보에서 커맨드 만들기"는 팝업을 모두 닫고 시뮬레이터로 이동합니다.
- QMS-44UX 06 쿼드 뷰 카드에 "칸 번호는 출력 번호 기준(1 좌상 · 2 우상 · 3 좌하 · 4 우하)입니다. 입력을 바꾸지 않으면 칸 1~4 = 입력 1~4번입니다." 한 줄을 더했습니다.

## 4. QMS-44UX 안내 문구를 "칸 번호 = 입력 번호"가 아닌 "출력 기준"으로 쓴 이유

- 44UX 매뉴얼 21쪽: QUAD 모드의 화면 구성은 출력 기준이고(1번 출력 좌측 상단 · 2번 우측 상단 · 3번 좌측 하단 · 4번 우측 하단), 입력은 [QUAD IN : 1 2 3 4]가 기본이며 출력에 연결할 입력을 매트릭스 모드와 같은 방식으로 고릅니다.
- 따라서 칸 번호가 입력 번호와 같은 것은 입력을 바꾸지 않은 기본 상태뿐입니다(0.243 보고에서 "칸 번호가 곧 입력 번호"라고 한 것을 이 근거로 바로잡았습니다). 88UX는 Q1 = 입력 1~4번, Q2 = 입력 5~8번으로 고정이라 0.243의 그룹 전환이 맞습니다.

## 5. 알티컴 확인 대기 (질문 29번)

- 매뉴얼에 없는 것: C1~C4가 카드의 어느 출력 포트에 대응하는지, `OQ`의 출력 번호가 매트릭스 출력 포트인지 카드의 HDMI 번호인지.
- 그래서 입력 연결(C) 명령은 사용자가 정한 "카드 첫 출력 포트"부터 C1~C4를 순서대로 둔 예시로만 만들고, 화면 안내(`FIELD_NOTE`)에 확인 대기라고 적었습니다. 입력 연결 명령은 체크로 끌 수 있고, 타이밍·레이아웃 명령은 매뉴얼 예시와 같은 형식입니다.
- 질문 문안: `docs/handoff/RTCOM_QUESTIONS_2026-10-16.md` 29번, 추적: `docs/handoff/OPEN_ITEMS.md`.
