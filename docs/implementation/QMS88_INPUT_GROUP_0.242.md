# QMS-88UX 쿼드 뷰·듀얼 입력 그룹 전환 (0.242.0)

## 1. 요청과 결정

- 사용자 요청 2026-10-16 "다음 단계 진행해줘". 직전 질문("QMS-88UX 분할 구성시 있어?")에 이어, 분할 도해에 입력 번호를 보여 주는 소규모 개선(제안 2번)을 진행했습니다.
- 시뮬레이터식 자유 배치는 만들지 않습니다. QMS-88UX 분할은 매뉴얼의 고정 레이아웃(쿼드 14종·듀얼 3종·월 4종)이라 끌어 놓는 방식과 맞지 않습니다.

## 2. 근거

- 매뉴얼 KV.04 22쪽 Output Option 목록: "Q1은 입력 1~4번 포트로 구성된 4분할 화면 세트, Q2는 입력 5~8번 포트로 구성된 4분할 화면 세트". 20~21쪽의 도해 칸 번호(1~4)는 그룹 안의 순서입니다.
- 그래서 Q1을 고르면 칸 1~4 = 입력 1~4번, Q2를 고르면 칸 1~4 = 입력 5~8번으로 표시합니다. 칸이 4개보다 적은 레이아웃(PBP 등)도 도해 번호 그대로 같은 규칙을 적용했습니다. 입력 옵션(우선순위·비율)이 실제로 어느 입력을 고르는지는 매뉴얼에 칸 단위로 적혀 있지 않아 따로 표시하지 않았습니다.

## 3. 변경

- `src/products.js`: `multiviewGroupToggle()`로 QMS-88UX의 QUAD·DUAL 카드에만 전환 버튼을 넣고, `layoutShapeSvg(..., group)`가 Q2일 때 칸 글자를 5~8로 바꿉니다. 8분할 레이아웃을 고르면 버튼을 숨깁니다(`isEightSplit`). 레이아웃 칩 클릭 처리는 카드 안에서 미리보기를 찾도록 바꿨습니다.
- `src/styles.css`: `rt-pg-group-toggle` 한 줄 스타일.
- `scripts/e2e-smoke.cjs`: Q1·Q2 전환, 8분할 숨김, 레이아웃을 바꿔도 Q2 유지, 듀얼 Q2(5,6), WALL 카드에 버튼 없음을 확인합니다(269건 통과).

## 4. 되돌리기
