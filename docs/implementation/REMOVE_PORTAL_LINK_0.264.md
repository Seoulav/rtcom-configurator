- `index.html` 머리(`.rt-top-links`)에서 `AV Portal에서 제품 찾기 ↗` 링크(`https://seoulav.github.io/AV-Portal/`, 0.7부터)를 지웠습니다. 오른쪽 버전 표기(`AV 시스템 설계 도구 · CATALOG BASED · 0.264`)는 그대로 둡니다.
- `src/styles.css`에서 링크 전용 규칙(`.rt-portal-link` 기본·hover·focus·480px·인쇄)을 지웠습니다. 버전 표기 배치(`.rt-top-links`)와 화면 읽기용 숨김 글자(`.rt-visually-hidden`, 다른 곳에서도 씀)는 남겼습니다.
- `tests/site.test.cjs`: 링크가 있는지 확인하던 줄을, 링크·전용 스타일이 다시 생기지 않았는지 확인하는 줄로 바꿨습니다.

## 바뀌지 않은 것

- 비공개 AV Portal이 이 저장소의 공개 제품 데이터(`data/products/`)를 읽는 구조는 그대로입니다. 화면의 바로 가기 링크만 지웠습니다.
- 지난 문서(CHANGELOG·구현 문서)에 남은 AV Portal 언급은 기록이므로 그대로 둡니다.
