## 설계 판단
- **화면 전환은 주소 조각(`#products`, `#products/<id>`)만 씁니다.**
  - 페이지 이동이 없어 상대 경로 이미지가 깨지지 않고 404도 나지 않습니다. 0.6에서 생긴 문제입니다.
  - 브라우저가 방문 기록을 자동으로 남기므로 뒤로가기가 상세 → 목록 → 구성기 순서로 동작합니다.
  - 구성기의 `pushState`/`replaceState` 규칙(주소 유지)은 바꾸지 않았습니다.
- **데이터 작성 규칙**
  - 카탈로그에 적힌 값만 씁니다.
  - 표기가 서로 다르면 원문 값을 그대로 두고 `REVIEW REQUIRED`와 `issues`로 표시합니다. 29종 중 17종이 해당합니다.
- **내부 정보 차단**: 검증 스크립트가 금지어(단가·원가·거래처·재고 등)가 있으면 실패합니다.
- **제품정보 화면에서 로고를 누르면** 확인 창 없이 구성기로 돌아갑니다. 0.18의 첫 화면 이동 확인 창은 구성기 화면에서만 뜹니다.
- **0.6 주소 `/products`** 는 호환성 계약대로 계속 구성기 첫 화면으로 이동합니다. 제품정보는 `#products`로 엽니다.

## 데이터 작성 방법
- 분류별로 병렬 작성했습니다: 시리즈 3 / 일체형·분배·케이블 13 / 전송기 13.
- 모든 이미지는 눈으로 확인했습니다.
- 카탈로그 충돌은 기존 근거 E23~E26과 새로 찾은 항목을 함께 기록했습니다. 예:
  - QMS-88UX: 해상도 3860 표기, 출력 10포트, 100-200 VAC
  - VDM-80X: 무게 오기 의심
  - XDM: 메인프레임 범위 표기 불일치

## 0.20.0 — 표기 방식 정리 (에이앤미디어 참고)

- 근거: 사용자가 에이앤미디어(antez.co.kr) 알티컴 제품 페이지(HD-14U, 2026-09-27 화면 캡처 제공)를 참고 표기로 지정했습니다. antez.co.kr은 이 작업 환경에서 자동 접속이 막혀 있어(403), 사용자가 캡처한 화면으로 형식을 확인했습니다.
- 반영한 요소
  - 개요 첫 문장을 굵게 강조(에이앤미디어의 "OOO는 ~다" 헤드라인 문구 스타일)
  - "한눈에 보기" 칩(대역폭·해상도·입력·출력): `distribution`·`integrated`·`cable` 그룹에서, 사양에 "대역폭"·"해상도" 항목이 있고 `io`에 HDMI 방향별 수량이 있을 때만 계산해서 보여 줍니다. 전송기·시리즈는 신호가 여러 가지라 표시하지 않습니다.
  - "주요 기능"과 "크기 및 무게"를 나란히 배치. 크기·무게 사양(`group:"Physical"`, `name`이 "무게" 또는 "크기"로 시작)은 제품 사양 표에서 빼서 별도 박스로 보여 줍니다.
  - 제품 사양 표를 "구분(그룹·항목) · 사양(값+단위+검토 배지) · 비고(조건)" 3단으로 정리했습니다. 값과 검토 필요 배지, 조건은 그대로 유지해 카탈로그 표기 충돌 정보를 잃지 않습니다.
- 데이터 파일(`data/products/*.json`)은 바꾸지 않았습니다. `src/products.js`의 `quickFacts`·`isSizeSpec` 함수와 `src/styles.css`만 바꿨습니다.
- 검증: 기존 자동 검사 27+48건 모두 통과. 데스크톱(960px)·휴대폰(390px) 화면을 직접 확인했습니다(분배기 HD-104U, 전송기 XDM-CTR100).
