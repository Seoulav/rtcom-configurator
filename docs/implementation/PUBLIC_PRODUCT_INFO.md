## 설계 판단
- **화면 전환은 주소 조각(`#products`, `#products/<id>`)만 씁니다.**
  - 페이지 이동이 없어 상대 경로 이미지가 깨지지 않고 404도 나지 않습니다. 0.6에서 생긴 문제입니다.
  - 브라우저가 방문 기록을 자동으로 남기므로 뒤로가기가 상세 → 목록 → 구성기 순서로 동작합니다.
  - 구성기의 `pushState`/`replaceState` 규칙(주소 유지)은 바꾸지 않았습니다.
- **데이터 작성 규칙**
  - 카탈로그에 적힌 값만 씁니다.
  - 표기가 서로 다르면 원문 값을 그대로 두고 `REVIEW REQUIRED`와 `issues`로 표시합니다. 29종 중 17종이 해당합니다.
- **내부 정보 차단**: 검증 스크립트가 금지어(단가·원가·거래처·재고 등)가 있으면 실패합니다.
- **제품정보 화면에서 로고를 누르면** 확인 창 없이 구성기로 돌아갑니다. 0.18의 첫 화면 이동 확인 창은 구성기 화면에서만 뜹니다.
- **0.6 주소 `/products`** 는 호환성 계약대로 계속 구성기 첫 화면으로 이동합니다. 제품정보는 `#products`로 엽니다.

  - VDM-80X: 무게 오기 의심

## 0.21.0 — 연결 다이어그램 (에이앤미디어 참고, 데이터 기반 자동 생성)

- 근거: 사용자가 에이앤미디어(antez.co.kr) 제품 페이지의 "연결 다이어그램" 섹션(idx=131 HD-13U, idx=132 HD-104U 화면 캡처, 2026-09-27)처럼 추가해 달라고 요청했습니다. antez.co.kr은 이 작업 환경에서 접속이 막혀 있어(403) 사용자 캡처로 형식을 확인했습니다.
- 그림은 손으로 그리지 않고 `src/products.js`의 `connectionDiagram(item)`이 각 제품의 `io` 배열에서 자동으로 만듭니다. 데이터가 없으면 그리지 않습니다(추측 금지 원칙 유지).
  - **분배기·일체형 매트릭스**(`splitterDiagram`): HDMI IN/OUT 행이 모두 있어야 그립니다. 소스 아이콘 → 기기 박스(모델명·포트 요약) → 디스플레이 아이콘. 입력·출력이 4개를 넘으면 4개까지 그리고 "외 N대"로 남은 수를 붙입니다.
  - **전송기**(`extenderDiagram`): `io[].group`이 `TX ·`/`RX ·`로 시작하는 항목에서 TX쪽 HDMI IN, RX쪽 HDMI OUT, `Transmission` 행(케이블)을 찾아 소스 → TX → (점선 케이블, 광=초록/HDBaseT=주황) → RX → 디스플레이로 그립니다. XDM-CTR100처럼 한 기기가 송신·수신 모드를 겸하는 트랜시버는 `group`에 TX·/RX· 접두어가 없는 것으로 구분해 같은 모델명에 "송신 모드"/"수신 모드"를 붙입니다.
  - 케이블 거리(`specifications`의 "전송거리")가 있으면 케이블 표기 아래에 작게 덧붙입니다. 영상·전송 신호 외의 나머지 단자(오디오·RS-232 등)는 다이어그램 아래에 "그 외 신호(…)는 위 입출력 표를 확인하세요"로 안내합니다.
- 그려지는 21종 / 그려지지 않는 8종
  - 시리즈 3(XDM·SPX·VDM): 카드 슬롯 구성이 있어야 실제 입출력이 정해지므로 단순화하지 않습니다.
  - MR-4S: 슬롯에 끼우는 모듈에 따라 달라지는 프레임이라 `io`가 없습니다.
  - 케이블 4종: 단자 정보를 개별 항목으로 관리하지 않습니다.
  - OBHD-2C는 원래 Transmission(광 커넥터) 행이 없어 그려지지 않았는데, 카탈로그 41쪽의 입력·출력단자 표(HDMI+LC connector 병기, TX/RX 미구분)를 근거로 일반적인 광 익스텐더 구조(TX가 광으로 내보내고 RX가 광을 받음)에 따라 TX·Transmission OUT / RX·Transmission IN 행을 추가했습니다. 추정임을 `issues`(I2)에 남겼고 `packageStatus`는 그대로 VERIFIED입니다(추정한 것은 방향 배정뿐, 커넥터 자체는 카탈로그 원문).
  - CT103-U-H/CR103-U, FT103-U-H/FR103-U(벽부형)는 사용자 지시(2026-09-27, "에이앤티 웹사이트나 알티컴 카탈로그 참고해")로 카탈로그를 다시 확인했습니다. 카탈로그 23·27쪽 제품사양표에 TX의 Input Signal("DVI / HDMI (TMDS), 3.5mm Stereo Audio")·Output Signal(광은 "Fiber Optical Output")이 텍스트로 명시돼 있어, 이를 근거로 TX 영상·오디오 입력과(FT103-U-H는) 광 출력·RX 광 입력·RX 오디오 출력 행을 수량 1로 추가했습니다. 카탈로그 사진에는 TX 쪽에 형태가 비슷한 단자가 2개 보이지만 표·본문에 구분 설명이 없어, 둘째 단자의 존재·용도(예: 로컬 HDMI 패스스루)는 추정하지 않고 issues에 남겼습니다. 광 커넥터 형식(SC/LC 등)도 원문에 없어 적지 않았습니다.
- 휴대폰 대응: SVG는 `min-width:620px`를 두어 좁은 화면에서도 글자가 작아지지 않게 하고, 다이어그램 영역만 가로로 스크롤합니다(페이지 전체는 가로 스크롤 없음). 기존 후면 랙 사진의 스크롤 안내 문구와 같은 방식입니다.

## 참고 자료 우선순위 (사용자 확인 2026-09-27)

에이앤미디어(antez.co.kr)는 이 작업 환경에서 자동 접속이 계속 막혀 있습니다(403). 사용자가 "연결 다이어그램은 알티컴 브로셔 활용해도 돼"라고 확인해, 표기 형식(레이아웃·범례 등)은 antez.co.kr 화면 캡처를 참고하되, **실제 값의 근거는 알티컴 종합 카탈로그(브로셔) 원문을 1차로 쓴다**는 방침을 확정합니다.

- antez.co.kr 화면 캡처(사용자 제공)가 있으면 형식(표 구성·연결 다이어그램 레이아웃 등) 참고 자료로 쓴다.
- 실제 사양·단자 값은 알티컴 종합 카탈로그 원문을 근거로 채운다. 자동 접속이 막혀 있어 antez.co.kr 페이지를 직접 대조하지 않는다.
- 카탈로그 원문이 모호하거나 사진·본문이 어긋나면 값은 그대로 두고 `REVIEW REQUIRED`/`issues`로 표시한다(0.19 §데이터 작성 규칙과 동일).
