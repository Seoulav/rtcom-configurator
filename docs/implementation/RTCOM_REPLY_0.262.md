- 사용자가 알티컴 통합 메일(2026-10-18 발송, 11건)에 대한 회신을 번호별 질문 아래에 붙여 전달했습니다(2026-10-26). 알티컴이 번호 아래에 직접 적은 답을 사용자가 그대로 옮긴 것이라, 이 문서의 "회신"은 알티컴 직접 회신으로 적습니다.

## 3. 이전 결정과 달라진 점

- **QMS-44UX의 IP 변경**: 사용자 확인(2026-10-18)은 "IP는 커맨드로 못 바꾸고 장비에서 직접 설정"이었고 LAN 제품 5개에 같은 문구를 넣었습니다(0.251). 이번 알티컴 회신에 QMS-44UX의 IP·게이트웨이·서브넷 설정 명령이 있어, **QMS-44UX만** 제조사 회신을 따라 "설정 명령(N)으로 바꿀 수 있고 DHCP 지원"으로 바꿨습니다(`lan.ipChange: "command"`). QMS-88UX는 회신("네트워크 명령은 터치 화면에서만")이 기존 문구와 맞고, XDM·VDM·SPX는 이번 회신 범위 밖이라 그대로입니다.
- **QMS-88UX 월 2개 한 줄 이어 쓰기(0.248)**: 매뉴얼 35쪽 첫 예시가 한 줄이었지만 알티컴은 월마다 따로 설정하라고 답해, 이어 쓰기를 없앴습니다. `walls` 검사(칸 수·범위 경고)는 월 1개 기준으로 그대로 씁니다. 0.248 문서(`QMS88_WALL_TWO_0.248.md`)는 기록으로 두고 이 문서가 대체합니다.
- **매뉴얼 19쪽 "2×2 월 최대 2개"(0.152)**: 회신("출력 10개 안에서 조합 자유")과 달라 06 WALL 요약을 바꿨습니다. 월 개수 상한은 회신에 없어 적지 않았습니다.

## 4. 답이 없어 남긴 것과 추정한 것

- 질문 16(HOS100 `L13`), 21(SPX 4건), 22 ①(`OT` 예시 `T02P04`와 표 불일치), 26(HDS 뮤트·볼륨 범위), 27(XDM-MR4S)은 전달된 글에 답이 없어 대기입니다.
- 22 ①: 알티컴이 표(T02 = 1920x1200, T03 = 720x480P)만 다시 보내고 어느 쪽이 오기인지 답하지 않아, 사이트는 표를 그대로 따릅니다.
- **VDM 월 끄기**: 알티컴은 `W10`이 Wall Off라고만 답했습니다. 사이트의 "월 끄기" 줄은 월 만들기 줄에서 `W11`을 `W10`으로만 바꾼 예시이고(월이 둘 이상이면 `W21` → `W20`은 이를 이어 유추), 화면에 장비에서 확인하라고 적었습니다.
- **QMS-88UX 사용자 레이어**: 회신 예는 창 1개(`M0`)와 창 4개(`M2`)뿐입니다. `M1`의 창 개수와 크기·위치 범위는 모릅니다. 창 2~4를 선택 입력으로 열어 두고 범위는 예시가 놓인 3840×2160 안으로 잡았으며, 입력·크기·위치는 모두 적거나 모두 비우도록 검사합니다.
- **자막**: 크기(0~2)와 색(0~5)이 무엇을 뜻하는지는 회신에 없어 번호만 보여 줍니다.
- 회신 속 `WO01-04`는 `OW` 명령의 오타로 읽었습니다(사이트의 기존 `OW` 명령과 같은 형식).

## 5. 구현 메모

- `src/control-example.js`: 명령 빌더에 `text`의 `quote:false`(따옴표 없는 자막 문구, `!`·따옴표·줄바꿈 제거)와 `allOrNone`(묶음 매개변수는 모두 적거나 모두 비움) 기능을 더했습니다. 쪽 번호가 없는 근거(알티컴 회신)는 "매뉴얼" 말머리 없이 보여 줍니다. QMS-44UX IP 안내 분기(`ipChange: "command"`)를 더했습니다.
- `src/vdm-wall.js`: `commandsFor`가 `off`(월 끄기 줄)를 돌려주고 화면에 "월 끄기 · Wall Off(W10)" 블록과 복사·AMX 담기 버튼이 생겼습니다.
- `src/products.js`: QMS-88UX 06 WALL 칩 "2×2 + 3×2"(출력 1~4번 + 5~10번).
- 제품 JSON 3개(`qms-88ux`·`qms-44ux`·`vdm`)와 표기 통일 도구 결과(`3840x2160`)를 반영했습니다. 질의서 문서(`docs/RTCOM_MANUFACTURER_DATA_REQUEST.md` §5, `docs/handoff/RTCOM_QUESTIONS_2026-10-16.md`)와 `docs/handoff/OPEN_ITEMS.md`에 회신과 남은 항목을 정리했습니다.
