# 0.253.0 AMX 장비 IP 칸 기본값 채움 (2026-10-18)

## 1. 요청과 원인

- 사용자 요청 2026-10-18: "QMS-88UX 제어 시 디폴트 IP 192.168.1.141이 안 되어 있어, 알티컴 LAN 제어 전 제품 동일하게 디폴트 IP를 넣어 줘."
- 0.252에서 AMX 코드의 `cDeviceIp`는 이미 기본값 `192.168.1.141`이 들어갔지만, 화면의 "장비 IP 주소" 입력 칸은 값이 비어 있고 흐린 안내 글자(placeholder)로만 같은 주소가 보였습니다. 그래서 사용자에게는 기본 IP가 설정되지 않은 것으로 보였습니다.

## 2. 변경

- `src/control-example.js`: `commOf`가 저장된 값이 없으면 `DEFAULT_IP`(192.168.1.141)를 돌려줍니다. 입력 칸 `value`가 이 값이라 칸에 실제 주소가 채워집니다. 같은 `commOf`와 `commBarHtml`을 쓰는 LAN 제어 제품 5종(XDM·SPX·VDM·QMS-44UX·QMS-88UX) 전부에 똑같이 적용됩니다.
- 기본값 그대로이면 AMX 코드 주석은 "(알티컴 장비 기본 IP, 현장에서 IP를 바꿨다면 변경)"으로 나옵니다. 직접 다른 값을 넣으면 주석 없이 그 값이 들어갑니다. 형식이 틀린 값은 기본값으로 돌아갑니다(코드 주입 방지 그대로).
- HDS-42MU·HDS-21U는 직렬 전용이라 IP 칸이 없습니다.
- 사용자가 칸을 비우면 코드와 다른 입력 칸에는 기본값이 보이고, 입력 중인 칸은 그대로 유지됩니다.

## 3. 검증

- 단위 테스트: 기본 `commOf`가 `ip: '192.168.1.141'`, 5종 제품의 `commBarHtml`에 `value="192.168.1.141"`이 있는지 새 테스트로 확인했습니다. 기존 주석 기대값(예시 → 알티컴 장비 기본 IP)을 맞췄습니다.
- 화면 시험과 나머지 기본 검증 명령은 PR 설명에 결과를 적습니다.

## 4. 되돌리기

`commOf`의 `v.ip||DEFAULT_IP`를 `v.ip||''`로 되돌리고 `ipGiven` 판정과 시험 기대값을 맞추면 됩니다(PR revert로도 가능).
