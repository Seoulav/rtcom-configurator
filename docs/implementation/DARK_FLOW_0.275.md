# 0.275 다크 모드 ③ 1차: Signal Flow 그림

## 요청과 결정

- 사용자 질문(2026-11-24): "다크모드에서 깔끔하게 이미지 볼 수 있게 개선할께 있다고 너가 그랬는데 그것도 무슨내용인지 다시 설명제안해줘"
- 제안: A안(그림별 다크 색, 단계별), B안(흰 판 눈부심만 줄이기), C안(그대로 둠)
- 사용자 결정: "a로 진행해줘". 1차는 가장 많이 보이는 03 Signal Flow 그림과 크게 보기 창입니다.

## 배경

- 0.238(다크 모드 ②)은 그림 SVG에 색이 직접 적혀 있어 일괄 변환이 어려웠습니다. 그래서 다크에서도 그림 판 7종에 흰 판을 깔았습니다.
- 그 결과 다크 화면 한가운데에 흰 사각형이 남았습니다.

## 방식

- 그림 코드의 색 250곳을 하나씩 고치지 않았습니다. 다크 블록 안에서 CSS가 그림 속 색을 요소별로 바꿔 칠합니다.
  - CSS 규칙은 SVG 속성 색보다 우선합니다.
  - 규칙은 `@media screen and (prefers-color-scheme:dark)` 안에만 있습니다. 그래서 라이트 화면과 인쇄는 그대로입니다.
- `src/products.js`의 `diagramWrap`이 Signal Flow 그림 `<svg>`에 `class="rt-pg-flow-svg"`를 붙입니다. 크게 보기 창은 이 svg를 복사하므로 클래스가 함께 옵니다.
- `scripts/tools/dark_tokens.cjs`
  - `PLATES`(흰 판 목록)의 `.rt-pg-svg-wrap>svg`·`.rt-flow-zoom-canvas svg`에 `:not(.rt-pg-flow-svg)`를 붙였습니다. Port Map 사진 그림 등은 흰 판을 유지합니다.
  - `FLOW_DARK` 바꿈표에서 규칙을 만듭니다(`node scripts/tools/dark_tokens.cjs --apply`).
  - 크게 보기 창의 그림 칸은 카드색 `#1C1C1E` 작업판으로 창 바탕(`#2C2C2E`)과 구분합니다.
