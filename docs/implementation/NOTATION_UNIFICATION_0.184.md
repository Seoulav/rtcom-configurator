# 0.184 사이트 전체 표기 통일(해상도·단위·케이블·용어)

## 1. 경위

- 2026-09-30 사용자가 사이트 전체의 용어·표기 통일을 외부 검수(ChatGPT)로 확인하고 싶다고 요청했습니다.
- Claude가 화면 문구 5,079행을 CSV로 뽑아 드렸고, 사용자가 ChatGPT 검수 결과(상세 1,850건, 사양값 확인 필요 8그룹)를 이 대화에 올렸습니다.
- Claude가 결과를 원본과 대조한 뒤, 기준이 정해지지 않은 항목은 사용자에게 물어 아래와 같이 정했습니다.

## 2. 표기 기준(사용자 결정 2026-09-30)

| 항목 | 기준 | 예 |
|---|---|---|

Extron 표기는 Extron 공개 사양서(DTP HDMI 4K 330 Tx/Rx, DTP HDMI 4K 230)에서 확인했습니다: `4K/60 @ 4:4:4`, `2560x1600 @ 60 Hz`, `1080p/60`. 단위 띄어쓰기만 사용자 결정(붙여 쓰기)을 따릅니다.

XDM 연결 전송기 4종의 04 사양 "최대 해상도"는 값 `4K/60`, 조건 `4:4:4`(0.110의 값·조건 구조 유지)입니다.

## 3. 적용 방법

- 변환 규칙은 `scripts/tools/unify_notation.cjs`에 있습니다. 화면에 나오는 제품 데이터 항목과 `src/*.js`의 따옴표 안 문자열만 바꾸고, 주석·출처·검증 기록은 건드리지 않습니다.
  - 픽셀 해상도는 실제 해상도 목록(640~4096 × 480~2160)만 대상으로 해서 크기 표기(483×402)를 바꾸지 않습니다.
  - `1080p 60m`, `4K 50m`처럼 뒤에 m이 오는 숫자는 전송거리라서 주사율로 보지 않습니다.
  - `4K 30Hz를`처럼 Hz가 빠지며 숫자로 끝나면 조사를 받침에 맞춥니다(`4K/30을`).
- 04 제품 사양 표는 값과 단위를 붙여 그립니다(`src/products.js` `unitGap`, 영어 낱말 단위 `hours`만 띄움). 01 한눈에 보기 해상도 칸은 `4K` + `/60 @ 4:4:4`로 보여 줍니다.
- 결과: 데이터 약 360곳, 코드 문자열 약 45줄이 바뀌었습니다. 다시 돌리면 "바뀔 곳 0건"입니다(단위 테스트로 확인).
- 화면 글꼴(Pretendard)이 숫자 사이 `x`를 `×` 모양으로 그리므로, 화면에서는 `3840×2160`처럼 보일 수 있습니다. 데이터는 `x`입니다.
