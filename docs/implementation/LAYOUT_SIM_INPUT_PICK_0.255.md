# 0.255.0 화면 연출 시뮬레이터 입력 선택 목록 (2026-10-18)

## 1. 요청

- 사용자 요청 2026-10-18: 다음 단계 제안 2번("구성기 연동 선택 목록")과 "1~2번 진행해줘". 0.254에서 입력 번호가 구성기 CH 번호임을 설명하고 범위 밖 경고를 넣은 데 이어, 번호를 외워 숫자로 넣는 대신 목록에서 고르게 합니다.

## 2. 변경 (`src/layout-sim.js`, `src/styles.css`)

- **선택 목록:** 구성기가 이 브라우저에 저장한 XDM 구성에 입력 카드가 있으면, 표의 "입력" 칸이 숫자 칸 대신 채널 목록 선택으로 바뀝니다. 한 줄은 `입력 5 · IN 2 · XDM-HI100 · PC`(채널 번호 · 입력 슬롯 · 카드 · 신호명)입니다. HOS100과 WOS100 표가 같은 함수(`inputControl`)를 씁니다.
- **신호명:** 구성기 03 "② 신호 입력"에 적은 신호명(`portAssignments`의 `assignedDevice`, 24자까지)을 목록에 붙입니다. 신호명을 적지 않은 채널은 카드까지만 보입니다.
- **이름 자동 채움:** 창의 "이름" 칸이 비어 있을 때만, 입력을 고르면 그 채널의 신호명으로 채웁니다. 이미 적은 이름은 바꾸지 않습니다.
- **직접 입력:** 목록 마지막의 "직접 입력…"을 고르면 그 행만 숫자 칸으로 바뀌고 옆에 "목록" 버튼이 생깁니다. 구성에 없는 번호를 시험하거나 다른 구성을 쓸 때 필요합니다. 목록에 없는 현재 값은 `입력 50 · 구성기에 없음` 항목으로 남아 값이 사라지지 않고, 켜진 창이면 주황 테두리로 표시합니다(0.254 경고와 같음).
- **저장된 구성이 없거나 XDM이 아니면** 지금까지처럼 숫자 칸입니다. 표 아래 안내 문장에 목록 사용법을 덧붙였습니다.
- 순수 함수: `savedInputChannels`가 `list`(채널마다 번호·슬롯·포트·카드·신호·신호명)와 `byN`을 함께 돌려주고, `inputChoiceLabel`이 목록 한 줄을 만듭니다.

## 3. 경계

- 구성기 저장 구성은 읽기만 하며 저장 형식(schema 3)은 그대로입니다. 다른 PC·브라우저의 구성은 읽지 못합니다.
- 출력 카드·전송기는 목록에 넣지 않습니다(입력 카드 채널만).
- "직접 입력" 상태는 화면을 다시 불러오면 목록으로 돌아갑니다(저장하지 않음).

## 4. 검증

- 단위 테스트: 채널마다 슬롯·카드·신호명이 있는 목록(공백 제거, 24자 제한, 빈 슬롯 번호 건너뜀, 출력 카드 제외), 화면 소스에 선택·전환·자동 채움 연결.
- 화면 시험: 저장된 구성이 없으면 숫자 칸 4개, 있으면 목록 4개(옵션 9개: 채널 8 + 직접 입력), 창 2에서 입력 6을 고르면 이름이 `CAM1`로 채워지고 연결 커맨드에 `I006O002`가 들어감, 직접 입력 전환·50 입력 시 경고·목록 복귀(`구성기에 없음`), WOS100도 목록.

## 5. 되돌리기

PR을 revert하면 0.254(숫자 칸) 상태로 돌아갑니다. 커맨드 문자열과 저장 형식은 바뀌지 않았습니다.
