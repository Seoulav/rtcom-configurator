# QMS-44UX·QMS-88UX 설정 명령 빌더 (0.234)

사용자 요청 2026-10-16: "1~2번 진행해"(0.231 보고의 다음 단계 1번 "QMS 나머지 명령 확장", 2번 "모듈러 매트릭스 진행").
이 문서는 1번입니다. 2번은 0.235 문서(`CONTROL_EXAMPLE_MODULAR_0.235.md`)에 남깁니다.

## 1. 무엇을 만들었나

0.231의 "AMX 통합 제어 커맨드 예시" 카드(QMS-44UX·QMS-88UX) 아래에 **설정 명령 패널**을 더했습니다. 명령을 코드에 하드코딩하지 않고 제품 JSON `controlExample.builders`에 정의하면 화면이 만들어지는 **명령 빌더** 구조입니다.

- 명령을 고르면 그 명령의 매개변수(드롭다운·숫자·번호 목록 "1-4,8")가 나타나고, 값을 바꾸는 즉시 명령 문자열·HEX·AMX `SEND_STRING` 한 줄이 갱신됩니다. 복사 버튼이 있고 선택값은 이 브라우저에만 기억합니다(`rtcom.controlExample.<제품 id>.builder`).
- 번호 목록은 매뉴얼 방식으로 줄입니다. 3개 이상 이어진 번호는 범위(`O01-10`), 그 밖에는 번호마다 적습니다(`O04O08`).
- 입력이 비었거나 범위 밖이면 명령을 만들지 않고 안내 문구를 보여 줍니다.

| 명령 | 예 | 근거 예시 |
|---|---|---|

| 출력 테스트 패턴 `OT` | `*255OTO03M01!`, `*255OTO01-04M06!` | 34쪽 |
| 입력 테스트 패턴 `IT` | `*255ITI03M04!`, `*255ITI01-04M07!` | 32쪽 |
| 비디오 월 `OW` | `*255OWO01-06M13H02V03O01O02O03O04O05O06!`(해상도 생략 가능) | 35쪽 |
| 멀티뷰 `Q` | `*255QM13L01S00!`, `*255QM10L07S02!` | 39쪽(옵션 표 38~39쪽) |
| 출력 초기화 `OR` | `*255ORO01-04!`, `*255ORO05!` | 36쪽 |
| 출력 정보 `OF` | `*255OFO01!` | 33쪽 |

## 2. 한계

- Wall(0~7)·Dual(0~2) 레이아웃 번호와 이름의 대응은 매뉴얼에 적혀 있지 않아 번호로만 표시했습니다.
- 88UX 멀티뷰 입력·출력 옵션 설명은 38~39쪽 표를 줄여 옮겼습니다(원문 표현이 일부 겹쳐 있어 옵션 번호를 앞에 붙임).
- 넣지 않은 명령: 88UX 사용자 레이어(M)·자막(SE·ST)·네트워크·볼륨 확인·펌웨어 확인·공장 초기화, 44UX 네트워크 설정(N) 등. 화면에 밝혔습니다.
- 매뉴얼이 이미지형 PDF라 해당 쪽을 이미지로 렌더링해 직접 읽었습니다.
