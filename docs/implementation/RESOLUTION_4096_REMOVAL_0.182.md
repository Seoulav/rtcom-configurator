# 0.182.0 4096×2160 표기 정리

사용자 결정 2026-09-30: "4096 X 2160 해상도 표기된거 전수 조사해줘" → 선택지 B("B로 진행해줘"). 0.110의 "4096은 잘 사용하지 않아서 모든 양식에서 빼자"를 XDM 전송기 4종에서 화면 전체로 넓혔습니다.

## 남긴 것과 이유
- CHANGELOG·감사·QA·장부·옛 시안(`docs/mockups`)의 4096: 과거 결정의 근거 기록.
- `src/products.js:71` 필터 정규식 `/4096|3840|4k/i`: 데이터에서 4096이 사라져도 `3840`·`4k`가 함께 있어 분류는 그대로.
- `src/products.js:1273` PDF canvas 한 변 4096px 한도: 해상도 표기가 아님.
- 제조사 매뉴얼의 4096×2160 원값: `docs/audit/CATALOG_MANUAL_CONFLICTS_2026-09-28.md`에 남아 있음.

## 주의
- VDM 전송기·카드는 제조사 매뉴얼이 4096×2160(DCI 4K)을 적었지만 화면에는 3840×2160(UHD) 기준으로만 표기합니다. 0.86의 "매뉴얼 값으로 통일" 중 해상도 숫자는 이번 결정으로 대체됩니다.
