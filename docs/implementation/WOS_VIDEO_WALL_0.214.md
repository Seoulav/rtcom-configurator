# 0.214 XDM-WOS100 레이어 구성도: 카드 4장 · 4K 디스플레이 4대(2×2)

## 요청

사용자 요청(2026-10-13, 팝업 화면 사진 첨부): "WOS카드 팝업설명인데 여기에서 출력 디스플레이를 4K 네 판으로 표시하고 레이어 4개를 연출한 화면으로 해줘. 그러면 WOS 카드를 네 장을 쓰는 거겠지. 이렇게 해야지 이해되지. 이렇게 하면은 HOS 카드랑 크게 차이점이 없어"

0.207의 구성도는 WOS100 카드 1장의 OUT 1이 디스플레이 1대에 레이어 4개를 겹치는 그림이었습니다. 이 그림은 HOS100 멀티뷰(출력 1개에 여러 화면)와 차이가 잘 드러나지 않습니다. 그래서 WOS100의 쓰임새인 비디오 월(Wall Overlay) 구성을 보여 주는 그림으로 바꿨습니다.

## 바뀐 그림(`src/app.js` `layerCompareSvg`·`layerCompareTallSvg`)

| 항목 | 0.207~0.213 | 0.214 |
|---|---|---|
| WOS100 | 카드 1장, 레이어 1~4 → 합성 → OUT 1 | 카드 4장(#1~#4), 카드마다 레이어 1~4 칩과 OUT 1 |
| 매트릭스 | 입력 → 레이어로 바로 이어짐 | 세로 막대 "매트릭스": 소스 1~4를 카드 4장에 모두 분배 |
| 출력 | 디스플레이 1대 | 4K 디스플레이 4대를 붙인 2×2 비디오 월(7680x4320), 카드 n의 OUT 1 → 화면 n |
| 레이어 창 | 디스플레이 1대 안 | 비디오 월 전체에 배치. 레이어 2(PC 2)·레이어 3(카메라)은 화면 경계에 걸침 |
| 동기 안내 | 없음(LED 상자에만) | 비디오 월 아래 "카드 4장 출력 동기(싱크) · 화면 경계에 걸친 레이어도 어긋나지 않음" |
| OUT 2~4 | 회색 점선 상자 | 한 줄 안내 "OUT 2~4: OUT 1과 같은 화면 · 사용 불가"(0.210 알티컴 확인) |

- **신호선:** 모두 한 방향 직선입니다(가로 그림은 수평선, 세로 그림은 수직선). 선끼리 교차하지 않고, 카드 n의 선 끝에 "화면 n"을 적어 비디오 월의 화면 번호와 짝을 맞췄습니다. 소스→입력, 입력→매트릭스, 매트릭스→카드, 카드→화면이 각각 4개라 모두 16개입니다.
- **팝업 안내 문장:** "아래 구성도는 카드 4장이 4K 디스플레이 4대(2×2)를 한 화면처럼 나눠 맡는 예입니다."를 더했습니다.
- **바꾸지 않은 것:** 핵심 수치 띠, 포트 조건 안내 상자, 레이어 배치 예시 6종(출력 1개 기준), LED 모드 상자, 비교표입니다.

## 근거와 한계

- **카드 사이 동기:** 알티컴 확인(사용자 전달 2026-10-13)은 "WOS100 2장 3장 사용 시 S-BOX 1,2 에대한 동기"입니다(0.211). 4장 구성은 사용자 요청에 따른 예시입니다.
- **카드마다 레이어 소스 4개:** 매트릭스는 한 입력을 여러 출력 슬롯에 함께 보낼 수 있으므로 소스 1~4를 카드 4장에 모두 보냅니다. 각 카드는 자기 화면에 걸친 레이어 부분을 냅니다.
