# SPX 매뉴얼 사진 슬롯 (0.11.0)

- 요청: "vdm도 spx도 xdm처럼 카드가 안보인다. 동일한 컨셉으로 하고 싶어" + SPX 국문 사용자 매뉴얼(250805KOR) PDF 첨부
- 근거: 근거 문서 U07 (매뉴얼 pp.5–11)
- 기준 커밋: `0b47026` (main, 0.10.0 병합)

- p.11: HOS12·COS12를 M810·M1620에 장착하면 11·12번 포트는 출력 10번 포트의 분배 역할을 합니다. M3236·M2472·M24120에서는 원래 포트로 동작합니다.

## 변경

- `scripts/tools/extract_spx_manual_assets.py` (새 파일)
  - 매뉴얼 쪽 번호와 쪽 안 이미지 위치로 이미지를 골라 추출합니다.
  - 카드 판넬: HIS8·COS12는 흰 배경이라 기존 `faceplate_band()`로 자릅니다. HOS10·HOS12는 검은 배경이라 테두리와 이어진 검은 영역을 투명하게 빼고 자릅니다.
  - 블랭크 커버: HIS8 판넬의 나사 끝과 금속면으로 합성합니다. `extract_spx_catalog_cards.py`의 `blank_from()`에 판넬 폭 배율(`scale`)을 추가해 재사용합니다.
  - 전면·후면 사진 10장은 원본 픽셀 크기 그대로 WebP로 저장합니다. 슬롯 좌표가 원본 픽셀 기준이기 때문입니다.
- `src/app.js`
  - `frameFronts`에 SPX 5종 전면 사진을 추가했습니다.
  - `rearPhotos`에 SPX 5종 후면 사진과 입력·출력 영역 좌표를 추가했습니다. 좌표는 카드 고정 나사 위치(중심점)와 카드 사이 어두운 경계선으로 측정했습니다.
  - `rackLayout`: M2472·M24120은 `vs`(세로 카드), 나머지 SPX는 `hs`(가로 카드 쌓기)입니다.
  - SPX 세로 랙은 입력(3)과 출력(6/10)의 슬롯 수가 달라 영역마다 열 수를 따로 지정합니다(`--rt-rack-columns`).
  - 카드 슬롯 제목 문구가 세로 랙에서 "왼쪽 입력 / 오른쪽 출력"으로 바뀝니다. 카탈로그 스캔 임시 이미지 안내 문구를 지웠습니다.
- `src/core.js`
  - `SPX_PORT_SPLIT`(WARNING): M810·M1620에 HOS12·COS12를 장착하면 11·12번 포트가 출력 10번의 분배라고 안내합니다.
  - `SLOT_LAYOUT`, `SPX_CARD_ALLOWLIST`, `SPX_RX_POC`의 근거를 매뉴얼 쪽 번호로 바꿨습니다. 카드 혼합 조건과 전송기 판매 SKU는 여전히 확인 필요(UNVERIFIED)로 둡니다.

## 알려진 한계

- M1620 매뉴얼 후면 사진은 가로로 눌려 있습니다(사진 비율 1.58, 실제 483×177mm 비율 2.73). 슬롯은 사진에 맞춰 겹치므로 판넬이 실제보다 두껍게 보입니다. 업체 후면 사진을 받으면 `src`·`size`·좌표만 바꿉니다.
- M2472·M24120 후면 사진은 약 380px로 작아 확대하면 흐립니다. 장착한 카드 판넬은 고해상도 이미지라 선명합니다.
- 매뉴얼 후면 사진에는 카드가 꽂혀 있습니다. 빈 슬롯은 불투명한 블랭크 커버로 덮어 표시합니다.

## 되돌리는 방법

이 PR의 병합 커밋을 revert하면 SPX는 0.10의 그림 랙과 카탈로그 스캔 판넬로 돌아갑니다. 슬롯 ID와 저장 형식은 바뀌지 않았으므로 저장한 구성은 그대로 읽힙니다.
