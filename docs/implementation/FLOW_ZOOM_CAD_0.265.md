# 0.265 Signal Flow 크게 보기 CAD식 이동·확대

## 요청

- 사용자 요청(2026-11-16): "XDM PSU에서 03 시그널 플로우를 확대했을 때 이 확대한 상태에서 화면을 이동하는 게 좀 불편한데 이거 어떻게 개선해줘? 캐드처럼 가능할까?"
- 이전 방식(0.99부터): −/+ 버튼으로 100·150·200·300% 네 단계만 고르고, 화면 이동은 스크롤 막대로만 했습니다.

## 바뀐 것(크게 보기 창이 있는 XDM-PSU·XDM-CTR100 PSE)

| 조작 | PC(마우스) | 휴대폰(터치) |
| --- | --- | --- |
| 화면 이동 | 왼쪽·가운데 버튼으로 끌기(손 모양 커서) | 한 손가락으로 끌기 |
| 확대·축소 | 휠: 마우스가 가리키는 지점을 고정한 채 한 칸에 약 15% | 두 손가락 벌리기·오므리기(두 손가락 가운데 기준) |
| 전체 맞춤 | 두 번 누르기, "맞춤" 버튼, 키보드 `0` | 두 번 누르기, "맞춤" 버튼 |
| 단계 확대 | −/+ 버튼(화면 가운데 기준 1.25배), 키보드 `+`·`-` | −/+ 버튼 |

- 배율: 100%는 그림 전체가 창 안에 들어가는 크기입니다. 이전에는 창 폭 기준이었습니다. 최대 600%이며, 이전 최대는 300%였습니다.
- 작업판: 그림 둘레에 창 크기 절반만큼 연한 회색 여백(`.rt-flow-zoom-stage`)을 두었습니다. 그래서 CAD처럼 그림 가장자리도 화면 가운데까지 끌어올 수 있고, 휠 확대 때 마우스 아래 지점이 밀리지 않습니다. 맞춤을 누르면 그림이 작업판 가운데에 옵니다.
- 머리 아래에 안내 줄을 두었습니다: "끌어서 이동 · 휠로 확대·축소(마우스 위치 기준) · 두 번 누르면 맞춤 · 휴대폰은 두 손가락으로 확대"
- 창 크기가 바뀌면 같은 배율로 다시 맞춥니다(`ResizeObserver`).
- 함께 고친 것:
  - 사진 확대 창(0.260)도 같은 `rt-flow-zoom` 틀을 써서, 예전 코드는 사진 창을 Signal Flow 창으로 잘못 집을 수 있었습니다. 이제 Signal Flow 창만 고릅니다.
  - 손가락을 잡는 처리(`setPointerCapture`)가 실패해도 두 손가락 확대가 이어지게 했습니다.
