# 03 카드 정보 타일 모델명 잘림 개선 (0.230)

## 1. 요청과 근거

- 0.228 보고의 다음 단계 제안("카드 정보 타일을 휴대폰에서 2열로 바꿔 모델명이 끝까지 보이게")에 사용자가 "다음 단계 진행해줘"(2026-10-16)로 답했습니다.
- 0.228 검사 중 발견했습니다. 신호 배지를 12px로 올리자 390px 타일의 모델명이 7px 더 넘쳐 GitHub 검사에서 페이지 가로 넘침이 났고, 그때는 타일 배지만 9.5px로 되돌려 임시로 막았습니다(`docs/implementation/SVT_DESIGN_TOUCH_0.228.md` §3.1). 이번에 근본 원인을 고쳤습니다.

## 2. 원인

- 타일 안쪽 폭: 3열(390px)에서 약 59px. 모델명(`XDM-WOS100` 등)은 12px 굵은 글씨로 약 75~90px.
- 신호 배지와 모델명이 `strong`(줄바꿈 없음) 안에 한 줄로 놓여 모델명이 오른쪽으로 넘쳤습니다. 다음 타일이 위에 그려져 "XDM-H"처럼 보이거나 타일 밖으로 나왔습니다.

## 3. 바꾼 내용(`src/styles.css`만)

| 폭 | 열 수 | 배지·모델명 |
|---|---|---|
| 1280px 이상 | 6열 | 두 줄(배지 위, 모델명 아래) |
| 561~1279px | 3열 | 두 줄 |
| 360~560px | 2열 | 두 줄 |
| 360px 이하 | 2열 | 두 줄 + 모델명 하이픈 줄바꿈 허용 |

- 3열 → 6열 전환 지점을 1100px에서 1279px로 올렸습니다. 1101~1279px에서 6열 타일이 좁아 모델명이 잘렸기 때문입니다(1280px부터는 잘림 없음).
- 0.228의 `.rt-palette-tile .rt-sig-badge{font-size:9.5px}` 예외는 지웠습니다. 배지는 모든 곳에서 12px입니다.

## 4. 검증

- 320, 360, 390, 430, 560, 561, 620, 700, 701, 800, 1000, 1100, 1101, 1200, 1279, 1280, 1440px에서 타일 12개의 글자가 타일 밖으로 나가는지 측정: 수정 후 모두 0건, 페이지 가로 넘침 0건.
- 수정 전(main 0.229) 같은 측정: 320~561px 12/12 잘림, 320px 페이지 넘침 14px·360px 1px, 데스크톱 1101px 12/12 잘림.
- 화면 비교: `docs/qa/card-tile-wrap-0.230/`(390px 수정 전·후).
- 기본 검증 명령 결과는 PR 설명에 있습니다.
