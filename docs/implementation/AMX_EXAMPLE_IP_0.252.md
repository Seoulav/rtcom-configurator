# 0.252.0 AMX 예시 장비 IP를 192.168.1.141로 (2026-10-18)

## 1. 요청과 결정

- 사용자 요청 2026-10-18: "AMX예시쪽에 192.168.1.141로 전부 반영했어?" 질문에 아직 반영하지 않았다고 답한 뒤 요청대로 반영했습니다.
- 이전에는 AMX 코드의 `cDeviceIp`에 비어 있을 때 예시 주소 `192.168.1.100`이 들어갔고, IP 입력 칸의 안내 글은 `192.168.1.xxx`였습니다.

## 2. 변경

- `src/control-example.js`: 예시 주소를 상수 `DEFAULT_IP = '192.168.1.141'` 하나로 모았습니다. IP 칸을 비워 두면 모든 AMX 코드(XDM·VDM·SPX·QMS-44UX·QMS-88UX의 설정 명령, 장바구니 "내 AMX 구성", 직접 입력 예시)가 `cDeviceIp[] = '192.168.1.141'`을 적고 "예시, 현장 IP로 변경" 주석을 답니다. IP 입력 칸의 안내 글(placeholder)도 같은 값입니다.
- 사용자가 IP 칸에 직접 넣은 값(형식이 맞는 것만)은 그대로 쓰고, 형식이 틀리면 예시 주소로 돌아갑니다(코드 주입 방지는 그대로).
- HDS-42MU·HDS-21U는 직렬 전용이라 IP가 나오지 않습니다.
- 안내 문구의 "기본 대역은 192.168.1.xxx"는 그대로 둡니다. 예시 주소만 바꾼 것입니다.

## 3. 경계

- 회사 내부의 IP 사용 순서(장비가 2대면 `.142`처럼)는 사내 정보라 이 저장소에 적지 않았습니다. 화면의 값은 "예시"입니다.
- 장비가 여러 대일 때 장비마다 다른 주소를 자동으로 나누지는 않습니다. 필요하면 IP 칸에 직접 넣습니다(IP 칸은 제품(시리즈)마다 하나이고 이 브라우저에 기억됩니다).

## 4. 검증

- 단위 테스트: 예시 주소 기대값을 `192.168.1.100` → `192.168.1.141`로 바꿨고(비워 둠, 잘못된 형식), 직접 입력한 값 시험은 그대로 통과합니다.
- 화면 시험(`scripts/e2e-smoke.cjs`), 제품 색인, 표기 통일 검사, 버전 검사는 기본 검증 명령으로 확인합니다.

## 5. 되돌리기

`DEFAULT_IP` 값을 `192.168.1.100`으로 되돌리고 시험 기대값을 맞추면 됩니다(PR revert로도 가능).
