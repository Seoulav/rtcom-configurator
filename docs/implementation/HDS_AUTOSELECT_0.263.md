# 0.263 HDS-42MU·HDS-21U 오토 셀렉팅(펌웨어 개선) 반영

## 요청과 근거

- 사용자 전달(2026-10-28): 알티컴이 펌웨어를 개선해 HDMI가 들어온 소스로 자동 전환되게 했고, 서울영상테크 SI사업본부가 시험했습니다.
  - 정상 동작 판단 근거: HDMI를 연결하면 연결한 소스로 채널이 바뀌고, HDMI를 빼면 이전 소스로 채널이 바뀝니다.
  - HDS-42MU:
    - 딥 스위치 3번 ON(출력 미러 모드)이면 OUT1·OUT2가 동시에 바뀝니다.
    - 3번 OFF(출력 별도 스위칭 모드)이면 OUT1만 자동으로 바뀝니다.
  - HDS-21U: 오토 셀렉팅이 정상 동작합니다.
- 사용자 요청: "이 내용을 가능하게 됐다라는 내용을 업데이트해 줘", "오토 스위칭 모드에 대해서 조금 손쉽게 표현해 줄 수 있으면 좋겠어".

## 바뀐 것

- **08 오토 셀렉팅 카드(두 제품, 새 카드):** 사용자 확인(2026-10-28 "딥스위치와 상관없이 오토셀렉팅이야")대로 딥 스위치 설정과 관계없이 동작하므로, 07 딥 스위치 설정 다음 별도 카드로 두었습니다. 제목 옆에는 "딥 스위치 설정과 관계없이 동작"을 표시합니다.
  - 안내 문장: "HDMI를 새로 꽂으면 그 입력으로 바로 바뀌고, 빼면 바로 전에 보던 입력으로 돌아갑니다. 버튼이나 리모컨을 누르지 않아도 됩니다."
  - 3단계 그림(사용자 확인 "HDMI케이블 뽑으면 이전 소스로 넘어가는거야"):

    | 단계 | 그림 | HDS-42MU | HDS-21U |
    | --- | --- | --- | --- |
    | ① 평소 | 입력 1번에 HDMI, 화면 "입력 1" | 같음 | 같음 |
    | ② HDMI를 꽂으면 | 새 케이블(초록), 화면 "입력 3"(파랑) | 입력 3번 | 입력 2번 |
    | ③ HDMI를 빼면 | 뺀 케이블(회색 점선 ×), 직전 소스 "입력 1"로 복귀 | 같음 | 같음 |

  - HDS-42MU만, 그림 아래에 **"딥 스위치 3번에 따라 자동으로 바뀌는 출력"** 두 칸을 둡니다. 시험 결과대로 OUT 1·OUT 2 모니터를 그리고, 자동으로 바뀌는 출력은 파랑, 그대로인 출력은 검정으로 표시합니다.
    - 3번 ON · 출력 미러 모드: OUT 1·OUT 2 동시 전환
    - 3번 OFF · 출력 별도 스위칭 모드: OUT 1만 자동 전환, OUT 2는 그대로
- HDS-42MU 07 딥 스위치 3번 ON·OFF 설명에 사용자 표현(출력 미러 모드·출력 별도 스위칭 모드)과 오토 셀렉팅 동작을 덧붙였습니다. 딥 스위치 2번 설명은 매뉴얼 Ver.1.0 문장 그대로 둡니다.
- AMX 통합 제어 커맨드 예시 카드는 08에서 09로 한 칸 밀렸습니다.
- 05 주요 기능(두 제품): "오토 셀렉팅 지원(새로 꽂은 HDMI 입력으로 자동 전환, 빼면 이전 입력으로 복귀)"을 Priority 줄 앞에 더했습니다.
- 소개 문장(lead): "Priority 오토셀렉팅과"를 "새로 꽂은 HDMI로 바로 바뀌는 오토 셀렉팅·Priority와"로 바꿨습니다.
