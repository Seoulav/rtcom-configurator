# 0.277 다크 모드 ③ 3차: 06 화면 구성 모드·시리즈 02 신호 구성·WOS100 레이어 그림

## 요청

- 사용자 요청(2026-11-24): "3차 진행해줘". 0.276 보고의 다음 단계 제안입니다.
- 이 3차로 B단계 다크 모드 ③(그림 다크 대응)을 마칩니다.

## 방식(0.275·0.276과 같음)

- 다크에 맞출 그림의 바깥 `<svg>`에 `class="rt-pg-dark-svg"`를 더했습니다.
  - `src/products.js`
    - QMS-44UX·QMS-88UX 06 화면 구성 모드의 크로스포인트 그림(`rt-pg-layout-matrix`)
    - XDM·SPX·VDM 시리즈 02 신호 구성 그림(`seriesSignalSvg`)
  - `src/app.js`
    - XDM-WOS100 레이어 구성도(넓은 화면 `rt-layer-svg-wide`, 휴대폰 `rt-layer-svg-tall`)
- `scripts/tools/dark_tokens.cjs`
  - `PLATES`의 `.rt-pg-svg-wrap>svg`·`svg.rt-pg-layout-matrix`·`svg.rt-layer-svg-wide`·`svg.rt-layer-svg-tall`·크게 보기 창에 `:not(.rt-pg-dark-svg)`를 붙여 흰 판 고정에서 뺐습니다.
  - 0.275 `FLOW_DARK` 바꿈표가 그대로 적용됩니다(본문 글자 `#1c1c1e`·`#1f2532` → `#F5F5F7`, 흰 칸 → 짙은 회색).
  - 새 색 세 개를 `DARK_PARTS`에 더했습니다. 모두 글자(`text`)에만 적용합니다.
    - 연동 전송기 점선 칩 이름(CTR100 TX·FT101 등) `#3A3A3C` → `#AEAEB2`. 같은 색의 `rect`(오디오 설정 칸 받침)는 바꾸지 않습니다.
    - WOS100 레이어 구성도에서 남색 상자 밖의 회색 설명(입력 카드 목록·겹침 순서 등) `#56627A` → `#AEAEB2`
    - WOS100 레이어 구성도의 카드 출력 동기 안내 `#1C4F8A` → `#8FB4FF`
- 규칙은 다크 블록 안에만 있습니다. 라이트 화면과 인쇄는 그대로입니다.
