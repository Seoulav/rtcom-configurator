# XDM-COS100 카드 판넬 사진 교체 (0.202.0)

## 요청

사용자 요청 2026-10-06: "XDM 시리즈 국문 사용자 매뉴얼 KV08 P18 COS카드 모양과 지금 COS카드 이미지가 서로 틀려서 이거 수정해줘"

## 차이

| 구분 | 포트마다 단자 |
|---|---|
| 예전 사진 `output/design/assets/cards/XDM-COS100.webp` | LED + RJ45 + 피닉스 3핀(`L ⏚ R`) |
| 매뉴얼 KV08 18쪽(인쇄 쪽 번호 16) | LED + RJ45 + 피닉스 5핀(`+ − L ⏚ R`, 오디오 추출 및 PoE) |

04 카드 사양(`src/card-specs.js`)과 XDM-PSU 03 Signal Flow 그림은 이미 "피닉스 5핀"으로 되어 있어, 사진만 사양과 달랐습니다.

## 처리

1. 공개 매뉴얼 `output/design/assets/docs/xdm-manual.pdf` 18쪽에 들어 있는 COS100 원본 사진(1214×136, PDF 안에서 90도 돌아가 있음)을 그대로 꺼내 바로 세웠습니다. 새로 찍거나 그린 그림이 아닙니다.
2. 사진 아래쪽 검은 줄과 판넬 바깥 검은 배경(테두리와 이어진 부분)만 투명하게 하고, 다른 XDM 카드와 같은 1200×122로 맞췄습니다.
3. 판넬 좌우 끝을 다른 출력 카드(HOS100 등)와 같은 5~1190px로 가로 방향만 맞췄습니다. `align_xdm_cards.py`는 초록 커넥터 분포로 맞추는데 5핀은 3핀 기준 카드와 모양이 달라 쓰지 않았고, RJ45·나사 위치가 예전 사진과 거의 같아 끝점만 맞췄습니다.

비교 그림: `docs/qa/xdm-cos100-plate-0.202/before-after.webp`(위 예전, 아래 새 사진)
