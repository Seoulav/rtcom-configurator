# XDM "내 AMX 구성"(커맨드 장바구니) (0.237)

사용자 요청 2026-10-16: "2번 진행하자 쉽게 설명해줘"(0.236 보고의 다음 단계 2번 "XDM 설정 명령과 07 화면 연출 시뮬레이터 명령을 한 구성으로 묶어 AMX 코드로 내보내기").

## 1. 쉬운 설명

- 전에는 07 시뮬레이터에서 만든 커맨드와 08 카드 "설정 명령"에서 만든 커맨드를 따로 복사해 AMX 코드에 직접 합쳐야 했습니다.
- 이제 두 곳 모두에 **담기 버튼**이 있어서, 필요한 커맨드를 눌러 담아 두면 08 카드의 **"내 AMX 구성"**에 순서대로 쌓입니다.
- 쌓인 목록은 터치 패널 버튼 1번, 2번, 3번… 순서의 **AMX 코드 하나**로 바로 만들어지고, 복사하거나 `.axs` 파일로 저장할 수 있습니다.
- 순서는 ↑ ↓로 바꾸고, 필요 없는 항목은 ×로 뺍니다. 목록은 이 브라우저에 저장되어 새로고침해도 남습니다.

## 2. 무엇이 바뀌었나

| 위치 | 변경 |
|---|---|
| 07 화면 연출 시뮬레이터(XDM) | WOS100·HOS100·전체 커맨드 3개 화면의 커맨드 줄에 **AMX 구성에 담기** 버튼. WOS100은 OW 한 줄, HOS100은 입력 연결(C)과 OQ 레이아웃 두 줄, 전체 커맨드는 포함한 카드의 줄 전부(`amxItems`) |
| 08 AMX 통합 제어 카드 "설정 명령"(XDM·SPX·VDM) | 명령 결과 옆에 **+ 구성에 담기** 버튼 |
| 08 카드 아래 "내 AMX 구성" | 담은 항목 목록(버튼 번호·이름·커맨드·출처), ↑ ↓ ×, 한 개의 AMX 코드, 코드 복사, 파일 저장(`rtcom-<시리즈>-amx.axs`), 전부 비우기 |

- 시뮬레이터 담기는 XDM 시리즈에만 있습니다(SPX·VDM에는 시뮬레이터가 없음). 설정 명령 담기와 "내 AMX 구성"은 같은 빌더를 쓰는 SPX·VDM에도 함께 생겼습니다.
- QMS-44UX·QMS-88UX 카드(설정 명령 패널은 있지만 "내 AMX 구성"은 없음)에는 담기 버튼을 넣지 않았습니다.

## 3. 규칙과 한계

- 새 명령 문법은 만들지 않았습니다. 시뮬레이터와 설정 명령이 만든 문자열을 그대로 담고, AMX 코드는 기존 `amxCode` 규칙(명령마다 `BUTTON_EVENT[dvTP,n]`와 `SEND_STRING`, 끝에 `$0D`)을 따릅니다.
- 문장형 명령(SPX 커맨드 2처럼 매뉴얼에 Enter가 없는 형식)은 `enter:false`로 담겨 `$0D`를 붙이지 않습니다.
- 같은 문자열은 한 번만 담고, 최대 60개까지 담습니다(넘으면 알림).
- 저장은 브라우저 `localStorage`(`rtcom.amxBasket.<시리즈 id>.v1`)뿐이며, 저장소를 쓸 수 없으면 그 화면을 보는 동안만 메모리에 둡니다. 기기 사이에는 공유되지 않습니다.
- `.axs` 파일은 UTF-8입니다. 한글 주석이 NetLinx Studio에서 깨져 보이면 `//` 주석 줄만 지우면 되고 동작에는 영향이 없습니다. NetLinx Studio에서 직접 열어 확인한 것은 아닙니다.
- AMX 장치 번호(`5001:1:0`)와 터치 패널 장치(`dvTP`)는 기존과 같은 일반 예시이며 현장에 맞게 바꿔야 합니다.
