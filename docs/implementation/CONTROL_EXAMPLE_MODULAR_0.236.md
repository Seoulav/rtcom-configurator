# 모듈러 매트릭스(XDM·SPX·VDM) AMX 통합 제어 커맨드 예시 (0.236)

사용자 요청 2026-10-16: "1~2번 진행해"(0.231 보고의 다음 단계 2번 "모듈러 매트릭스 진행"). 1번(QMS 설정 명령)은 `CONTROL_EXAMPLE_QMS_CMD_0.234.md`입니다.
사용자 확인: "SPX·VDM 메뉴얼 보면 커맨드 방법이 안내되어 있어" → 저장소에 이미 공개된 매뉴얼로 진행했습니다(`input_doc/` 자료 불필요).

## 1. 무엇을 만들었나

제품정보 XDM·SPX·VDM **시리즈 페이지** 맨 아래(XDM은 07 화면 연출 시뮬레이터 다음 08, SPX·VDM은 07)에 "AMX 통합 제어 커맨드 예시" 카드를 더했습니다. 헤더에 "AMX 커맨드 예시" 이동 버튼도 있습니다. 프레임이 커서(최대 수십~수백 포트) 0.231의 클릭 표 대신 **명령 빌더**(0.234)만 씁니다: 명령을 묶음별로 고르고 값을 넣으면 매뉴얼 형식의 문자열·HEX·AMX `SEND_STRING`이 만들어집니다. 위쪽에 통신 설정과 AMX 시작 코드(`DEFINE_DEVICE`·`SET BAUD`)도 보여 줍니다.

빌더 엔진(`src/control-example.js`) 확장: 입력 1개 × 출력 목록의 **연결·해제 쌍**(`route`, 예 `I001O001-007,I001O009`), **문장형 템플릿**(`template`, SPX 커맨드 2), **번호 자릿수 선택**(`variants`, VDM 2·3자리), 텍스트 매개변수(OSD 자막), 쉼표 목록(`comma`), 고정 숫자(`lit.num`), 명령 묶음(`group`), 명령별 제품 ID(`productId`), Enter 없음(`enter:false`).

| 시리즈 | 번호 | 통신 | 명령 수 | 근거 |
|---|---|---|---|---|
| XDM | 3자리, ID 255 | 가이드 67쪽 응답 예시 115200bps·패리티 None·스톱 1비트(데이터 비트는 가이드에 없음) | 18 | Command Guide 1013 2~22·67~69쪽 |
| SPX | 3자리, ID 255 | 115200bps 8N1(매뉴얼 20쪽 화면 사진에서 선택된 값) | 30(커맨드 1: 16, 커맨드 2: 14) | 매뉴얼 20·28~51쪽 |
| VDM | 2자리(VDM-128X·256X는 3자리), ID 255 | 19200bps 8N1 공장 출고값(매뉴얼 53쪽) | 26 | 매뉴얼 53쪽·67~84쪽 |

- **XDM(18)**: 연결 `C`·해제 `D`·프리셋 `PC`(1~20)·상태 `?V`, 입력 영상 타이밍 `?IF`·정보 `IF`·오디오 `IA`·영상 스트림 `IV`·테스트 패턴 `IT`·리셋 `IR`·OSD 자막 `ID`, 출력 정보 `OF`·해상도 `OS`·영상 스트림 `OV`·테스트 패턴 `OT`·화질 `OG`·OSD `OD`, 시스템 조회(`?SID`·`?SNA`·`?SRA`·`H000`·`?VERSION`). 월 오버레이(OW)·멀티뷰(OQ)는 같은 페이지의 07 화면 연출 시뮬레이터가 맡습니다.
- **SPX(30)**: 커맨드 1(`*255…!`)은 연결·해제·프리셋·상태·입력 정보·입력 볼륨·출력 정보·해상도·영상 스트림·화질·쿼드뷰·비디오 월(만들기·끄기)·베젤·CEC·출력 볼륨(설정·확인)·펌웨어. 커맨드 2(문장형 `s in 1 av out 2!`)는 입력→출력 연결·프리셋 저장·불러오기·삭제·월 만들기·월 입력 전환·월 끄기·쿼드뷰 켜기·끄기·CEC·EDID 지정·조회.
- **VDM(26)**: 연결 `C`·`VC`·`AC`, 해제 `D`·`VD`·`AD`·전체 해제 `ALLIO`, 상태 `?`·`A?`(입력·출력·전체), 입력 영상 소스 `IV`·오디오 `IA`·모니터링 `IM`·정보 `IF`, 출력 오디오 `OM`·`OS`, 테스트 패턴 `OT`, 정보 `OF`, 쿼드뷰 `OQ`(타이밍·레이아웃), 신호 리셋 `OZ`, 볼륨 `AV`·확인 `AF`, 보레이트 `@`, 터치 잠금 `K`, 연결 확인 `H000`, 펌웨어 `*999?version!`.

## 2. 한계와 매뉴얼 안의 불일치

- **SPX 월 생성(문장형)**: 형식 줄은 `s wall v set hdiv …`인데 예제는 `s wall 2 hdiv 3 …`로 `set`이 없습니다. 장비에서 확인이 필요해 화면에서 둘 중 고르게 했고 기본은 예제 형식입니다.
- **VDM 테스트 패턴(OT)**: 예시 `T02P04`를 "720x480p, 256 Gray"로 설명했지만 같은 매뉴얼 표에서 T02는 1920x1200, 720x480p는 T03입니다. 표를 기준으로 했습니다.
- **VDM 해제**: 일부 예시가 출력 범위에 `~`를 쓰지만(`O03~06`) 일반 규칙(하이픈)을 따라 `-`로 만듭니다.
- **SPX 커맨드 2**: 매뉴얼에 Enter가 적혀 있지 않아 붙이지 않았고(HEX·SEND_STRING도 CR 없음), 번호 범위는 매뉴얼에 적힌 값(입력 1~16, 출력 0~16)을 따랐습니다. 재부팅(s reboot)·공장 초기화(s reset)는 위험해 넣지 않았습니다.
- **SPX 프리셋(커맨드 1)** 번호 범위, **XDM 데이터 비트**는 자료에 없어 화면에 밝히거나 일반값(8)으로 적었습니다.
- 번호 목록에서 이어지지 않는 번호는 매뉴얼 OS 예시 방식(`O001O004`)으로 O를 반복합니다.
- 넣지 않은 명령은 각 카드 아래 "이 카드에 넣지 않은 명령"에 밝혔습니다(XDM 출력 오디오·RS-232+·쿼드뷰·월·CEC·이미지 편집, SPX 일부 네트워크 조회, VDM 익스텐더 제어·네트워크 설정 등).
