# 신호 색 통일 0.239

## 근거
- 사용자 제공 구성도(2026-10-16, 컨퍼런스룸 AV 구성도 260903 PDF) 범례에서 뽑은 색: 광 `#00B0F0`, SDI `#000000`, LAN `#00B050`, HDMI `#FF0000`, A.AUDIO `#7030A0`, USB `#0000FF`, 접점 `#E97132`.
- 사용자 선택(2026-10-16): "내가 그리는 구성도 범례 색상이 첨부파일이야 그거로 최대한 유사한게 좋고 추천하는 레드 좋아보여" → DP는 추천안 신호 레드 `#E5242B`.

## 바꾼 것
| 신호 | 구성기 신호 배지(이전 → 0.239) | 제품정보 신호 구성도·전송기 그림(이전 → 0.239) |
|---|---|---|
| HDMI | `#002060` 그대로 | `#007AFF` → `#002060` |
| DP | `#FF0000` → `#E5242B` | `#5E5CE6` → `#E5242B` |
| SDI | `#000000` 그대로 | `#E08A20` → `#000000` |
| HDBaseT·CATx(LAN) | `#00B050` 그대로 | `#1E9E52` → `#00B050`(전송기 그림 CAT 케이블 포함) |
| 광 | `#00B0F0` 그대로 | `#30B0C7` → `#00B0F0`(전송기 그림 광케이블 포함) |

- HDMI는 범례에서 빨강이지만 DP가 빨강을 쓰므로 0.170 사용자 요청("HDMI 색상을 남색으로 하면 어때?")대로 남색을 유지했습니다.
- DP `#E5242B`는 흰 글자 대비 4.55:1로 순색 `#FF0000`(4.0:1)보다 읽기 좋습니다.
- 다크 화면에서는 신호 배지와 제품정보 범례 점에 옅은 테두리를 둡니다(SDI 검정·HDMI 남색이 묻히지 않게, `scripts/tools/dark_tokens.cjs` 손 규칙).
- 그대로 둔 것: 입력·출력을 뜻하는 파랑·보라(신호 종류가 아님), 멀티뷰 보라, 장비 상태 LED 초록, 전원 주황.

## 검증
- `tests/signal-colors.test.cjs`: 구성기 배지·제품정보 `--pg-sig-*`·전송기 케이블 색이 위 표와 같은지 확인.
- 라이트·다크 화면 촬영(구성기 03, XDM 02 신호 구성, XDM-FT101/FR101 Signal Flow).
