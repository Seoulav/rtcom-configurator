# 0.209 XDM 시리즈 Command Guide 공개 · 알티컴 기술 회신(제품 사실) · 커맨드 가이드 근거 특장점

## 요청

- **알티컴 기술 회신:** 사용자가 알티컴 담당자의 기술 회신 메일(특정 현장용 커맨드 안내)을 붙여 넣고 반영 범위를 물었습니다. 사용자 결정(2026-10-13)은 세 가지입니다.
  - 반영 범위: "제품 사실만 공개 반영"
  - 회신 메일의 출력 9~12번 카드: XDM-HOS100
  - WOS100 레이어를 쓸 때 나머지 포트: "불가 (HOS100과 같음)"
- **커맨드 가이드:** "XDM 시리즈 Command Guide야 이것도 보기/다운로드 버튼 넣어줘"(알티컴 `RTcom_XDM_Command_Guide_1013.pdf` 첨부). 공개 범위를 다시 묻자 사용자는 "공개 진행"을 골랐습니다.
- **제어 분석:** "HOS, WOS출력카드를 어떻게 제어가능한지? 입력소스가 들어왔을때 인식해서 AMX통합제어 보낼수 있는 기능이 있는데 그부분이 있는지 분석해줘". 분석 결과는 대화로 보고했고, 이 문서 §5에 남깁니다.
- **특장점:** "우리 만든 사이트 넣을만한 특장점 같은게 있는지도 찾아봐죠", "대표적인 입력자막기능 이런거 라든지". 사용자는 후보 네 가지(OSD 자막(입력·출력), HOS100 레이아웃 14종, WOS100 LED 모드·로고, 운영 기능 묶음)를 모두 골랐습니다.

## 2. 알티컴 기술 회신에서 반영한 제품 사실

| 사실 | 반영 위치 |
|---|---|

- 회신 메일의 현장 이름
- 특정 현장의 커맨드 값: 입력 HPD 끄기·켜기, 가이드 EDID 표에 없는 EDID 번호, 모니터링 화면 배치 좌표
- Genlock 해상도: 현장 설정이라 넣지 않았습니다.

## 3. WOS100 레이어 포트 제한(사용자 확인 "불가 (HOS100과 같음)")

WOS100 레이어도 HOS100처럼 카드 출력 포트 자원을 함께 씁니다.

| 레이어 수 | 포트 상태(합성 화면을 1번 포트에 낼 때) |
|---|---|
| 4개 | 1번 합성 · 2~4번은 1번과 같은 화면이 나와 사실상 사용 불가 |
| 2개 | 1·2번, 3·4번이 짝입니다. 1번에 쓰면 2번 사용 불가, 3·4번은 따로 사용(3번에도 레이어 2개를 쓰면 4번 불가) |
| 3개 | 아직 확인되지 않았습니다(`docs/handoff/OPEN_ITEMS.md`, 제조사 질의서 Q6). |

- **팝업 안내 상자:** "확인 중" 문구를 "레이어는 카드 출력 포트 자원을 함께 씁니다(HOS100과 같음)"로 바꾸고 2개·4개 규칙과 3개 미확인 사실을 적었습니다.
- **포트 칩:** 레이어 배치 예시 6종마다 HOS100 팝업과 같은 포트 칩(1~4번: 합성·불가·1번 동일·사용)을 붙였습니다. 색은 파랑(합성)·빨강(불가)·회색(1번 동일)·초록(사용)입니다.
- **예시 조정:** 레이어 3개 조건을 모르므로 0.207의 3레이어 예시 "PBP + PIP"에 로고 레이어를 더해 "PBP + PIP + 로고"(레이어 4개)로 바꿨습니다. 예시는 레이어 4개 5종, 2개 1종입니다.
- **구성도:** 가로·세로 그림 모두 OUT 1 옆에 회색 점선 상자 "OUT 2~4 · 1번과 같은 화면 · 사용 불가"를 그렸습니다.
- **그 밖의 위치:** 비디오 프로세서 비교표의 WOS100 행, 구성기 출력 카드 선택 팝업의 WOS100 활용 TIP, 카드 설명(`cardTips`), WOS100 카드 사양 "레이어 포트 제한" 행에 같은 규칙을 적었습니다.

## 5. AMX 통합 제어 분석(입력 감지 후 제어 신호 보내기)

**결론:** 가이드에는 XDM이 입력 신호 변화를 먼저 알려 주는 알림(이벤트) 커맨드가 없습니다. AMX 같은 제어기가 주기적으로 상태를 조회하고, 결과가 바뀌면 동작하는 방식으로 구성해야 합니다.

- **제어 경로:** RS-232와 LAN(TCP/IP)입니다. 커맨드 형식은 `*255…!` + CR이고 기본 ID는 255, 모든 장비에 보내는 ID는 999입니다. 응답은 `*255s…!` 형식입니다.
- **HOS100 제어:** `OQ` 커맨드로 멀티뷰 레이아웃(L00~L13)과 창 위치·크기·겹침 순서를 바꿉니다.
- **WOS100 제어:** `OW` 커맨드로 Wall Zoom·Wall Overlay(레이어), LED 모드, 로고 출력을 설정합니다.
- **상태 조회에 쓸 수 있는 커맨드:**
  - `*255?IFI000!`: 입력 정보 조회
  - `*255IFIxxx!`: 입력 포트별 정보
  - `*255OFOxxx!`: 출력 포트별 정보
  - `*255?VO000!`: 출력 해상도 조회
- **알티컴에 물을 것**(`docs/handoff/OPEN_ITEMS.md`):
  - 입력 신호가 없을 때 위 조회 커맨드가 돌려주는 응답 문자열 형식
  - 입력 신호 변화를 XDM이 먼저 보내는 기능의 유무
  - 회신 메일의 EDID 번호가 표준 펌웨어에 있는지
