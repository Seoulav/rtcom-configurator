# 0.180 VDM 정면 그림 실제 비율로 맞추기

사용자 요청(2026-09-30): "VDM 정면 그림도 실제 비율로 맞추기 … 진행해줘". 0.179에서 VDM 후면을 실제 비율로 다시 그렸고(`docs/implementation/VDM_REAR_RATIO_0.179.md` §4), 남아 있던 정면 차이를 이번에 맞췄습니다.

## 1. 기준

- 정면은 랙 날개를 포함한 폭 483mm ÷ 카탈로그 높이로 봅니다(VDM-256X는 랙 2대 966mm ÷ 39U 1,733.6mm).
- 후면(몸체 폭 440mm)과 같은 높이로 놓으면 후면 폭은 정면 폭의 약 91%가 됩니다.

## 2. 점검 결과와 조치 (`scripts/tools/draw_vdm_frames.cjs` `FRONT`)

| 모델 | 이전 가로:세로 | 실제 | 조치(그림 단위) |
|---|---|---|---|
| VDM-8X | 3.24 | 3.65 | 626×193 → 704×193, 화면·전원 스위치·MADE IN KOREA 위치를 옮김 |
| VDM-16X | 1.56 | 1.56 | 유지 |
| VDM-32X | 1.03 | 0.91 | 485×473 → 485×535, 부품 묶음을 31 내림 |
| VDM-48X | 0.57 | 0.57 | 유지 |

| VDM-180X | 0.30 | 0.29 | 189×636 → 189×661, 아래 통풍구·볼트 줄 연장 |

- 정면 그림은 구성기 슬롯 좌표와 관계가 없어 `src/app.js`는 바꾸지 않았습니다. 후면 파일은 다시 렌더링해도 바뀌지 않았습니다.

## 3. 확인

- 제품정보 프레임 팝업(PC 1280px) 좌우 배치 7종: 정면·후면 높이 같음, 후면 폭 ÷ 정면 폭 0.91(32X·48X·64X·80X·128X·180X·256X).
- 위아래 배치(8X·16X): 가로폭을 같게 놓았을 때 후면이 정면보다 약 10% 높게 보이며, 이는 실물 비율(483 ÷ 440)과 같습니다.
- `node --test tests/*.test.cjs` 72개, `node scripts/e2e-smoke.cjs` 219개 통과.
