## 1. 제품과 연결 다이어그램이 맞지 않는 문제

### A1. XDM-CTR100 "조합 1" 도식이 제목과 다르게 그려짐

- 위치: `src/products.js` `extenderDiagram()`의 `pseCombo` 분기
- 현상: 제목은 "조합 1 · XDM-CIS100·COS100 카드에 직결"인데, 그림은 `소스/매트릭스 → CTR100(송신) → CTR100(수신) → 디스플레이`로 **CTR100끼리 한 쌍**을 그립니다. 매트릭스 카드(CIS100·COS100)는 그림에 없습니다.
- 올바른 흐름(근거 U03·U04, 카탈로그 10쪽):
  - 입력: 소스 → CTR100(TX, 전원 직접) → HDBaseT → **XDM-CIS100**
  - 출력: **XDM-COS100** → HDBaseT → CTR100(RX, 전원 직접) → 디스플레이
- "조합 2 · 매트릭스 카드에 연결하지 않을 때" 문구도 구성기와 어긋납니다. 구성기는 PSE+CTR100 쌍을 **XDM HDMI 카드(HIS100·HI100·HOS100·WOS100) 연장**에 씁니다(`core.js` `psePair`). "HDBaseT 카드에 연결하지 않을 때(HDMI 카드 연장·단독 1:1 연장)"가 정확합니다.
- 전송거리는 첫 번째 사양 행(100m)만 표시되어, 0.28에서 추가한 CI6522(CAT6) 80m가 도식에 나오지 않습니다.
- 권장 모델: Sonnet(명세가 정해진 SVG 수정)

### A2. QMS-88UX 제조사 다이어그램이 실제 제품과 다름

- 위치: `output/design/assets/products/qms-88ux-diagram.webp` (46쪽판 28쪽 원본)
- 현상: 다이어그램 속 후면 라벨이 `HDMI IN 1~8`, `HDMI Out 1~8`, `DC + 12V`입니다. 같은 쪽 제품사양은 **출력 10포트**(9·10번 쿼드 뷰), 전원 **100-200 VAC**, 후면 사진도 AC 인렛·로커 스위치입니다. 제조사가 다른 섀시 그림을 재사용한 것으로 보입니다.
- 현재 처리: `qms-88ux.json` R2(출력 수)·R3(전원)에 텍스트 불일치는 기록했지만, **다이어그램 자체가 8출력·DC 섀시**라는 점은 화면에 안내가 없습니다.
- 권장: 다이어그램 아래에 "제조사 원본 그림 — 포트 수·전원 표기는 제품사양 표 기준" 캡션 추가, 또는 제조사 확인 전까지 자동 생성 도식(8 IN / 10 OUT)으로 되돌리기.
- 권장 모델: Sonnet

### A3. VDM 전송기 4종의 RS-232 단자가 입출력 표·도식에서 빠짐

- 대상: CT101-U/CR101-U, CT103-U-H/CR103-U, FT101-U/FR101-U, FT103-U-H/FR103-U
- 현상: 개요·주요 기능·영문 요약은 "비디오·오디오·**RS-232**"를 전송한다고 적고(카탈로그 21·22·24·25쪽 소개문, 사진의 녹색 Phoenix 단자), 구성기(`app.js` FT101-U 사양)도 RS-232를 표시합니다. 하지만 `io` 배열에 RS-232 행이 없어 **입출력 표와 자동 생성 도식에 RS-232가 나오지 않습니다.** 같은 계열 CT104-U/CR104-U는 RS-232 행이 있습니다.
- 권장: 카탈로그 사진·소개문 근거로 `Control / BIDIR / RS-232` 행 추가(커넥터 형식이 표에 없으면 condition에 "사진 기준 Phoenix, 핀 수 미기재" 표시).
- 권장 모델: Sonnet(카탈로그→JSON 옮겨 적기)

## 2. 제품정보와 구성기가 맞지 않는 문제

### B3. 최신 카탈로그와 구성기 모델 목록 차이 — 사용자 결정 필요

| 항목 | 46쪽판 카탈로그 | 제품정보 | 구성기 |
|---|---|---|---|
| XDM-288 | LINE-UP에서 삭제(6종만) | lineup에 "사양 미수록"으로 표시 | 선택 가능("상세 사양 확인 예정") |
| VDM HOS4-U | 20쪽 출력 보드에서 빠짐 | lineup 유지 + R6 검토 필요 | 선택 가능 |
| VDM-256X | 미수록(9종) | 매뉴얼 근거로 표시 | 선택 가능(사용자 결정 0.12) |

- XDM-288은 최신 카탈로그 기준 단종·미출시 가능성이 커서, 구성기에서 선택되면 견적이 잘못 나갈 수 있습니다.
- 선택지: ① 구성기·제품정보에서 숨김(추천, 호환성 계약상 저장된 구성은 불러올 때 경고) ② "제조사 확인 필요" 배지 유지 ③ 현행 유지.

**사용자 결정과 처리 결과(2026-09-27, 0.29.0)**

- VDM HOS4-U: HOS4-U는 "일반 스위칭" HDMI 출력 카드, HOS4S-UW는 "심리스 스위칭" HDMI 출력 카드로 두 카드 모두 현행 판매 제품이라는 사용자 확인을 받았습니다. 46쪽판에서 빠진 것은 편집 누락으로 확인해, `data/products/vdm.json`의 R6을 INFO로 바꾸고 구성기(`src/catalog.js`)·제품정보 라인업에 스위칭 방식을 명시했습니다. 선택지 ②(배지 유지)에 해당하지만, "제조사 확인 필요"가 아니라 "사용자 확인 완료"로 정리했습니다.
- XDM-288: 위 선택지 ①(숨김, 저장된 구성은 불러올 때 경고)로 확정했습니다. `src/catalog.js`의 XDM 모델 목록에서 지웠고(호환성 계약: 섀시 22 → 21), 예전에 저장한 XDM-288 구성은 `src/core.js`의 `checkState()`가 복원 실패 대신 "제품군 XDM 유지 + 섀시 미선택 + 카드·연결 비움 + 안내 문구" 형태로 안전하게 되돌리도록 처리했습니다. 자세한 내용은 `docs/implementation/XDM_288_REMOVAL.md`, 검증 결과는 `docs/qa/XDM_288_REMOVAL_QA.md`를 참고하세요. 제품정보(`data/products/xdm.json`의 lineup)는 이번 결정에서 제외해 그대로 두었습니다.
- VDM-256X는 이번 검토 대상이 아니며(0.12 사용자 결정으로 이미 확정), 표는 비교 참고용으로 남겨 둡니다.

### B4. 구성기 → 제품정보 연결이 없음

- 제품정보 → 구성기("XDM 구성기에서 구성하기")는 있으나, 구성기의 카드·전송기 타일에서 `#products/<id>` 상세로 가는 링크가 없습니다(`app.js`에 `#products` 참조 0건).
- 전송기 타일의 사양 문구(`app.js` `extenderInfo`)는 JSON과 별도로 손으로 적어 두어, JSON이 바뀌면 구성기 문구가 따로 놉니다(예: CTR100 80m 미반영).
- 권장: 타일에 "제품 상세 보기" 링크 추가, 장기적으로 `extenderInfo` 사양 문구를 JSON에서 읽기.
- 권장 모델: Opus(두 데이터 원본 통합 설계)

### B5. 케이블 거리 선택과 사양 검증이 없음

- 구성기 CAT 거리 선택지는 10/30/50/100m 고정이고 케이블 종류 입력이 없습니다. CTR100은 CAT6(CI6522)에서 80m, VDM CT104-U는 4K30에서 100m(CI6522) 등 조건부 거리인데, 100m를 골라도 경고가 없습니다(화면 문구: "케이블 종류·거리·급전 적합성은 아직 검증하지 않습니다").
- 권장: 케이블 등급(CAT6/CAT6A/CAT7) 선택 + 제품 JSON의 전송거리 행과 비교하는 WARNING 규칙.

## 3. 데이터 기록·표기 불일치

### B6. 쪽 번호가 두 카탈로그로 섞여 표시됨

- 목록 카드·상세의 "카탈로그 N쪽"은 48쪽판(`catalogPages`) 기준이고, 다이어그램 note와 C2 출처는 46쪽판 기준입니다. 21쪽 이후는 2쪽씩 차이가 납니다(예: HD-13U 화면 "36쪽" ↔ 46쪽판 34쪽, QMS-44UX 29 ↔ 27).
- 권장: 화면 표기를 46쪽판(최신)으로 통일하고 48쪽판은 출처 목록에만 남기기.

### B7. VDM 전송기 5종은 46쪽판 재검증 기록이 없음

- CHANGELOG 0.27은 "CT101/103/104-U, FT101/103-U … 새 카탈로그도 같은 표기를 반복"이라고 적었지만, 5개 파일 모두 0.19 이후 수정 이력이 없고 C2 출처·46쪽 언급이 0건입니다. 다른 22종은 C2 출처가 있습니다.
- 권장: 46쪽판 21~25쪽과 줄 단위 대조 후 C2 출처·재검증 issue 추가(A3과 함께 처리).
