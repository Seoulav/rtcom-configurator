# 제품정보 "확인 사항" 정리 기록 (2026-09-27)

사용자 요청: "확인사항 너 스스로 확인해서 대폭 삭제"(2026-09-27).

## 1. 결과

- 정리 전: 27종 제품 상세의 "확인 사항"에 118건이 있었습니다. 모두 상태가 INFO였고, REVIEW REQUIRED는 없었습니다.
- 정리 후: 2건만 남겼습니다(HD-104U·HD-108U 실크 표기 변경 예정 안내). 나머지 25종은 이 칸이 화면에서 사라집니다.
- 화면 제목을 "확인 사항"에서 "참고 사항"으로 바꿨습니다. 남은 2건은 고객에게 알려 드리는 안내이기 때문입니다.
- 정리 전 118건의 원문은 아래 4장에 그대로 남겼습니다.
