## 상태 정의

- `DOCUMENTED`: 제공 카탈로그에서 명시적으로 확인한 주장. 제품의 모든 사양과 연결 조건이 승인되었다는 뜻은 아니다.
- `CANDIDATE`: 조합 후보이나 직접적인 허용 관계 근거 부족.
- `CONFLICT`: 같은 자료 내 문구·표가 충돌하거나 해석 불일치.
- `MISSING`: 구성 검증에 필요한 자료가 없음.

생산 카탈로그의 `VERIFIED`는 필요한 필드·관계·예외의 근거가 확인되어 검토된 경우에만 부여한다. 특정 장비의 포트 수가 DOCUMENTED라도 그 장비의 모든 조합이 VERIFIED가 되지 않는다.

- Matrix/XDM/SPX/VDM 및 전송기 그룹의 정보 구조와 공통 조합 엔진 설계는 가능하다.
- 카탈로그에 명시된 XDM 직접 연결 관계와 SPX COS12/RX 관계를 구체적인 설계·테스트 시나리오로 사용할 수 있다.
- VDM 카드-전송기 직접 호환, SPX-TX 입력 경로, 프레임별 실제 슬롯·카드 허용 조건은 추가 확인이 필요하다.
- 따라서 기획 완료와 생산 데이터 확정은 구분한다. 이번 검토만으로 세 제품군 전체를 VERIFIED 처리하거나 원본 기획의 PHASE 0 Gate를 통과했다고 선언하지 않는다.
- 후속 확인에서도 출처의 상태·페이지·검토일을 유지하고 충돌 값은 임의로 고치지 않는다.
