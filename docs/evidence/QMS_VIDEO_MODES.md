# QMS-44UX·QMS-88UX 화면 구성 모드 근거 (2026-09-27)

- 출처 M-Q44: 알티컴 QMS-44UX 사용자 매뉴얼 KV.04(39쪽, 사용자 제공 2026-09-27). 저장소에는 PDF를 넣지 않고 이 요약만 둡니다.
- 출처 C2: 알티컴 종합 카탈로그 46쪽판(`docs/RTcom_catalogue_2026_46p.pdf`) 27쪽(QMS-44UX), 28쪽(QMS-88UX)
- 요청: 제품 상세에 "Video Mode · 다양한 화면구성" 아이콘 예시(MATRIX·DUAL·QUAD·WALL)를 주요 특징으로 표시(사용자 요청 2026-09-27)

## QMS-44UX (매뉴얼 기준, 전면 MATRIX/QUAD/DUAL/WALL 버튼으로 전환)

| 모드 | 요약 | 세부 레이아웃 | 매뉴얼 쪽 |
|---|---|---|---|
| MATRIX | 입력 4 → 출력 4 임의 스위칭·분배, 심리스 스위칭. 1 TO 1(같은 번호끼리)·ALL(한 입력을 모든 출력으로) 버튼 | — | 20 |
| QUAD | 입력 4개를 분할해 한 화면에 출력(모든 출력에 같은 분할 화면). 분할 화면 하나를 ZOOM-IN으로 전체 화면 전환 | QUAD, 3-BOTTOM, 3-SIDE RIGHT, 3-SIDE LEFT, CASCADE1, 4CH-POP, 2CH-SIDE, 3CH-MODE1, 3CH-MODE2, USER MODE 1~3(RS-232 커맨드로 설정) — 12종 | 21–23 |
| WALL | 2×2 비디오월, 1프레임 단위 베젤 보정 | 2×2, 2×1, 1×2, 3×1, 1×3, 4×1, 1×4, Full — 8종 | 23–24 |
| DUAL | 한 화면 2분할(출력 1·2, 3·4 쌍별 레이아웃) | PBP, PBP-Full, PIP, User Mode — 4종 | 24 |

- 제어: 전면 버튼·LCD, LAN(Telnet·Web), RS-232, IR 리모컨(매뉴얼 5·25쪽). PANEL LOCK을 켜면 모드 변경이 막힙니다(18쪽).
- 출력 해상도: 모드별로 설정합니다. 3840×2160 60/50/30/24Hz부터 800×600까지 18종(13–14쪽).

## QMS-88UX (카탈로그 C2 28쪽 기준, 매뉴얼 미확보)

| 모드 | 요약 |
|---|---|
| MATRIX | 입력 8 → 출력 8 임의 스위칭·분배, 심리스 스위칭 |
| WALL | 최대 3×3 비디오월, 베젤 조정 |
| QUAD(멀티뷰) | 출력 9·10번 전용, 한 화면 최대 8분할(8CH Multi-view) |
| DUAL | 듀얼 모드 |

- 세부 레이아웃 목록은 QMS-88UX 매뉴얼을 확보하기 전까지 표시하지 않습니다. 44UX 목록을 옮겨 적지 않습니다.

## 부수 확인: QMS-44UX 전원(§6 판단 정정)

- 매뉴얼 3쪽 구성품 "DC 12V 5A 전원 어댑터", 6쪽 전원 사양 "DC 12V 5A", 카탈로그 연결도 라벨 "+12V DC 5A"로 세 곳이 일치합니다.
- 카탈로그 사양표 "DC 12V 2A"와 매뉴얼 11쪽 본문 "DC 12V 2A 전원 어댑터"는 소수 표기로 보고 **DC 12V 5A**로 정정합니다(출처 M-Q44).
